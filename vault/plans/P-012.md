# ゴール

ルール拡張ポイント（`vault/rules/`、`scripts/rules.sh`）をインストール先に配り、README・runbook で使い方を説明する。`docs/roadmap-rules-extension.md` の「## ⑦ install.sh と README」に対応するプラン（①〜⑥は完了済み）。

## 分割方針

- 「配る（install.sh）」と「説明する（README / runbook）」を別タスクに分ける。説明タスクは配布対象のファイル名を README に書くため、配る側のタスクの後に置く（`after`）
- T-a（配る）は `scripts/install.sh` の1ファイル変更に限定し、`scripts/smoke.sh` には手を入れない（ロードマップの決定どおり）
- T-b（説明する）は `README.md`（新節＋構成ツリー）と `docs/runbook.md`（追記）の2ファイルだが、README.md の新節を主成果物とし、runbook.md への追記は付随とする
