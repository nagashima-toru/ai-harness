# T-02 README のセットアップ節を短くし docs/install.md へのリンクに寄せる

## 目的
README のセットアップ節から、CLAUDE.md へのマーカーブロックのマージや `install.sh --update` の細かい挙動を外し、`docs/install.md` へのリンクに置き換えて短くする（説明の正本は `docs/install.md`）。

## 入力
- `README.md`（T-01 の後の版）
- `docs/install.md`（「パターン2: 既存リポジトリに追加する」の CLAUDE.md マージの表と、マーカーの外の行を配らない説明、「ハーネスを更新する（2回目以降）」節。変えない）

## 成果物
- `README.md`（1ファイル。「## セットアップ」節だけを変える）

## 受け入れ基準
- セットアップ節が短い。確認：`awk '/^## セットアップ/{s=1;next} /^## /{s=0} s' README.md | grep -c .` の出力が `5` 以下
- セットアップ節から docs/install.md の該当箇所へ辿れる。確認：`awk '/^## セットアップ/{s=1;next} /^## /{s=0} s' README.md | grep -oF -e '](docs/install.md)' -e 'パターン2: 既存リポジトリに追加する' -e 'ハーネスを更新する（2回目以降）'` の出力に、この3つの文字列がすべて1回以上現れる
- 細かい挙動の説明が README から無くなっている。確認：`grep -cE 'skip \(edited\)|CLAUDE\.md\.bak-|--no-claude-md|マーカーの外|未編集のファイルだけ|4行ブロック' README.md` の出力が `0`。clone の手順はクイックスタートだけにある：`grep -c 'git clone' README.md` の出力が `1`
- README から落とした情報（このリポジトリの CLAUDE.md のマーカーの外の `@docs/vision.md` は導入先に配らないこと）が docs/install.md に残っている。確認：`grep -cF 'マーカーの外の行（ハーネス本体のリポジトリだけが読む `@docs/vision.md` など）は配らない' docs/install.md` の出力が `1`
- 見出し構成が変わっていない。確認：`grep -E '^## ' README.md` の出力がちょうど次の8行（この順）：`## 目的`・`## セットアップ`・`## クイックスタート`・`## 使い方`・`## 拡張ポイント（ルール）`・`## 仕組み`・`## 構成`・`## ライセンス`
- 文書中のパスが実在する。確認：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`

## 決定済み
- セットアップ節に残すのは、前提の行（`claude`（Claude Code）・`git`・`python3`）と、他のプロジェクトへの組み込み・更新・取り外しは `[docs/install.md](docs/install.md)` を見る旨の1〜2行だけ。案内の文には `パターン2: 既存リポジトリに追加する` と `ハーネスを更新する（2回目以降）` の2つの節名をそのまま書く（GitHub の日本語見出しのアンカーは使わず、ファイルへのリンク＋節名で示す）
- 「# このリポジトリで試す」の clone・smoke のコードブロックはセットアップ節から消す（クイックスタート節に同じ手順があるため。`git clone` は README 全体で1回）
- `bash scripts/install.sh --update <組み込み先>` というコマンド名を1回書くのはよいが、その挙動（未編集のファイルだけ最新化・`skip (edited)`・マニフェスト）は書かない
- CLAUDE.md の説明（ルール本文が `.claude/ai-harness.md` にあり導入先の CLAUDE.md にはマーカー付きブロックだけが入る・`CLAUDE.md.bak-<日時>`・`--no-claude-md`・マーカーの外の `@docs/vision.md`）はセットアップ節から消す。これらは `docs/install.md` パターン2（「マーカーの外の行（ハーネス本体のリポジトリだけが読む `@docs/vision.md` など）は配らない」の文と出力の表）と「ハーネスを更新する（2回目以降）」節に既にあるので、`docs/install.md` には追記しない（変えない）
- セットアップ節以外（冒頭・クイックスタート・使い方・拡張ポイント・仕組み・構成・ライセンス）は変えない
