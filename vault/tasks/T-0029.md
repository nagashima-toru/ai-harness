# T-0029 `scripts/install.sh` への組み込み（`--no-claude-md`）と関連ドキュメント更新

## 目的
`scripts/install.sh` が `merge_claude_md.py` を使って CLAUDE.md を既定でマージするようにし、
`--no-claude-md` で従来の note 案内に戻せるようにする。関連ドキュメント（smoke.sh・
docs/install.md・README.md・docs/decisions.md）を実挙動に合わせて更新する。

## 入力
- T-0028 の `scripts/merge_claude_md.py`
- `scripts/install.sh`（現行61〜66行の CLAUDE.md 分岐、13〜15行の `copy_if_absent`、7行目の引数
  チェック）
- `docs/install.md`（80行目付近の表、34行目の複製対象の説明）
- `README.md`（「## セットアップ」節）
- `docs/decisions.md`（末尾に1行追記する形式）

## 成果物
- `scripts/install.sh`（変更）

## 決定済み
- インターフェース：`bash scripts/install.sh [--no-claude-md] <target-dir>`（フラグは target-dir の前に置く）。既存の「引数がちょうど1つ」というチェックはフラグを除いた残り引数の数で判定するよう変更する。
- 既定（フラグ無し）の実装イメージ：`python3 "$SRC/scripts/merge_claude_md.py" "$SRC/CLAUDE.md" "$DST/CLAUDE.md"` を呼び、そのスクリプトの標準出力（`create`/`merge`/`update`/`skip` の1行）を install.sh の出力にそのまま混ぜる。挙動が同じであれば別実装でもよい。
- `--no-claude-md` 指定時は、現行の分岐（`$DST/CLAUDE.md` があれば `note  CLAUDE.md は既にあります。...` を出す、無ければ `copy_if_absent` で複製する）をそのまま残す。`rm` は使わない。
- `scripts/smoke.sh` への追加ケースは新しい一時ディレクトリ（既存のフック検証用 `$TMP` とは別に `mktemp -d`）を使い、`echo dummy > $TMP2/CLAUDE.md` のように既存本文を置いてから `bash "$ROOT/scripts/install.sh" --no-claude-md "$TMP2"` を実行し、実行後も `$TMP2/CLAUDE.md` の中身が `dummy` のまま変わらないことを確認する。
- `docs/install.md` のパターン2節（80行目付近の表）は、`note`/`skip` の説明に加えて既定動作（`merge_claude_md.py` による自動マージ、出力が `create`/`merge`/`update`/`skip` のいずれかになること）と `--no-claude-md` で従来の note 案内に戻せることを説明する。34行目の複製対象の説明文にも `.claude/ai-harness.md` を含める。
- `README.md` の「## セットアップ」節には、CLAUDE.md はマーカー付きスタブで本文は `.claude/ai-harness.md` にある旨を1行加える。
- `docs/decisions.md` に追記する1行：日付 `2026-09-19`、内容「CLAUDE.md はマーカー+`@.claude/ai-harness.md` のスタブにし、`scripts/install.sh` は既定で `merge_claude_md.py` により既存 CLAUDE.md にマージする（`--no-claude-md` で従来の note 案内に戻せる）」、理由「既存 CLAUDE.md を壊さずハーネスの規律をメインコンテキストに読み込ませるため」。
