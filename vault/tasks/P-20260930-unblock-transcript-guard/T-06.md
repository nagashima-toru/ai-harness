## 受け入れ基準
- 2節の「`blocked→todo` は人のみ」が、人が `/plan unblock <計画ID> <id> [回答]` で指示する旨を含む。確認：`grep -n 'blocked→todo` は人のみ' docs/vault-spec.md` がヒットせず、`grep -n '/plan unblock' docs/vault-spec.md` が2節内の行にヒットする
- 7節に、解除の log 行の形 `- <日時> <id> blocked→todo 人の指示: /plan unblock <計画ID> <id>` が追記されている。確認：`grep -n 'blocked→todo 人の指示: /plan unblock' docs/vault-spec.md` が7節内の行にヒットする
- 10節に plan_guard の解除の裏付け（作業ツリーと HEAD のタスク表の比較・裏付けが無ければブロックして `git restore` を指示・読めない時は警告・非 git では何もしない・解除の直後にコミットする）が追記されている（目視で確認）
- 12節の判定表に agent_write_guard の解除の行（blocked の行が blocked 以外になる書き込み → メインセッションかつ会話記録に `/plan unblock <計画ID> <id>` がある時だけ許可、それ以外はブロック、読めない時は許可）が追加され、会話記録の規則に `unblock` のコマンドの一致（計画 ID・タスク ID の完全一致、後ろに回答可）が追記されている。確認：`grep -n 'unblock' docs/vault-spec.md` が12節内の行にヒットする
- 追記以外の記述の意味が変わっていない。確認：`git diff -- docs/vault-spec.md | grep -E '^-[^-]'` の出力が、2節の遷移の1行と、追記に伴う行の書き換えに限られることを目視で確認する

- 設計文書 `vault/designs/D-010.md` は変更しない
