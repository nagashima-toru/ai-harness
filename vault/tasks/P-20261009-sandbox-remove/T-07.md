# T-07 README の構成の節から settings.json の「サンドボックス」を外す

## 目的
T-01 で `.claude/settings.json` から `sandbox` を外すと、`README.md` の「## 構成」の「settings.json（hooks・許可・サンドボックス）」が事実と合わなくなるので直す（人の回答：この計画に含める）。

## 入力
- `README.md` の「## 構成」のコードブロックの `.claude/` の行（計画作成時は80行目）
- T-01 後の `.claude/settings.json`（トップレベルのキーは `hooks`・`permissions`・`worktree`）

## 成果物
- `README.md`（1ファイル）

## 受け入れ基準
- `README.md` にサンドボックスへの言及が無い。確認：`grep -c "サンドボックス" README.md` の出力が `0`
- 構成の節の `.claude/` の行が決定済みの1行になっている。確認：`grep -c -F '.claude/   settings.json（hooks・許可）、agents/（creator, verifier, planner）、hooks/、skills/（design, plan, run）' README.md` の出力が `1`
- 見出しの数は変わらない。確認：`grep -c "^## " README.md` の出力が `7`
- `bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` を含む（参照切れの検査 `(ref-1)` を含む）

## 決定済み
- 「## 構成」のコードブロックの `.claude/` の行を、次の1行にする：「.claude/   settings.json（hooks・許可）、agents/（creator, verifier, planner）、hooks/、skills/（design, plan, run）」（`.claude/` の後の空白3つ・全角の括弧と読点は今の行のまま。「・サンドボックス」だけを消す）
- ほかの行は変えない
