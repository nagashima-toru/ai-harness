# T-04 ai-harness.md のスキルの節から /plan approve を外し、自動承認の説明にする

## 目的
`.claude/ai-harness.md` の「## スキル」の節の `/plan` の説明を、承認待ちの無い流れ（D-015 フェーズ2）に合わせる。

## 入力
- `vault/designs/D-015.md` の「フェーズ2」の節
- `.claude/ai-harness.md`（「## スキル」の節。計画作成時は27行目）

## 成果物
- `.claude/ai-harness.md`（1ファイル）

## 受け入れ基準
- `/plan approve` が残っていない。確認：`grep -c "plan approve" .claude/ai-harness.md` の出力が `0`
- `/plan` の説明が自動承認と `/run` の続行になっている。確認：`grep -c -F '`/plan <ゴール>`（計画を draft で作りブランチを切り、粒度の確認を通ったら approved にしてコミットし、続けて `/run` を実行する。' .claude/ai-harness.md` の出力が `1`
- `/plan unblock` の説明は残る。確認：`grep -c -F '`/plan unblock <計画ID> <id> [回答]` で blocked を解除して todo に戻す' .claude/ai-harness.md` の出力が `1`
- 行数と見出しの数は変わらない。確認：`grep -c "" .claude/ai-harness.md` の出力が `32`、`grep -c "^## " .claude/ai-harness.md` の出力が `6`
- `bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` を含む（`merge_claude_md.py` と参照切れの検査を含む）

## 決定済み
- 「## スキル」の節の1行のうち、`/plan <ゴール>` の括弧の中だけを次にする：「計画を draft で作りブランチを切り、粒度の確認を通ったら approved にしてコミットし、続けて `/run` を実行する。`/plan unblock <計画ID> <id> [回答]` で blocked を解除して todo に戻す」。その後ろの `・`/run`（…）・`/design <ゴール>`（…）` は1文字も変えない
- 「## 状態遷移（5つで固定）」の「`blocked → todo` は人が `/plan unblock …` で指示した時だけ（フックが会話記録で確認する。…）」は変えない（`agent_write_guard.py` の unblock の判定が今回も会話記録を見るため。D-015 フェーズ3・5 で直す）
- 「## 開始時に読む順」「## 役割」など、ほかの行は変えない
- 改行は1行のまま（行を増やさない）
