# T-01 creator.md に確認コマンドがガードに拒否された時のふるまいを書く

## 目的
creator が受け入れ基準の確認コマンドをガード（権限判定・サンドボックスなど）に拒否された時に、基準を緩めた確認へ黙って置き換えず、緩めずに確かめられる時だけ代替で確かめて「進捗」に記録し、それ以外は blocked を返すようにする。

## 入力
- `.claude/agents/creator.md`（変更対象。「## やらないこと（このリポジトリで実際に起きた失敗から）」節）
- `.claude/agents/verifier.md` の「## 手順」8（verifier 側の同種のルール。整合させる相手）
- `docs/vision.md`（「迷ったら推測で進めずに止める」「完了かどうかは作った本人に決めさせない」）

## 成果物
- `.claude/agents/creator.md`（1ファイル）

## 受け入れ基準
- `grep -c '拒否されて実行できない時は' .claude/agents/creator.md` の出力が `1`
- `grep -c '4つをセットで書く' .claude/agents/creator.md` の出力が `1`
- `grep -c '元の基準より緩い確認にしかならない時は' .claude/agents/creator.md` の出力が `1`
- `grep -c 'verifier が元の確認コマンドで行う' .claude/agents/creator.md` の出力が `1`
- `grep -n -e '^## ' -e '拒否されて実行できない時は' .claude/agents/creator.md` の出力で、`拒否されて実行できない時は` を含む行の行番号が `## やらないこと（このリポジトリで実際に起きた失敗から）` の行より大きく、`## 完了前の確認` の行より小さい
- `bash scripts/smoke.sh 2>&1 | tail -1` の出力が `smoke: pass=<数> fail=0` の形
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`

## 決定済み
- 方針は「緩めずに確かめられる代替がある時だけ代替で確かめて『進捗』に記録し、緩める以外に手が無い時は blocked」に決まっている（計画の方針として決定済み。Issue の候補 (a)・(b) のどちらかを選び直さない）。
- 追加するのは箇条書き1項目だけ。置き場所は「## やらないこと（このリポジトリで実際に起きた失敗から）」節の、既存の最後の項目（「受け入れ基準に無い作業を足さない（…）」の行）の直後、「## 完了前の確認」の見出しの前の空行より前。既存の行は1文字も変えない。
- 追加する項目の本文は、次の1行をそのまま書く（文言を変えない。受け入れ基準の grep はこの文言に一致させてある）：
  `- 受け入れ基準の確認コマンドがガード（権限判定・サンドボックスなど）に拒否されて実行できない時は、黙って別のコマンドに置き換えない。同じ対象を同じ条件で確かめられる代替（例：Bash の grep が拒否されたら、同じパターンを Grep ツールで探す）がある時だけそれで確かめ、「進捗」に、元の確認コマンド・拒否された旨・代替の確認方法・その結果の4つをセットで書く。パターンの一部を削る・条件を緩めるなど、元の基準より緩い確認にしかならない時は、代替で済ませず、どの基準のどのコマンドが拒否されたかを添えて「blocked: <質問文>」を返す。代替で確かめても完了の判定は verifier が元の確認コマンドで行うので、完了報告で「実質同じ」と主張しない。`
  （上の行の前後のバッククォートは、このタスク票で引用するための囲みで、creator.md には書かない。行頭は `- ` から始める）
- 計画 ID・Issue 番号・タスク ID などこのリポジトリ固有の経緯は creator.md に書かない（creator.md は導入先に配布されるため）。
- `.claude/agents/verifier.md`・`.claude/agents/planner.md`・`vault/rules/` は変えない（範囲外。verifier 側は既に「手順」8で同種のルールを持つ）。
- smoke の `(agents-1)` は creator.md に「起点コミット」の語が無いことを見る。追加する文言にこの語は無いので、そのまま書けばよい。
- auto mode で `.claude/` の編集が Self-Modification として権限判定に拒否された時は、自分で回避せず「blocked: .claude/agents/creator.md の編集が権限判定に拒否された」を返す。
- コミットはしない（受け入れ基準にコミットは無い）。
