# T-03 smoke.sh の fixtures-comment の依存を外し、一括削除後も smoke が全部通ることを確かめる

## 目的
`scripts/smoke.sh` が過去の計画のタスク票ディレクトリ（`vault/tasks/P-20261004-hooklib-rules/fixtures-comment/`）のフィクスチャを読まず、一時ディレクトリに自分で作るようにする。そのうえで、計画のゴール（一括削除 `bash scripts/purge_plan.sh --merged --apply` の後も smoke が全部通る）を、一括削除した一時 worktree で確かめる。

## 入力
- `scripts/smoke.sh`（1829〜1835行目付近の `# d` の hooklib-rules の current_plan.sh のテスト）
- `vault/tasks/P-20261004-hooklib-rules/fixtures-comment/vault/plans/P-FIXTURE-COMMENT.md`（今のフィクスチャ。読むだけで変えない）
- `scripts/current_plan.sh`・`scripts/purge_plan.sh`
- 先行タスク T-01（`docs/vault-spec.md`）・T-02（`docs/runbook.md`）の成果物（計画ブランチにマージ済み。このタスクでは変えない）

## 成果物
- `scripts/smoke.sh`（1ファイル）

## 受け入れ基準
- smoke.sh が計画の実ファイルを読まない。確認：`grep -nE 'ROOT/vault/(plans|tasks|verdicts|log|archive)' scripts/smoke.sh` と `grep -nF 'P-20261004-hooklib-rules' scripts/smoke.sh` がどちらも何も出力しない
- smoke.sh が fixtures-comment と同じ frontmatter のフィクスチャを自分で作り、テストが通る。確認：`grep -cF 'id: P-FIXTURE-COMMENT # id の後ろにメモ\nstatus: approved # status の後ろにメモ' scripts/smoke.sh` が `1`、`grep -cF '[ "$hr_fc" = "P-FIXTURE-COMMENT" ]' scripts/smoke.sh` が `1`、`bash scripts/smoke.sh 2>&1 | grep -F 'current_plan.sh: id・status が引用符付き'` の行が `ok` で始まる（行頭の空白を除く）
- 一括削除していない作業ツリーで smoke が全部通る。確認：`bash scripts/smoke.sh 2>&1 | tail -1` が `fail=0` を含む
- `vault/log/` が一括削除後も残る。確認：`git ls-files vault/log/.gitkeep` が `vault/log/.gitkeep` を出力する
- 一括削除した一時 worktree で smoke が全部通る（ゴールの確認）。確認（対象の作業ツリーのルートで、次の単一コマンドを順に実行する）：`mkdir -p /tmp/claude/P-20261010-purge-prereq-T-03`、`git worktree remove --force /tmp/claude/P-20261010-purge-prereq-T-03/wt`（無ければ失敗してよい）、`git worktree prune`、`git worktree add --detach /tmp/claude/P-20261010-purge-prereq-T-03/wt HEAD`、`env -C /tmp/claude/P-20261010-purge-prereq-T-03/wt bash scripts/purge_plan.sh --merged --apply | tail -1` が `vault/archive/` を出し、`bash /tmp/claude/P-20261010-purge-prereq-T-03/wt/scripts/smoke.sh 2>&1 | tail -1` が `fail=0` を含む

## 決定済み
- 直し方：`# d` のブロックで、`$TMP/hr_fc/vault/plans/P-FIXTURE-COMMENT.md` を作り、`CLAUDE_PROJECT_DIR` をそこ（`$TMP/hr_fc`）に向ける。次の形にする（`hr_fc` の判定の行と `expect_eq` の行は変えない）：
  ```
  mkdir -p "$TMP/hr_fc/vault/plans"
  printf -- '---\nid: P-FIXTURE-COMMENT # id の後ろにメモ\nstatus: approved # status の後ろにメモ\n---\n' > "$TMP/hr_fc/vault/plans/P-FIXTURE-COMMENT.md"
  hr_fc="$(CLAUDE_PROJECT_DIR="$TMP/hr_fc" bash "$CURRENT_PLAN_SH")"
  ```
  `$TMP/vault/plans` はこのブロックで消して作り直されるので、フィクスチャはそれとは別の `$TMP/hr_fc` に置く。printf の1つの文字列に frontmatter を書く（受け入れ基準2の grep はこの1行に一致する）。本文（ゴール・タスク表）は current_plan.sh が frontmatter しか見ないので書かない
- `# d` のコメント（「status の後ろに語が続く fixtures-comment も同じ出力に含める。両方満たす時だけ P-CUR-Q になる」）は、フィクスチャを smoke が作ることが分かる言い回しに直してよい。テスト名（`(hooklib-rules) current_plan.sh: id・status が引用符付き → 引用符を外した計画 ID を出す`）は変えない
- `vault/tasks/P-20261004-hooklib-rules/fixtures-comment/` は変えない・消さない（過去の計画のタスク票ディレクトリで、一括削除で消える。成果物でもない）
- ほかに smoke が計画の実ファイルに依存している箇所：計画時点の洗い出し（`grep -nE 'ROOT/vault/(plans|tasks|verdicts|log|archive)' scripts/smoke.sh`）では1833行目の1件だけ。そのほかの `vault/plans/P-*`・`vault/archive/` などの出現は `$TMP` などの一時ディレクトリに自分で作るフィクスチャで、直さない。着手時に同じ grep をやり直し、ほかの一致があれば同じく一時ディレクトリにフィクスチャを作る形に直す
- `vault/log/.gitkeep` は creator が作らない（差分ゲートが `vault/log/` 配下の変更を宣言があっても違反にする）。人が計画ブランチに足す前提（計画票の「人への質問」の1）。受け入れ基準4を満たさない（`git ls-files vault/log/.gitkeep` が何も出さない）時は、作らずに `blocked: vault/log/.gitkeep が計画ブランチに無い` で返す
- 受け入れ基準5で fail が残った時は、`bash /tmp/claude/P-20261010-purge-prereq-T-03/wt/scripts/smoke.sh 2>&1 | grep -F 'NG'` で落ちたテストを見る。原因が smoke.sh 以外（`docs/` の文書・`.claude/` の文書・`vault/log/.gitkeep`）にある時は、このタスクでは直さず `blocked: <テスト名と原因のファイル>` で返す
- 受け入れ基準5の「対象の作業ツリー」：creator は自分の worktree のルート（smoke.sh の変更をコミットしてから一時 worktree を作る。`HEAD` に入っていない変更は一時 worktree に入らない）、verifier は渡された worktree（`git -C <worktree のパス> worktree ...` の形で実行してよい）。`/tmp/claude/...` に書けない時は、代わりに対象の作業ツリーの `.claude/worktrees/purge-check-T-03`（`.gitignore` 済み）を使ってよい
- 一時 worktree は detached HEAD で作る（現在のブランチの計画の除外条件に当たらないが、この計画の計画票は approved なので一括削除の対象にならない）。一括削除（`git rm`）は一時 worktree の中だけで行い、対象の作業ツリーでは `purge_plan.sh --merged --apply` を実行しない。確認が終わったら `git worktree remove --force /tmp/claude/P-20261010-purge-prereq-T-03/wt` で片づける（`rm -rf` は使わない。親ディレクトリは残してよい）
- 計画時点で一時 worktree の手順を実行した結果：smoke は `pass=476 fail=2`（ref-1 と hooklib-rules の current_plan.sh の2件）。所要は約1分
- （人への質問1の回答）`vault/log/.gitkeep` は (a)：人の指示で計画ブランチに足してコミット済み（48b14e9）。このタスクでは作らない
- （/plan unblock の回答）一時 worktree（/tmp/claude/ 配下で git worktree add したもの）の中での purge_plan.sh --merged --apply の実行は人が許可する。基準5はその一時 worktree で確かめる
- （/plan unblock の回答・2回目）一時 worktree の中での purge_plan.sh --merged --apply は、acceptEdits セッションで人が確認のプロンプトを承認して実行する
