# T-06 creator.md の破棄の指示から、permissions.deny で拒否済みという括弧書きを外す

## 目的
T-01 で `permissions.deny` から `git clean`・`git reset --hard` を外すと、`.claude/agents/creator.md` の git 節の「（`.claude/settings.json` の `permissions.deny` で拒否済み）」が事実と合わなくなる。括弧書きだけを直し、creator は worktree でこの2つを使わないという指示は残す（人の回答：この計画に含める）。

## 入力
- `vault/designs/D-015.md` の「決定事項」の表（`permissions.deny` の行）
- `.claude/agents/creator.md` の「## git」節の「- 破棄：」の行（計画作成時は37行目）
- T-01 後の `.claude/settings.json`

## 成果物
- `.claude/agents/creator.md`（1ファイル）

## 受け入れ基準
- `.claude/agents/creator.md` に `permissions.deny` で拒否済みという記述が無い。確認：`grep -c "permissions.deny" .claude/agents/creator.md` の出力が `0`
- 「- 破棄：」の行が、2つのコマンドを使わない指示と決定済みの理由で終わっている。確認：`grep -c "^- 破棄：.*clean.*reset --hard.* は使わない（worktree の中の自分の作業まで消すため）$" .claude/agents/creator.md` の出力が `1`
- 破棄に `git restore` だけを使うという指示は残る。確認：`grep -c "^- 破棄：作業ツリーの変更の破棄は .git restore. だけを使う。" .claude/agents/creator.md` の出力が `1`
- 見出しの数は変わらない。確認：`grep -c "^## " .claude/agents/creator.md` の出力が `11`
- `bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` を含む

## 決定済み
- 「- 破棄：」の行を次の1行にする（ほかの行は変えない）：「- 破棄：作業ツリーの変更の破棄は `git restore` だけを使う。`git clean`・`git reset --hard` は使わない（worktree の中の自分の作業まで消すため）」
- 「使わない」という指示は残す（創作側が自分の作業を消す操作を避けるため）。半端な git 状態をエージェントが直す手順は D-015 フェーズ5 で `docs/runbook.md` に書くので、このタスクでは足さない
- 括弧書きに `permissions.deny`・`settings.json` の語を残さない
- 確認コマンドの `.git restore.` の `.` は、バッククォートの代わりに任意の1文字に一致させるためのもの（確認コマンドにバッククォートを書かないため）
- `.claude/agents/creator.md` の編集が拒否された時は、別の手段で書き換えず、拒否の理由を question に書いて `blocked` にする
