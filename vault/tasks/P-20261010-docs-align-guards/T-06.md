# T-06 creator.md・ai-harness.md・README.md を揃え、リポジトリ全体に古い語が残っていないことを確かめる

## 目的
`.claude/agents/creator.md`・`.claude/ai-harness.md`・`README.md` に残る守りを絞る前の記述（フックが常に拒否・下書きファイル方式・会話記録による unblock の確認）を実際の状態に揃え、計画全体のゴール（古い語がリポジトリのどこにも残っていない）をリポジトリ全体で確かめる。

## 入力

- `.claude/agents/creator.md`・`.claude/ai-harness.md`・`README.md`（直す対象）
- 実際の状態の正本：`.claude/hooks/agent_write_guard.py`（判定は (a)(b)(c) の3つだけ）・`scripts/diff_gate.py`（`FORBIDDEN_PREFIXES`）・`.claude/skills/plan/SKILL.md`（B 節 unblock）
- 先行タスク T-01〜T-05 の成果物（計画ブランチにマージ済み。このタスクでは変えない）

## 成果物
- `.claude/agents/creator.md`（主な成果物）
- `.claude/ai-harness.md`（付随して変える）

## 受け入れ基準
- リポジトリ全体（当時の記録と smoke のテストを除く）に古い語が残っていない。確認：`git grep -n "plan approve\|excludedCommands\|提案ファイル\|会話記録で確認" -- . ':!vault/designs' ':!vault/log' ':!vault/archive' ':!vault/plans' ':!vault/tasks' ':!vault/verdicts' ':!scripts/smoke.sh'` が何も出力しない
- リポジトリ全体（同じ除外と `vault/rules/README.md`）に、守りを絞る前の言い回しが残っていない。確認：`git grep -n 'フックが常に拒否\|-proposal\.md\|会話記録で裏付け\|会話記録の人の発言\|計画を承認する' -- . ':!vault/designs' ':!vault/log' ':!vault/archive' ':!vault/plans' ':!vault/tasks' ':!vault/verdicts' ':!scripts/smoke.sh' ':!vault/rules/README.md'` が何も出力しない
- `creator.md` の書き込まない物の節が差分ゲートで説明され、frontmatter は変わっていない。確認：`grep -c '^## 書き込まないもの（差分ゲートが差し戻す）$' .claude/agents/creator.md` が `1`、`sed -n 1,6p .claude/agents/creator.md` の出力が「決定済み」に書いた6行と一致する
- `ai-harness.md` の unblock の説明と `README.md` のルールの説明が今の状態になっている。確認：`grep -c 'フックでは確かめない' .claude/ai-harness.md` が `1`、`sed -n '/^## 拡張ポイント（ルール）/,/^## 仕組み/p' README.md | grep -c 'scripts/diff_gate.py'` が1以上
- `bash scripts/smoke.sh 2>&1 | tail -1` が `fail=0` を含む（主な文書の参照切れの検査を含む）

## 決定済み
- 確認の範囲はゴールの範囲（リポジトリ全体）にする。除外とその理由：
  - `vault/designs/`・`vault/log/`・`vault/archive/`・`vault/plans/`・`vault/tasks/`・`vault/verdicts/`：当時の記録なので書き換えない（D-015 フェーズ5 の決定済み）
  - `scripts/smoke.sh`：古い語が無いことを確かめるテストのケース名・テスト用データを含む
  - `vault/rules/README.md`（受け入れ基準2だけ）：`scripts/diff_gate.py` が `vault/rules/` 配下の変更を宣言があっても違反にするため、creator のタスクでは変えられない。扱いは計画票の「人への質問」の1で人が決める。古い語4つはこのファイルに無いので、受け入れ基準1では除外しない
- 受け入れ基準1・2で何か出力された時、それが T-01〜T-05 の成果物（`docs/` の5ファイル・`.claude/agents/planner.md`）の中なら、このタスクでは直さず `blocked: <ファイルと行>` で返す（同じファイルを2つのタスクで変えない）
- `creator.md` の直し：
  - 23行目の「（計画票への書き込みはフックが常に拒否する）」を「（計画票はオーケストレーターだけが書く。creator の差分に入ると差分ゲートが差し戻す）」に直す
  - 45行目の見出しを `## 書き込まないもの（差分ゲートが差し戻す）` にする
  - 48行目は次の1行にする：`- `vault/rules/` 配下：ルールの変更はタスクの成果物にしない（宣言があっても差分ゲートが違反にする）。人が編集する`
  - 60行目は次の1行にする：`- タスク中に `vault/rules/` を編集しない（宣言があっても差分ゲートが違反にする）。`
  - 35行目（`main` に直接コミットしない。`agent_write_guard.py` が強制）・37行目（`git clean`・`git reset --hard` を worktree で使わない）・54・61行目（done のタスク票）は実際の状態と合っているので変えない
  - frontmatter（1〜6行目）は変えない。今の6行は次のとおり（1行目と6行目が `---`）：
    ```
    ---
    name: creator
    description: run のメインセッション（オーケストレーター）から Agent ツールで呼ばれ、タスク ID を受け取ってタスク1件分の成果物を作る作成エージェント。計画票のタスク表・ログへの書き込みは行わず、成果物とタスク票の「進捗」だけを書く。
    tools: Read, Grep, Glob, Bash, Write, Edit
    model: sonnet
    ---
    ```
- `.claude/ai-harness.md` の12行目の括弧書き「（フックが会話記録で確認する。エージェントの独断は不可）」を「（フックでは確かめないが、エージェントの独断は不可）」に直す。「フックでは確かめない」はこのファイルで1回だけ書く。ほかの行（承認済みの計画の読み方・禁止の節など）は変えない
- `README.md` の53行目は次の趣旨の1項目にする：フックは `vault/rules/` への書き込みを止めないが、creator のタスクの成果物にはできない（差分ゲート `scripts/diff_gate.py` が `vault/rules/` 配下の変更を宣言があっても違反にする）。ルールの追加・変更はタスクにせず、人が編集する（自分で、またはタスクの外でエージェントに指示して）。変更は PR の差分で見える。README.md のほかの行は変えない
- 古い語（`/plan approve`・`excludedCommands`・`提案ファイル`・`会話記録で確認`）と受け入れ基準2の言い回しは、「廃止した」という説明でも書かない
- バッククォートで囲むパス（`vault/`・`scripts/`・`docs/`・`.claude/` で始まるもの）は実在するものだけにする（smoke の参照切れの検査が見る）
