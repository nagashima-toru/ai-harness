# T-0028 `scripts/merge_claude_md.py` 新規作成と `scripts/smoke.sh` へのケース追加

## 目的
CLAUDE.md へのハーネスブロックのマージを冪等に行うスクリプトを作り、create/merge/update/skip の
4パターンを `scripts/smoke.sh` で検証する。

## 入力
- T-0027 が作った `CLAUDE.md`（4行のブロック。merge_claude_md.py が読み込む「ブロックの雛形」その
  もの）と `.claude/ai-harness.md`
- `scripts/smoke.sh`（既存の `expect`/`expect_guard`/`expect_rules` ヘルパーとケースの書き方。
  `TMP="$(mktemp -d)"` を使い回す構造）
- ゴールで指定された5パターンのうち、`--no-claude-md` に関するもの（5番目）を除く4パターン
  （無し→作成、既存あり→追記+bak、2回実行→冪等、ブロック変更後→置換）

## 成果物
- `scripts/merge_claude_md.py`（新規、python3）
- `scripts/smoke.sh`（追記のみ。既存ケースは変更しない）

## 受け入れ基準
- dst が存在しない状態で `python3 scripts/merge_claude_md.py <src> <dst>` を実行すると dst が作成され `@.claude/ai-harness.md` を含み、標準出力が `create ` で始まる。確認コマンド: smoke.sh 内の該当ケース、または個別に `TMP=$(mktemp -d); python3 scripts/merge_claude_md.py CLAUDE.md "$TMP/CLAUDE.md"` を実行し出力とファイル内容を確認
- 既存 dst（マーカーを含まない本文があるファイル）に対して実行すると、既存行がすべて残ったまま末尾にブロックが追記され、`<dst>.bak-<YYYYMMDDHHMMSS>` が1つ作られ、標準出力が `merge ` で始まる
- 同じ src/dst の組で直後にもう一度実行すると、`ai-harness:begin` の出現回数が1のままで、標準出力が `skip ` で始まる（冪等）。確認コマンド: `grep -c 'ai-harness:begin' <dst>`（1）
- src のブロック本文（見出し行など）を変えてから再実行すると、旧ブロックが消えて新ブロックに置き換わり、マーカー外の既存本文は変更されない。標準出力は `update ` で始まる
- `bash scripts/smoke.sh` が pass のみで終わる（新規ケース込みで fail=0）。確認コマンド: `bash scripts/smoke.sh | tail -1`（`fail=0` を含む）

## 決定済み
- 呼び出し形式：`python3 scripts/merge_claude_md.py <src_claude_md> <dst_claude_md>`（ディレクトリではなく2つのファイルパス）。install.sh からの呼び出し方は T-0029 で決める（このタスクでは単体スクリプトとして完結させる）。
- 判定順序：(1) dst が無ければ親ディレクトリを作って src の内容をそのまま書き込み `create <dst>` を1行出力。(2) dst があり内容が src と完全一致（バイト一致）なら何もせず `skip <dst>` を出力。(3) dst に `<!-- ai-harness:begin` で始まり `<!-- ai-harness:end -->` で終わる範囲（正規表現、バージョン番号 `v1` 等は問わない、`re.DOTALL`）が見つかれば、その範囲だけを src の内容に置換して `update <dst>` を出力。(4) 見つからなければ、既存内容の末尾に空行1つ + src の内容を追記して `merge <dst>` を出力。
- (3)(4) は書き換え前に必ず `<dst>.bak-<YYYYMMDDHHMMSS>`（タイムスタンプはローカル時刻でよい。JST固定は運用ログ用の要件であり、バックアップファイル名の一意性確保が目的のここでは必須ではない）を作ってから dst を上書きする。`rm` は使わない。(1)(2) はバックアップを作らない。
- 標準出力は `create <path>` / `merge <path>` / `update <path>` / `skip <path>` のいずれか1行だけ。終了コードは成功時0。src が読めない場合はエラーメッセージを stderr に出し終了コード1。
- 実装は標準ライブラリのみ（`re`・`sys`・`pathlib`・`datetime`・`shutil` 等）。`sed -i` は使わない（BSD/GNU差異のため、既定の決定どおり）。
- smoke.sh への追記は既存の `== stop_gate.py ==` 等と同じ見出しスタイルで `== merge_claude_md.py ==` を追加し、`$TMP` を使い回してよい（各ケースの直前で対象ファイルを作り直す）。
