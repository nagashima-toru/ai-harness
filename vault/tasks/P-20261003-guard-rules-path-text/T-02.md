# T-02 ガードが cat のヒアドキュメントだけのコマンド置換を解析できるようにする

## 目的
`gh issue create --body "$(cat <<'EOF' … EOF)"` のように、本文が `cat` のヒアドキュメントだけのコマンド置換は書き込みを起こさない。これを解析前に1語の文字列に置き換え、`analyze_bash_writes` が None（従来判定）に落ちて本文中の `vault/rules/` を書き込み先とみなす誤検知を無くす。

## 成果物

## 決定済み
- 置き換える形：`$(` の直後（空白可）に `cat`、空白、`<<` か `<<-`、区切り語（`'EOF'`・`"EOF"`・`\EOF`・`EOF` のどれか。語は `[A-Za-z_][A-Za-z0-9_]*`）、行末までの空白、改行、本文、区切り語だけの行（`<<-` の時は行頭のタブを許す）、その後に空白・改行だけを挟んで `)` が来るもの。この `$(…)` 全体を1語 `HEREDOC_TEXT`（引用符・空白・記号を含まない語）に置き換える。二重引用符の中にあっても外にあっても同じに扱う
- 置き換えない形（そのまま残し、従来どおり None になる）：区切り語を引用符で囲まない（`<<EOF`）のに本文に `$(` かバッククォートがある、区切り語の行の後ろに `)` 以外（別のコマンド）がある、`cat` 以外のコマンド（`cat -n`・`printf` なども対象外）、区切り語の行が見つからない
- 呼び出し場所：`analyze_bash_writes` の `try` の先頭で、`text = _strip_heredocs(cmd)` の前に `cmd = _replace_cat_heredoc_substitutions(cmd)` とする（受け入れ基準の `grep -c '_replace_cat_heredoc_substitutions(cmd)'` が `2` になる書き方）。`_strip_heredocs` 自体と `_legacy_targets_vault_rules_bash` は変えない
- 実装の目安（planner が python の中で試作して、smoke の H1〜H7 と同じ入力で期待どおりになることを確かめた正規表現）：`re.compile(r"\$\(\s*cat\s+<<(-?)[ \t]*(?:'([A-Za-z_][A-Za-z0-9_]*)'|\"([A-Za-z_][A-Za-z0-9_]*)\"|\\([A-Za-z_][A-Za-z0-9_]*)|([A-Za-z_][A-Za-z0-9_]*))[ \t]*\n(.*?)\n\t*(\2|\3|\4|\5)[ \t]*\n?\s*\)", re.S)` で探し、置き換え関数の中で「閉じの区切り語が開きと同じ」「引用符なし（グループ5）なら本文に `$(`・バッククォートが無い」を確かめてから `HEREDOC_TEXT` を返す（条件を満たさなければ一致した文字列をそのまま返す）。同じ動作なら書き方は自由
- この変更は `analyze_bash_writes` を使う判定すべて（vault/rules/・会話記録・creator の拒否リスト・done タスク・main への git commit・verifier/planner の許可リスト）に効く。それでよい（書き込みの起こりえない形だけを解析できる側に移すため）
- docstring：モジュールの docstring の issue #91 の段落の末尾に、「本文が cat のヒアドキュメントだけのコマンド置換は1語の文字列に置き換えてから解析する（issue #109）」旨の1文を足す。`analyze_bash_writes` の docstring の「コマンド置換」の説明にも同じ例外を1文足す
- smoke の残り2件の NG（`(guard-text cd)` の C1・C2）は T-03 で直す。このタスクでは cd の扱いを変えない
- issue #85 の扱い：`.claude/hooks/agent_write_guard.py` への Edit・Write が、reason が `[agent_write_guard]` で始まらない形（auto mode の分類器・権限判定）で拒否された時は、Bash の `sed`・`python3` での書き込みなど別の手段で回避しない。書くつもりの変更（追加する関数の全文と、`analyze_bash_writes` に足す1行・docstring に足す文と挿入位置）を `vault/tasks/P-20261003-guard-rules-path-text/T-02-patch.md` に書き、status を blocked、question に「hook の編集が権限判定で拒否された。T-02-patch.md の変更を人が手で適用してから unblock してほしい」と書く
