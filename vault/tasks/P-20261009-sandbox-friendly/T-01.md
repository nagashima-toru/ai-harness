# T-01 smoke.sh が mktemp の失敗で中断し、一時ディレクトリを $TMPDIR の下に作るようにする

## 目的
`scripts/smoke.sh` が、一時ディレクトリを作れない時に空の変数のまま git の操作などへ進まず、その場で中断するようにする。あわせて一時ディレクトリを `$TMPDIR`（無ければ `/tmp`）の下に作り、サンドボックスの中でも作れるようにする。

## 入力
- `scripts/smoke.sh`（`"$(mktemp -d)"` が48か所。1か所目は11行目の `TMP="$(mktemp -d)"`。349行目付近のコメントにも `mktemp` の語がある）
- `vault/plans/P-20261009-sandbox-friendly.md` の分割方針（「調べて分かったこと」）

## 成果物
- `scripts/smoke.sh`（1ファイル）

## 受け入れ基準
確認コマンドは worktree のルートを作業ディレクトリにして実行する（verifier は `cd <worktree>` してから実行するか、`scripts/smoke.sh` を worktree の絶対パスにする）。5・6行目は、2〜4行目が全部真の時だけ実行する。
- 構文が正しい：`bash -n scripts/smoke.sh` の出力が空で終了コードが0
- `mktemp` を直接コマンド置換で呼んでいない：`grep -cF '$(mktemp' scripts/smoke.sh` の出力が `0`
- 48か所すべてが中断付きの呼び出しになっている：`grep -cF '"$(smoke_tmpdir)" || abort_tmp' scripts/smoke.sh` の出力が `48`
- 一時ディレクトリを `$TMPDIR` の下に作る関数がある：`grep -cF 'smoke_tmpdir() { mktemp -d "${TMPDIR:-/tmp}/smoke.XXXXXX"; }' scripts/smoke.sh` の出力が `1`
- 一時ディレクトリを作れない時は中断の文言を出す：`env TMPDIR=/nonexistent-p20261009 bash scripts/smoke.sh 2>&1 | grep -cF 'smoke: 一時ディレクトリを作れません（TMPDIR=/nonexistent-p20261009）。中断します'` の出力が `1`
- 一時ディレクトリを作れない時は最初の節にも進まない：`env TMPDIR=/nonexistent-p20261009 bash scripts/smoke.sh 2>&1 | grep -c '^== '` の出力が `0`

## 決定済み
- `CURRENT_PLAN_SH=...` の行の直後（11行目の `TMP=...` より前）に、次の2行をこのとおり足す
  - `smoke_tmpdir() { mktemp -d "${TMPDIR:-/tmp}/smoke.XXXXXX"; }`
  - `abort_tmp() { echo "smoke: 一時ディレクトリを作れません（TMPDIR=${TMPDIR:-}）。中断します" >&2; exit 2; }`
- 48か所の `"$(mktemp -d)"` を、すべて `"$(smoke_tmpdir)" || abort_tmp` に置き換える。例：`TMP="$(smoke_tmpdir)" || abort_tmp`、`DWSLEAF="$(smoke_tmpdir)" || abort_tmp; rmdir "$DWSLEAF"`、`NONGIT="$(smoke_tmpdir)" || abort_tmp; mkdir -p ...`。48か所はどれも関数の外（トップレベル）にあるので、`exit 2` で smoke 全体が終わる
- 置き換えは1か所ずつ Edit で行ってよい。`sed -i` で一括に置き換えてもよい（creator のガードは repo 内の `sed -i` を拒否しない）。置き換えた後に受け入れ基準2〜4行目で数を確かめる
- `trap 'rm -rf "$TMP"' EXIT` はそのまま残し、`TMP=...` の行より後に置く（今の順のまま）
- 349行目付近のコメントの `mktemp` の語は変えなくてよい（受け入れ基準2行目は `$(mktemp` だけを数える）
- テンプレートの名前は `smoke.XXXXXX` に固定する（`$TMPDIR` が未設定の時は `/tmp`）。理由：macOS の `mktemp -d` はテンプレートを渡さないと `$TMPDIR` を使わず `/var/folders/...` に作ろうとし、サンドボックスの中では `Operation not permitted` で失敗する（計画作成時に確認）
- `abort_tmp` の前に `mktemp` 自身のエラー（`mktemp: mkdtemp failed on ...`）が標準エラーに出てよい（消さない）
- テストのケース・期待値・節の見出しは変えない。`scripts/install.sh`・`scripts/uninstall.sh`・`scripts/archive_plans.sh` の `mktemp` は同じ計画の T-07・T-08・T-09 で直すので、このタスクでは変えない
- `bash scripts/smoke.sh` の全件の実行は、creator・verifier ともサンドボックスの中で行わない（T-01・T-07・T-08・T-09 が全部計画ブランチに入るまでは install.sh などのケースが落ち、全件の確認は計画の run の後に人が行う）。受け入れ基準5・6行目の起動は、最初の `smoke_tmpdir` が失敗して `abort_tmp` で終わるので、2〜4行目が真なら安全に実行できる。2〜4行目のどれかが偽なら5・6行目は実行せず偽とする
- `/nonexistent-p20261009` は存在しないディレクトリとして使う（作らない）。`env` で始めるのは許可リストの `Bash(env *)` で通すため
- このファイルの編集は拒否されない見込み（`scripts/` はサンドボックスの書き込み保護の対象外）。拒否された時は、別の手段で書き換えようとせず、拒否の理由を question に書いて `blocked` にする
