# T-01 agent_write_guard: verifier の Bash 書き込み制限をリポジトリ外の一時作業に限り許可する

## 目的
`.claude/hooks/agent_write_guard.py` の verifier 向け Bash 書き込み判定（`BASH_WRITE_PATTERNS` に一致するコマンドを一律拒否する現状の実装）を、対象パスが `root`（`resolve_root()` が解決するリポジトリのルート）の外であれば許可するように直す。リポジトリ内への書き込みは引き続き `vault/verdicts/` のみに制限する（GitHub Issue #27）。

## 決定済み
- スコープは Issue #27 の「直したいこと」に書かれた範囲（root 配下かどうかで判定）に限定する。`/etc/passwd` のようなシステムファイルへの書き込みまで許可してしまう点は、root 外を一律許可する以上避けられない既知のトレードオフとして受け入れる（過度に複雑な許可リスト方式にはしない）。このトレードオフはコード内コメント（判定関数の docstring）に一言残すこと。ただし受け入れ基準はこの点を要求しない（Issue のスコープ外）
- 修正対象は `main()` 末尾の verifier/planner 向け Bash 判定（現状261〜269行目、`if tool == "Bash": ... targets = re.findall(r">{1,2}...")`）のみ。`targets_vault_rules()`（改ざん防止判定）・`targets_creator_denied_paths()`（creator 拒否リスト）は対象パスがそもそも `vault/rules/`・`vault/plans/`・`vault/log/` というリポジトリ内固定パスなので変更不要（Issue のスコープ外）
- 対象パス抽出は、現状のリダイレクト（`>`/`>>`）に加えて `mkdir`/`cp`/`touch`/`rm`/`mv` の引数パスも見る。フラグ（`-` で始まるトークン）は対象パスに含めない
- 判定方針：抽出した対象パスをそれぞれ `normalize()`（または同等の絶対パス化）した上で、`root` の外（`root` 配下でない）パスは無条件に許可する。`root` 内のパスは既存どおり `allowed`（verifier なら `vault/verdicts/`）で始まるかどうかで判定する。抽出した対象パスが1つでも `root` 内で `allowed` に該当しない場合は、他に `root` 外のパスが含まれていてもコマンド全体を拒否する（部分許可はしない。全体を許可するか拒否するかの二値のまま）
- 対象パスが1つも抽出できない場合（曖昧なコマンド）は、現状の fail-closed（拒否）の挙動を維持する。安全側に倒すことを優先し、抽出ロジックの網羅性を追求しすぎない
- 既存の破壊的コマンド判定（`rm|mv|cp|git ...|sed -i|tee` を含む場合は redirect のみの許可条件を満たしていても拒否する現状のチェック）は、対象パスがすべて root 外である場合は適用しない（root 外への rm/cp はリポジトリに影響しないため）。対象パスに root 内のものが混じる場合は、既存どおりこのチェックを維持する
- テストは `scripts/smoke.sh` の既存 `expect_guard`/`run_guard` ヘルパー（126〜130行目）をそのまま使う。新規ケースは `== agent_write_guard.py ==` セクション内、既存の `gh api`/`curl` 関連ケース（145〜154行目付近）の後ろに追加してよい。一時ディレクトリ対象のテストには実際にホスト上に存在する `/tmp` 配下のパス文字列を使ってよい（過去の worktree テストのように `mktemp -d` で実ディレクトリを作る必要はない。パス文字列の判定のみを見るテストのため）
- テスト名には `root 外` または `tmp` を含める（受け入れ基準の確認コマンドが `grep` で拾えるようにするため）
- `docs/vault-spec.md` の更新は本タスクのスコープ外（挙動の修正であり、フックの判定仕様は `docs/vault-spec.md` 第12節に詳細を書いていない実装詳細のため）
- コミット・PR は `git.md`（`vault/rules/common/git.md`）どおり、作業ステップごとに小さく分ける。PR の説明・コミットメッセージに `#27` を参照させてよい
