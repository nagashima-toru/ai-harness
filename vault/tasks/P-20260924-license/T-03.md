# T-03 .claude/・vault/rules/ の外部由来コード出典確認

## 目的
`.claude/` 配下（skills・hooks・agents・settings.json）と `vault/rules/` 配下の全ファイルについて、外部由来のコード・雛形が含まれていないかを確認し、結果を記録する。含まれる場合は出典と選定ライセンスとの互換性判断を記録する。

## 入力
- `.claude/skills/`・`.claude/hooks/`・`.claude/agents/`・`.claude/settings.json` の全ファイル
- `vault/rules/` 配下の全ファイル
- T-01 で選定したライセンス種別（決定済み欄。互換性判断の基準に使う）

## 成果物
- `docs/third-party-notices.md`（新規1ファイル）

## 受け入れ基準
- `docs/third-party-notices.md` が存在する。確認コマンド: `test -f docs/third-party-notices.md && echo exists`
- `.claude` という文字列を含む行があり、`.claude/` 配下の確認結果（外部由来なし、または出典一覧）が記載されている。確認コマンド: `grep -n ".claude" docs/third-party-notices.md`
- `vault/rules` という文字列を含む行があり、`vault/rules/` 配下の確認結果が記載されている。確認コマンド: `grep -n "vault/rules" docs/third-party-notices.md`
- 外部由来のコード・雛形が見つからない場合は「該当なし」、見つかった場合は出典URL・元ライセンス名・選定ライセンスとの互換性判断が記載されている。確認コマンド: 目視で `docs/third-party-notices.md` を確認する
- `docs/third-party-notices.md` 以外のファイルを変更していない。確認コマンド: `git status --porcelain | grep -v ' vault/' | grep -v 'docs/third-party-notices.md$'` の出力が空（`vault/` 配下の進捗・log 更新は除く）

## 決定済み
- 調査対象は `.claude/skills/`・`.claude/hooks/`・`.claude/agents/`・`.claude/settings.json`・`vault/rules/` 配下の全ファイルに限る。`scripts/` や他のディレクトリは対象外
- 現時点でこのリポジトリのスクリプト・エージェント定義は独自作成と見られるが、必ず実ファイルを読んで確認すること。推測で「該当なし」と書かない
- 外部由来のコードが見つかり、選定ライセンスとの互換性が自分で判断できない場合は、自己判断で断定せず `blocked` にして question に具体的なファイルパスと出典を書くこと
