# T-03 CLAUDE.md のマーカーの外に @docs/vision.md を足す

## 目的
このリポジトリのメインセッションが `docs/vision.md` を読むように、`CLAUDE.md` のマーカーブロックの外（後ろ）に `@docs/vision.md` を1行足す。T-01・T-02 で、マーカーの外の行は導入先に配られなくなっている。

## 入力
- `CLAUDE.md`（今はマーカーブロックの4行だけ）
- `docs/vision.md`（読み込ませる正本。変えない）
- `scripts/smoke.sh` の `(mc-out)`・`(in-out)` の検査（T-01・T-02 で入った。ここで `$ROOT/CLAUDE.md` に行が入ると意味を持つ）

## 成果物
- `CLAUDE.md`（1ファイル）

## 受け入れ基準
- `grep -n '^@docs/vision\.md$' CLAUDE.md` の出力が `6:@docs/vision.md` の1行
- `grep -c '' CLAUDE.md` が `6`（マーカーブロックの4行・空行1行・`@docs/vision.md` の1行）
- `head -4 CLAUDE.md` の出力が `<!-- ai-harness:begin v1 -->`・`# AI協働ハーネス 共通ルール`・`@.claude/ai-harness.md`・`<!-- ai-harness:end -->` の4行（マーカーブロックは変えていない）
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (mc-out) '` が `5`、かつ `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (in-out) '` が `5`（リポジトリの `CLAUDE.md` に行が入った状態で、create・merge・update・既定の install・`--no-claude-md` のどれでも `@docs/vision.md` が導入先に入らない）
- `bash scripts/smoke.sh 2>&1 | grep -c '^  NG '` が `0`

## 決定済み
- 足すのは5行目の空行と6行目の `@docs/vision.md` の2行だけ。ファイルの末尾は改行で終える。マーカーブロックの中には入れない（中に入れると導入先に配られる）
- `@docs/vision.md` の行の前後に説明のコメント（`<!-- ... -->` を含む）は書かない（`BLOCK_RE` の一致や行数の基準に影響させないため）
- `.claude/ai-harness.md` には vision への参照を足さない（`.claude/ai-harness.md` は導入先に配られるため）
- vision の本文・要約はどこにも写さない（`docs/vision.md` が唯一の正本）
- smoke が通らない時に `scripts/` を直すのはこのタスクの範囲外。直す必要が出たら blocked にして question に書く
