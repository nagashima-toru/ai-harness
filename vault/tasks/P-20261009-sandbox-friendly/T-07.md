# T-07 install.sh が mktemp の失敗で中断し、一時ファイルを $TMPDIR の下に作るようにする

## 目的
`scripts/install.sh` の一時ファイルを `$TMPDIR`（無ければ `/tmp`）の下に作り、サンドボックスの中でも作れるようにする。作れない時は、中断の文言を出してその場で終わる（T-01 の `scripts/smoke.sh` と同じ方針）。これで smoke の install.sh のケースがサンドボックスの中で落ちなくなる。

## 入力
- `scripts/install.sh`（`"$(mktemp)"` が4か所：40行目の `HANDLED_LIST`・41行目の `SKIPPED_LIST`・95行目付近の `UPDATE_LIST`（`--update` の時だけ通る）・187行目付近の `MANIFEST_LIST`）
- `vault/plans/P-20261009-sandbox-friendly.md` の分割方針（「調べて分かったこと」）
- `vault/tasks/P-20261009-sandbox-friendly/T-01.md` の決定済み（同じ方針の smoke.sh の直し方。参考）

## 成果物
- `scripts/install.sh`（1ファイル）

## 受け入れ基準
確認コマンドは worktree のルートを作業ディレクトリにして実行する（verifier は `cd <worktree>` してから実行する）。5〜7行目は、2〜4行目が全部真の時だけ実行する。
- 構文が正しい：`bash -n scripts/install.sh` の出力が空で終了コードが0
- `mktemp` を直接コマンド置換で呼んでいない：`grep -cF '$(mktemp' scripts/install.sh` の出力が `0`
- 4か所すべてが中断付きの呼び出しになっている：`grep -cF '"$(install_tmpfile)" || abort_tmp' scripts/install.sh` の出力が `4`
- 一時ファイルを `$TMPDIR` の下に作る関数がある：`grep -cF 'install_tmpfile() { mktemp "${TMPDIR:-/tmp}/install.XXXXXX"; }' scripts/install.sh` の出力が `1`
- 一時ファイルを作れない時は中断の文言を出す：`env TMPDIR=/nonexistent-p20261009 bash scripts/install.sh /tmp/claude/P-20261009-sandbox-friendly-T-07/abort 2>&1 | grep -cF 'install: 一時ファイルを作れません（TMPDIR=/nonexistent-p20261009）。中断します'` の出力が `1`
- 中断した時は何も複製していない：`ls -A /tmp/claude/P-20261009-sandbox-friendly-T-07/abort` の出力が空
- 一時ファイルを作れる時は最後まで通る：`bash scripts/install.sh /tmp/claude/P-20261009-sandbox-friendly-T-07/dst 2>&1 | grep -cx 'done: /tmp/claude/P-20261009-sandbox-friendly-T-07/dst'` の出力が `1`、続けて `bash scripts/install.sh --update /tmp/claude/P-20261009-sandbox-friendly-T-07/dst 2>&1 | grep -cx 'done: /tmp/claude/P-20261009-sandbox-friendly-T-07/dst'` の出力も `1`

## 決定済み
- `MANIFEST_FILE="$DST/.claude/harness-manifest.json"` の行の直後（40行目の `HANDLED_LIST=...` より前）に、次の2行をこのとおり足す
  - `install_tmpfile() { mktemp "${TMPDIR:-/tmp}/install.XXXXXX"; }`
  - `abort_tmp() { echo "install: 一時ファイルを作れません（TMPDIR=${TMPDIR:-}）。中断します" >&2; exit 2; }`
- 4か所の `"$(mktemp)"` を、すべて `"$(install_tmpfile)" || abort_tmp` に置き換える。例：`HANDLED_LIST="$(install_tmpfile)" || abort_tmp   # --update で処理済みの…`（行末のコメントは残す）、`UPDATE_LIST="$(install_tmpfile)" || abort_tmp`。4か所はどれも関数の外にある（`UPDATE_LIST` は `if` の中だがトップレベルのシェル）ので、`exit 2` で install.sh 全体が終わる。`set -e` は `||` の左側では効かないので、`abort_tmp` が必ず呼ばれる
- テンプレートの名前は `install.XXXXXX` に固定する（`$TMPDIR` が未設定の時は `/tmp`）。理由：macOS の `mktemp` はテンプレートを渡さないと `$TMPDIR` を使わず `/var/folders/...` に作ろうとし、サンドボックスの中では `Operation not permitted` で失敗する（計画作成時に確認）
- `trap 'rm -f "$HANDLED_LIST" "$SKIPPED_LIST"' EXIT` はそのまま残す。`UPDATE_LIST`・`MANIFEST_LIST` を trap で消さないのは今までどおりで、このタスクでは直さない
- `mkdir -p "$DST"`（37行目付近）が一時ファイルより前にあるのは変えない（受け入れ基準6行目は、中断した時に `abort` のディレクトリが空のまま残ることを見る）
- `abort_tmp` の前に `mktemp` 自身のエラー（`mktemp: mkstemp failed on ...`）が標準エラーに出てよい（消さない）
- 複製の中身・出力の文言・引数の扱いは変えない。`scripts/smoke.sh`（T-01）・`scripts/uninstall.sh`（T-08）・`scripts/archive_plans.sh`（T-09）は変えない
- 受け入れ基準の確認先は `/tmp/claude/P-20261009-sandbox-friendly-T-07/abort` と `/tmp/claude/P-20261009-sandbox-friendly-T-07/dst` の固定パス（install.sh が `mkdir -p` で作るので、前もって作らなくてよい）。`abort` には5行目の中断の起動だけを使い、7行目の起動を向けない。ここに作ったファイルは消さない（人にも消させない）。2回目以降の起動で `skip  (exists)` の行が出ても、最後の `done:` の行は出る
- `/nonexistent-p20261009` は存在しないディレクトリとして使う（作らない）。`env` で始めるのは許可リストの `Bash(env *)` で通すため
- install.sh は `<target-dir>` の下にだけ書くので、受け入れ基準5〜7行目の起動はサンドボックスの中で実行してよい。`bash scripts/smoke.sh` の全件の実行は、creator・verifier ともサンドボックスの中で行わない（全件は計画の run の後に人が確かめる）。2〜4行目のどれかが偽なら5〜7行目は実行せず偽とする
- このファイルの編集は拒否されない見込み（`scripts/` はサンドボックスの書き込み保護の対象外）。拒否された時は、別の手段で書き換えようとせず、拒否の理由を question に書いて `blocked` にする
