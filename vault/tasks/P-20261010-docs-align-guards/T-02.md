# T-02 vault-spec.md の unblock の記述・vault/rules と差分ゲート・やめた判定の書き方を揃える

## 目的
`docs/vault-spec.md` に残る、守りを絞る前の記述（2節の「フックが会話記録で裏付ける」、12節の「会話記録で確認する判定」）を直し、11節に `vault/rules/` と差分ゲートの関係を書く。

## 入力
- `vault/designs/D-015.md`（冒頭の「決定事項」表と「フェーズ5」節の決定済み）
- `docs/vault-spec.md`（直す対象。2節・5節・11節・12節）
- 実際の状態の正本：`.claude/hooks/plan_guard.py`（unblock の裏付けの検査が無い）・`.claude/skills/plan/SKILL.md`（B 節）・`scripts/diff_gate.py`（`FORBIDDEN_PREFIXES`）

## 成果物
- `docs/vault-spec.md`（1ファイル）

## 受け入れ基準
- 「会話記録で」の記述が残っていない。確認：`grep -n '会話記録で' docs/vault-spec.md` が何も出力しない
- 2節の遷移の説明が、フックでは確かめないことを書いている。確認：`sed -n '/^## 2\./,/^## 3\./p' docs/vault-spec.md | grep -c 'フックでは確かめない'` が `1`
- 11節が、`vault/rules/` を creator のタスクの成果物にできない理由として差分ゲートを書いている。確認：`sed -n '/^## 11\./,/^## 12\./p' docs/vault-spec.md | grep -c 'scripts/diff_gate.py'` が1以上
- 12節の「やめた判定」は6項目のままで、blocked の解除の項目が残っている。確認：`sed -n '/^## 12\./,/^### worktree/p' docs/vault-spec.md | grep -c '^- '` が `6`、`sed -n '/^## 12\./,/^### worktree/p' docs/vault-spec.md | grep -c '^- blocked の解除の裏付け'` が `1`
- 古い語が残っていない。確認：`grep -n 'plan approve\|excludedCommands\|提案ファイル' docs/vault-spec.md` が何も出力しない
- `bash scripts/smoke.sh 2>&1 | tail -1` が `fail=0` を含む（主な文書の参照切れの検査を含む）

## 決定済み
- 2節の44行目は次の文にする：`遷移：`todo→doing→review→(done | doing[attempt+1] | blocked)`。`blocked→todo` は、人が `/plan unblock <計画ID> <id> [回答]` で指示した時だけ行う。フックでは確かめない（D-015 フェーズ2 で廃止）ので、エージェントは人の指示なしに解除しない。` 「フックでは確かめない」はこの1か所だけに書く（2節の中で1回）
- 12節の「やめた判定」の最後の項目は、次の形に直す（項目の頭の `- blocked の解除の裏付け` は残す）：`- blocked の解除の裏付け（人の発言に `/plan unblock` があるかをフックで見る判定）：会話の記録の形式への依存と誤拒否の費用が、エージェントの独断を防ぐ効果より大きい` 。ほかの5項目は今の文のまま（古い語4つを使っていないことは確認済み）
- 11節の冒頭の段落の「エージェントも `vault/rules/` に書き込める（フックは止めない）。ルールの変更は PR の差分で人が見る（D-015）。」の後に、次の趣旨の1〜2文を足す：ただし creator のタスクの成果物にはできない（差分ゲート `scripts/diff_gate.py` が `vault/rules/` 配下の変更を宣言があっても違反にする。5節）。ルールの追加・変更はタスクにせず、人が編集する（自分で、またはタスクの外でエージェントに指示して）
- 5節の差分ゲートの説明（`vault/rules/` を違反にする行を含む）は実際の状態と合っているので変えない
- 12節の「### サンドボックス（使っていない）」は今の記述のまま変えない（フェーズ1 で直してある）
- 7節の `D-015 フェーズ2 より前の承認の行（補足が `人の指示:` で始まるもの）は書き換えない` は変えない
- 古い語（`/plan approve`・`excludedCommands`・`提案ファイル`・`会話記録で確認`）は、「廃止した」という説明でも書かない
- バッククォートで囲むパス（`vault/`・`scripts/`・`docs/`・`.claude/` で始まるもの）は実在するものだけにする（smoke の参照切れの検査が見る）
