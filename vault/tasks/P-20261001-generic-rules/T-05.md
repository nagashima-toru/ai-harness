# T-05 settings.json の allow から npm・npx・pytest・make を外す

## 目的
配布する `.claude/settings.json` の `permissions.allow` から、特定の言語・ビルドツールに依存するエントリ（`npm test*`・`npm run *`・`npx *`・`pytest *`・`make *`）を外し、ハーネスの仕組みに必要な許可だけにする（D-010 フェーズ10、#80）。

## 入力
- `.claude/settings.json`（現行の allow は51件、deny は18件）
- `scripts/merge_settings_json.py`（既存の導入先の allow を変更しないことの確認用。読むだけ）
- `vault/designs/D-010.md` のフェーズ10

## 成果物
- `.claude/settings.json`（`permissions.allow` から5件を削除）

## 受け入れ基準
- allow に `npm`・`npx`・`pytest`・`make` で始まるエントリが無い（`jq -r '.permissions.allow[] | select(test("^Bash\\((npm|npx|pytest|make)"))' .claude/settings.json` が何も出力しない）
- allow が51件から5件減って46件である（`jq '.permissions.allow | length' .claude/settings.json` が `46`）
- deny は変わっていない（`jq '.permissions.deny | length' .claude/settings.json` が `18`）
- トップレベルのキー構成が変わっていない（`jq -r 'keys | join(",")' .claude/settings.json` が `hooks,permissions,worktree`）
- ハーネスが使う許可が残っている（`jq -e '.permissions.allow | index("Bash(bash scripts/*)") != null' .claude/settings.json` と `jq -e '.permissions.allow | index("Bash(python3 *)") != null' .claude/settings.json` がどちらも `true`）

## 決定済み
- 削除するのは `Bash(npm test*)`・`Bash(npm run *)`・`Bash(npx *)`・`Bash(pytest *)`・`Bash(make *)` の5件だけ。他のエントリの順序・文言は変えない。インデントなど JSON の書式も既存に合わせる
- `Bash(python3 *)`・`Bash(python *)`・`Bash(bash *)`・`Bash(sh *)` は残す（ハーネスのスクリプト実行に使う）
- 既存の導入先の allow は `merge_settings_json.py` が変更しないので、allow から外しても導入先に影響しない。`merge_settings_json.py`・`install.sh` は変更しない
- README・docs に allow の一覧を書いている箇所は無い（`npm` で検索してヒットしない）ので、ドキュメントの追随は不要
- `docs/decisions.md` は変更しない
- smoke.sh はこのタスクの基準に含めない（T-06 で流す）
