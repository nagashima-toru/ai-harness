# T-03 install.md のサンドボックスの節の古い理由と人の仕事を揃える

## 目的
`docs/install.md` の「サンドボックスを有効にする（任意）」の節に残る、守りを絞る前の理由（フックの Bash の解析の抜け道を塞ぐ・`vault/rules/` と会話記録を守る）と、末尾の人の仕事（「計画を承認する」）を、D-015 の後の実際の状態に揃える。

## 入力
- `vault/designs/D-015.md`（冒頭の「決定事項」表。サンドボックスの行）
- `docs/install.md`（直す対象。「## サンドボックスを有効にする（任意）」と「## インストール後の次の一歩」）
- `docs/vault-spec.md` 12節の「### サンドボックス（使っていない）」（理由の正本）
- `.claude/hooks/agent_write_guard.py`（Bash の書き込み解析が無いこと）

## 成果物
- `docs/install.md`（1ファイル）

## 受け入れ基準
- フックの Bash の解析・`denyWrite`・承認の裏付け・計画の承認の記述が残っていない。確認：`grep -n 'Bash の解析\|denyWrite\|承認の裏付け\|計画を承認する' docs/install.md` が何も出力しない
- 末尾の人が日々やることが4つに直っている。確認：`grep -c '人が日々やること（ゴールを入れる・blocked に答える・PR をマージする・月次で片づける）' docs/install.md` が `1`
- サンドボックスの節の見出しと、ハーネス自身を変える作業に向かない旨が残っている。確認：`grep -c '^## サンドボックスを有効にする（任意）$' docs/install.md` が `1`、``grep -c 'ハーネス自身（`.claude/`）を変える作業には向かない' docs/install.md`` が `1`
- 古い語が残っていない。確認：`grep -n 'plan approve\|excludedCommands\|提案ファイル\|会話記録で確認' docs/install.md` が何も出力しない
- `bash scripts/smoke.sh 2>&1 | tail -1` が `fail=0` を含む（主な文書の参照切れの検査を含む）

## 決定済み
- 節の最初の段落（157行目）は次の趣旨に直す：Claude Code のサンドボックスは、Bash とその子プロセスの書き込み先と通信先を OS で制限する。ハーネスは使わなくても同じに動き、ハーネス本体（ai-harness）では使っていない（理由は `docs/vault-spec.md` 12節の「サンドボックス（使っていない）」）。導入先で、Bash の書き込みと通信を OS で絞りたい時に使う任意の追加の守り。「フックの Bash の解析」「`vault/rules/` への書き込みを塞ぐ」は書かない
- 159行目の「（フック・`permissions`・`agent_write_guard.py` は変わらない）」は残してよい
- 設定例の JSON から `"filesystem": { "denyWrite": [...] }` のブロックを消す（守る対象だった `vault/rules/` と会話記録は D-015 で守る対象から外した）。`enabled`・`allowUnsandboxedCommands`・`network.allowedDomains` は残す。JSON として正しい形（カンマの位置）を保つ
- 185行目（`denyWrite` の説明の箇条書き）は消す。186・187行目（`allowedDomains` と Anthropic の API のドメイン）は残す
- 195行目の「その時はフックの Bash の解析だけが守りになる」は「その時はフックと `permissions` だけが守りになる」に直す
- 191行目（ハーネス自身（`.claude/`）を変える作業には向かない）は文言を変えない（受け入れ基準3が見る）
- 224行目は次の文にする：`人が日々やること（ゴールを入れる・blocked に答える・PR をマージする・月次で片づける）は `docs/runbook.md` にまとまっている。`
- サンドボックスの節以外（インストール・更新・アンインストールの手順）は変えない
- 古い語（`/plan approve`・`excludedCommands`・`提案ファイル`・`会話記録で確認`）は、「廃止した」という説明でも書かない
- バッククォートで囲むパス（`vault/`・`scripts/`・`docs/`・`.claude/` で始まるもの）は実在するものだけにする（smoke の参照切れの検査が見る）
