# T-03 run/SKILL.md の creator の呼び出しで HARNESS_CREATOR_MODEL を Agent ツールの model に渡す

## 目的
`.claude/skills/run/SKILL.md` の手順3（creator の呼び出し）に、環境変数 `HARNESS_CREATOR_MODEL` があれば Agent ツールの `model` にその値を渡すことと、その値の確かめ方を書く。手順0.5の `creator=` の値の説明を、T-01 で変えた transition.py の動き（環境変数を優先）に合わせる。

## 入力
- `vault/designs/D-013.md` の「フェーズ3 creator のモデルの切り替えと計測」（ゴール文1・受け入れ基準の候補の4行目・決定済み）
- `.claude/skills/run/SKILL.md`（手順0.5「実行モデルの記録」・手順3「作る」の2・手順5「検証する」）
- `scripts/transition.py`（T-01 で入った `HARNESS_CREATOR_MODEL` の扱いと docstring）

## 成果物
- `.claude/skills/run/SKILL.md`（1ファイル）

## 受け入れ基準
- 手順3に、値の確かめ方として `echo "${HARNESS_CREATOR_MODEL:-}"` の行がある：`grep -cF 'echo "${HARNESS_CREATOR_MODEL:-}"' .claude/skills/run/SKILL.md` の出力が1以上
- 手順3に、出力が空でなければ creator を呼ぶ Agent ツールの `model` にその値を渡し、空なら `model` を指定しない（`.claude/agents/creator.md` の frontmatter の値になる）ことが書かれている（Read で確認）
- 手順3に、値の検査はせず、Agent ツールがその値を受け付けずに呼び出しが失敗した時は、そのタスクの処理を止めて人に報告する（状態は変えない）ことが書かれている（Read で確認）
- 手順0.5に、`creator=` の値は `HARNESS_CREATOR_MODEL` を優先し、無ければ frontmatter の `model` であることと、verifier の呼び出し（手順5）と `verifier=` は環境変数の影響を受けないことが書かれている（Read で確認）
- 既存の smoke が全件通る（`(ms-3)` の `creator=`・`verifier=` の記述の確認を含む）：`bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` を含む

## 決定済み
- 確かめ方は `echo "${HARNESS_CREATOR_MODEL:-}"`（許可リストの `Bash(echo *)` で通る。設計の決定済み）。手順3の1（`PLAN_HEAD` を控える所）の近くで、選んだタスク全部について1回だけ実行する形にする。この行は SKILL.md に文字どおり書く（受け入れ基準1で grep する）
- 値は transition.py と同じく、空文字は未設定と同じ扱い（`model` を指定しない）
- 渡すのは creator の呼び出しだけ。手順5の verifier の呼び出しには渡さない（verifier・planner のモデルは変えない。設計の決定済み）。差し戻し・FAIL の再試行・ハング時の復旧で creator を呼び直す時も手順3を通るので同じ値が渡る（手順3に書けば足り、他の節に重ねて書かなくてよい）
- 呼び出しが失敗した時に止めるのは、手順3の creator の呼び出しが Agent ツールのエラーで返った場合（モデル名が受け付けられない等）。この時は transition.py を呼ばず、エラーの内容と `HARNESS_CREATOR_MODEL` の値を人に報告して止まる。doing のまま残るので、次の `/run` の再開手順（手順2.2）で扱われる
- 手順0.5は「値は `.claude/agents/creator.md`・`.claude/agents/verifier.md` の frontmatter の `model` から transition.py が読む」の部分を、creator は `HARNESS_CREATOR_MODEL` を優先する形に直す。書式の正本が `docs/vault-spec.md` 7節である旨はそのまま残す（7節の更新は T-04）
- `creator=`・`verifier=` の語は手順0.5に残す（smoke の `(ms-3)` が確かめている）
- 手順2・4・6・7・8 とハング時の復旧の節は変えない。`.claude/agents/`・`docs/`・`scripts/` は変えない
