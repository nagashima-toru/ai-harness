# T-01 .claude/hooks/_hooklib.py を新設し3フックに複製されている10関数を置く

## 目的
3フックに中身が同じまま複製されている10関数を、共通モジュール `.claude/hooks/_hooklib.py` に1つずつ置く。フック側の置き換えは T-02〜T-04 で行う。このタスクでは移し先を用意するだけにする。

## 入力
- `vault/designs/D-011.md`（決定事項の表・フェーズ1）
- `.claude/hooks/plan_guard.py`（10関数すべての複製元：`existing_ancestor`・`git_toplevel`・`delegate_to_worktree`・`plan_id_and_status`・`approved_plans`・`raw_rows`・`frontmatter_status`・`human_messages`・`is_approve_command`・`is_unblock_command`）
- `.claude/hooks/agent_write_guard.py`・`.claude/hooks/stop_gate.py`（同じ関数の複製。照合用）

## 成果物
- `.claude/hooks/_hooklib.py`（新規1ファイル）

## 受け入れ基準
- 構文が正しい：`python3 -B -c "import ast; ast.parse(open('.claude/hooks/_hooklib.py').read()); print('ok')"` の出力が `ok`
- 10関数がちょうど1回ずつ定義されている：`grep -cE '^def (existing_ancestor|git_toplevel|delegate_to_worktree|plan_id_and_status|approved_plans|raw_rows|frontmatter_status|human_messages|is_approve_command|is_unblock_command)\(' .claude/hooks/_hooklib.py` の出力が `10`
- 関数が元と同じに動く：`python3 -B -c "import sys; sys.path.insert(0, '.claude/hooks'); import _hooklib as H; print(H.plan_id_and_status('vault/plans/P-20261004-hooklib-extract.md'), [p for p, _ in H.approved_plans('.')], H.frontmatter_status('---\nstatus: \"approved\"\n---\n'), H.is_approve_command('/plan approve P-X', 'P-X'), H.is_unblock_command('/plan unblock P-X T-01 回答', 'P-X', 'T-01'), H.raw_rows('## タスク表\n| id | status |\n|---|---|\n| T-01 | todo |\n'), H.human_messages(None))"` の出力が `('P-20261004-hooklib-extract', 'approved') ['P-20261004-hooklib-extract'] approved True True [['T-01', 'todo']] []`
- 存在しないディレクトリからでも git のルートを返す：`python3 -B -c "import sys; sys.path.insert(0, '.claude/hooks'); import _hooklib as H; print(H.git_toplevel('no/such/dir') == H.git_toplevel('.'), H.git_toplevel('.') is not None)"` の出力が `True True`
- `delegate_to_worktree` が委譲先のスクリプト名を引数で受ける：`python3 -B -c "import sys, inspect; sys.path.insert(0, '.claude/hooks'); import _hooklib as H; print(inspect.signature(H.delegate_to_worktree))"` の出力が `(payload, script_name)`
- 標準ライブラリしか import しない：`python3 -B -c "import ast; t = ast.parse(open('.claude/hooks/_hooklib.py').read()); print(sorted({(a.name if isinstance(n, ast.Import) else n.module).split('.')[0] for n in ast.walk(t) if isinstance(n, (ast.Import, ast.ImportFrom)) for a in n.names} - {'json', 'os', 're', 'subprocess', 'sys'}))"` の出力が `[]`

## 決定済み
- 関数の本体は `plan_guard.py` の版をそのまま写す（挙動を変えない）。規則のずれの統一（受け入れ基準の数え方・frontmatter の引用符・表の行頭空白など）はフェーズ2の対象なので、このタスクでは一切直さない
- `raw_rows` の名前は `raw_rows` にする（`agent_write_guard.py` の `plan_raw_rows` は T-02 で `H.raw_rows` に置き換える）
- `delegate_to_worktree(payload, script_name)`：委譲先のパスは `os.path.join(worktree_root, ".claude", "hooks", script_name)` にする。それ以外（`_HOOK_DELEGATED` による二重委譲の防止、`self_root` を `CLAUDE_PROJECT_DIR` か `git_toplevel(os.path.dirname(os.path.abspath(__file__)))` で求めること、タイムアウト20秒、非0ならフォールバックして None）は今の実装のまま変えない。`__file__` は `_hooklib.py` になるが、フックと同じディレクトリにあるので、求まる `self_root` は変わらない
- docstring
  - モジュール docstring には次の3点を書く
    - 3フックが共通で使う関数を置くこと（D-011）
    - 標準ライブラリだけを使い、import した時に副作用（標準出力への出力・ファイルの書き込み）を起こさないこと
    - フック本体ではないので settings.json に登録しないこと
  - 各関数の docstring からは「コピー」「import しない」「同名関数のコピー」の注記を消す。関数の説明（何を返すか・fail-open の扱い）は残す
  - `delegate_to_worktree` の docstring は、特定のスクリプト名や D-008 のフェーズ番号に依存しない書き方にする
- モジュール直下に置くのは、import 文・関数定義・docstring だけにする。`sys.path` の操作や `if __name__ == "__main__":` は書かない
- Python 3.9 で動く書き方にする（このマシンの python3 は 3.9）
- 3フック（`agent_write_guard.py`・`plan_guard.py`・`stop_gate.py`）・`scripts/smoke.sh`・docs は、このタスクでは変更しない（T-02〜T-06 で行う）
- 動作確認で `_hooklib` を import する時は `python3 -B` を使う。`.claude/hooks/__pycache__/_hooklib*` を作ったら消しておく（後続タスクの `__pycache__` 検査の邪魔になる）
- コミットは受け入れ基準に無いので、creator はしない（オーケストレーターが行う）
