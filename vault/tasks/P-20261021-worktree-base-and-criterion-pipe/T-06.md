# T-06 計画の差分が `/code-review` を通過する

## 目的
計画単位のレビュータスク。T-01〜T-05 をマージした後の計画全体の差分を `/code-review` で確かめ、致命的な指摘があれば直す。

## 入力
- 計画全体の差分（`git -C <worktree のパス> diff --merge-base <ベースブランチ>`）
- 各タスク票 `vault/tasks/P-20261021-worktree-base-and-criterion-pipe/T-01.md`〜`T-05.md` の受け入れ基準
- `.claude/agents/creator.md` の「コードレビューを参照する基準がある時」の節

## 成果物
- 計画の差分への修正（主な成果物）。直してよいのは先行タスクで変えた次のファイルだけ：
  - `scripts/amend_task.py`
  - `scripts/smoke.sh`
  - `scripts/add_worktree.sh`
  - `scripts/install.sh`
  - `README.md`
  - `.claude/skills/run/SKILL.md`
  - `.claude/agents/creator.md`
  - `docs/vault-spec.md`
  - `docs/decisions.md`

## 受け入れ基準
- `/code-review` で計画の差分に致命的な指摘が残っていない
- smoke 全体が通る：`bash scripts/smoke.sh 2>&1 | tail -1` の出力が `smoke: pass=<n> fail=0` の形（`<n>` は任意）
- amend_task.py の検査が通る：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (amend-task) 0[78] '` の出力が `2`
- add_worktree.sh の検査が通る：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (add-wt-[1-5]) '` の出力が `5`
- 文書のバッククォートのパスがすべて存在する：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`
- `isolation: "worktree"` の語が残る文書は run/SKILL.md だけ：`git grep -l 'isolation: .worktree.' -- .claude docs README.md` の出力が `.claude/skills/run/SKILL.md` の1行だけ

## 決定済み
- レビューの範囲は、ベースブランチ（`HARNESS_BASE_BRANCH`、前後の空白を除いて空なら `main`）との分岐点からの計画全体の差分（`git -C <worktree のパス> diff --merge-base <ベースブランチ>`）
- 計画一式4種（`vault/plans/`・`vault/tasks/`・`vault/verdicts/`・`vault/log/`）はレビューの対象にしない
- 致命的な指摘が無ければ成果物を変えず、「進捗」への記録だけでよい（「進捗」の追記が収集コミットになるので、新規コミット無しの blocked にはならない）
- 差分の外（既存コード）・致命的でない指摘・設計や仕様の変更が要る指摘の扱いは、`.claude/agents/creator.md`・`.claude/agents/verifier.md` の「コードレビューを参照する基準」の節に従う
- 修正した時は、上の確認コマンドをもう一度すべて通してから完了報告する
