# T-03 README.md から docs/guide.md へリンクする

## 目的
利用者が README から、やりたいこと別の入口 `docs/guide.md` に辿り着けるようにする。

## 入力
- `README.md` の「使い方」節の箇条書き（`docs/configuration.md` へのリンクの行）と「構成」節の表
- `docs/guide.md`（T-02 で作成済み）

## 成果物
- `README.md`（1ファイル。2行の追加だけ）

## 受け入れ基準
- 「使い方」節にリンクの行がある：`grep -cxF -- '- やりたいこと別の入口は [docs/guide.md](docs/guide.md) を参照' README.md` が `1`
- 「構成」節の表に行がある：``grep -cxF '| `docs/guide.md` | やりたいこと別の入口 |' README.md`` が `1`
- `scripts/install.sh` が guide.md を配らない：`grep -c 'guide.md' scripts/install.sh` が `0`
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` が `1`
- `bash scripts/smoke.sh 2>&1 | tail -1` が `fail=0` で終わる

## 決定済み
- 「使い方」節の `- 指定できる環境変数（`HARNESS_*`）の一覧は [docs/configuration.md](docs/configuration.md) を参照` の行の直前に、`- やりたいこと別の入口は [docs/guide.md](docs/guide.md) を参照` を1行足す（文言はこのとおり）
- 「構成」節の表の `` | `docs/configuration.md` | 環境変数リファレンス | `` の行の直前に、`` | `docs/guide.md` | やりたいこと別の入口 | `` を1行足す（文言はこのとおり）
- README のほかの行は変えない。`docs/install.md` の「インストール後の次の一歩」など README 以外からのリンクは足さない（ゴールは README からのリンクだけ）
- `scripts/install.sh` は変えない（設計文書の決定事項）
