# T-0001 ハーネスの動作確認（README の使い方節に1行追記）

## 目的
run-queue → verifier → Stop フックの一連の流れが実タスクで回ることを確認する。成果物は意図的に最小。

## 入力
- `README.md`（「## 使い方」節）
- `docs/vault-spec.md`

## 成果物
- `README.md` の「## 使い方」節（1行追記のみ）

## 受け入れ基準
- 「## 使い方」節の箇条書きに、`claude -p "/run-queue"` を cron や CI から定期実行して無人で回す旨の行が1行ある。確認：`awk '/^## 使い方/{f=1;next} /^## /{f=0} f' README.md | grep -c 'cron'` の出力が `1`
- README.md の変更は追加1行のみで、削除行は無い。確認：`git diff --numstat -- README.md` の出力が `1	0	README.md`
- README.md 以外のファイルは変更していない（vault/ 配下を除く）。確認：`git status --porcelain | grep -v '^.. vault/' | grep -v 'README.md'` の出力が空
- `bash scripts/smoke.sh` が通る。確認：`bash scripts/smoke.sh | tail -1` に `fail=0` が含まれる

## 決定済み
- 追記する行はこの文言をそのまま使う：`- 無人で回す場合は \`claude -p "/run-queue"\` を cron や CI から定期実行する`
- 追記位置は「## 使い方」節の末尾（既存の箇条書きの直後、次の見出しの前）
- git commit はしない（人が確認してからコミットする）
- 表や他の節は触らない
