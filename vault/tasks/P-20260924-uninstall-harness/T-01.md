# T-01 scripts/unmerge_claude_md.py を作る（CLAUDE.md からマーカーブロックのみ除去）

## 目的
`scripts/merge_claude_md.py` の逆処理として、CLAUDE.md からハーネスのマーカーブロックだけを取り除くスクリプトを作る。アンインストール時に既存の本文を残したまま、追記した4行ブロックだけを消せるようにする。

## 入力
- `/home/user/ai-harness/scripts/merge_claude_md.py`（対になる正処理。`BLOCK_RE`・バックアップの作り方・メッセージ文言の流儀をそろえる）
- マーカー文字列の実例：`CLAUDE.md`（`<!-- ai-harness:begin v1 -->` 〜 `<!-- ai-harness:end -->`）

## 成果物
- `scripts/unmerge_claude_md.py`（新規ファイル1つ）

## 受け入れ基準
- 引数無しで実行すると usage を stderr に出し exit 2 する。確認：`python3 scripts/unmerge_claude_md.py; echo $?` の標準エラーに `usage` を含み、終了コードが `2`
- マーカーブロックのみを持つ CLAUDE.md（ブロックの前後に他の本文が無い）に対して実行すると、ファイルごと削除され `delete <path>` と出力する。確認：一時ファイルに `merge_claude_md.py` が書くブロックのみを書き込み実行し、`[ ! -e <path> ]` が真になること
- マーカーブロック＋他の本文を持つ CLAUDE.md に対しては、ブロックだけを除去し他の本文を残して `remove <path>` と出力する。確認：一時ファイルに他の本文＋ブロックを書いて実行し、実行後の内容に `ai-harness:begin` が含まれず、他の本文の行がそのまま残っていること
- マーカーブロックが無い CLAUDE.md（またはファイルが存在しない）は変更せず `skip <path>` と出力する。確認：ブロックの無い一時ファイルで実行前後の内容が一致すること（`diff`）
- ブロックを除去・ファイルを削除する時だけ `<path>.bak-<YYYYMMDDHHMMSS>` のバックアップを残す（`merge_claude_md.py` と同じ命名規則）。確認：バックアップファイルの存在と、その中身が実行前の内容と一致すること
- マーカー検出の正規表現は `merge_claude_md.py` の `BLOCK_RE`（`<!-- ai-harness:begin.*?<!-- ai-harness:end -->` を `re.DOTALL` で検出）と同じパターンにする。確認：`grep -n 'ai-harness:begin.*ai-harness:end' scripts/unmerge_claude_md.py`

## 決定済み
- コマンド名・引数順は `python3 scripts/unmerge_claude_md.py <target_claude_md>`（`merge_claude_md.py` が `<src> <dst>` の2引数なのに対し、こちらは除去対象の1引数だけでよい。除去元の内容を別途用意する必要は無い）
- 出力文言は `create`/`update`/`merge`/`skip` に対称させて `delete`/`remove`/`skip` の3種類とする（除去後に本文が空文字列またはブロック除去後の残りが空白のみなら `delete` でファイル自体を消す。残りがあれば `remove`。ブロックが無ければ `skip`）
- 「本文が空文字列またはブロック除去後の残りが空白のみ」の判定は `str.strip() == ""` でよい
- バックアップは `delete`・`remove` の時だけ作る（`skip` の時は作らない）。ファイル名の日時は `merge_claude_md.py` と同じ `datetime.now().strftime('%Y%m%d%H%M%S')`
- 実装は `merge_claude_md.py` を import せず、独立したファイルとして自己完結させてよい（`install.sh` の配布対象リストに1ファイルとして加えるだけで済むようにするため）
