# T-01 amend_task.py の --replace-criterion が基準の文の縦棒をそのまま残す

## 目的
Issue #220。`scripts/amend_task.py --replace-criterion` で差し替えた受け入れ基準の文の `|` が全角 `／` に変わらないようにし、smoke で確かめる。

## 入力
- `scripts/amend_task.py`（216行付近の `transition.clean_text(text)`、78行の `--note` の `clean_text`、冒頭の docstring）
- `scripts/transition.py` の `clean_text`（179行付近。`|` を `／` に、改行を空白にして前後の空白を除く）
- `scripts/smoke.sh` の `# amend_task.py（タスク票の成果物の追加・受け入れ基準の差し替えと log の記録）` の節（`am_run`・`am_task`・`tw_setup` と `(amend-task) 01`〜`06`）

## 成果物
- `scripts/amend_task.py`（主な成果物。基準の文の整形）
- `scripts/smoke.sh`（`(amend-task) 07`・`08` の検査を足す）

## 受け入れ基準
- smoke に足した2件の検査が通る：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (amend-task) 0[78] '` の出力が `2`
- smoke 全体が通る：`bash scripts/smoke.sh 2>&1 | tail -1` の出力が `smoke: pass=<n> fail=0` の形（`<n>` は任意）
- 基準の文に `clean_text` を通していない：`grep -c 'clean_text(text)' scripts/amend_task.py` の出力が `0`
- `--note` は今までどおり `clean_text` を通す：`grep -c 'transition.clean_text(args.note)' scripts/amend_task.py` の出力が `1`
- docstring に基準の文の扱いを書いている：`grep -c 'の改行は空白に置き換え、... は置き換えない' scripts/amend_task.py` の出力が `1`

## 決定済み
- 基準の文の整形：改行（`\r\n`・`\r`・`\n`）だけを空白1つに置き換え、前後の空白を除く（`clean_text` から `|` の置き換えだけを外した動き）。`|` も `／` もそのまま書く。関数を amend_task.py の中に作るか式で書くかは任せる。`transition.py` の `clean_text` は変えない（計画票の表のセル・log の1行に使うため）
- `--note` は log の1行に入るので、今の `transition.clean_text(args.note)` のまま変えない（78行の式の文字列を変えない）
- docstring の「2. --replace-criterion:」の項に、次の文言をこのまま足す（`|` はバッククォートで囲む）：「<文> の改行は空白に置き換え、`|` は置き換えない」。括弧で囲んで既存の文の後ろに足してよい
- smoke の検査は `(amend-task) 06` の直後（`# --- 主な文書の参照切れの検査 ---` の前）に足す。ラベルと説明はこのとおり：
  - `(amend-task) 07 --replace-criterion の文の | がそのまま残る`：`tw_setup blocked 1` の後、`am_run P-TEST T-01 --replace-criterion 1 'a | b'` が終了コード0で、タスク票の受け入れ基準の1行目が `- a | b` になる（`／` を含まない）
  - `(amend-task) 08 --replace-criterion の文の改行は空白1つになり基準の行数が変わらない`：改行を含む文（例：`$'p\nq'`）で差し替えると1行目が `- p q` になり、受け入れ基準の行数が差し替え前と同じ
  - 書き方は既存の `expect_eq` と `am_run`・`am_task` を使う。一時ディレクトリは既存の `tw_setup` に任せる
- docs/vault-spec.md の amend_task.py の説明（2節）は「`- <文>` の1行に置き換え」のままで食い違わないので、このタスクでは変えない
