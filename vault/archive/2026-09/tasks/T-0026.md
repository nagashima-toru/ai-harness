# T-0026 README.md のセットアップ節と docs/runbook.md に docs/install.md への導線を追加する

## 目的
README の「セットアップ」節に残っていた1本化前の組み込み手順を整理し、2ユースケースの詳細を `docs/install.md` に一本化する導線を README と runbook の両方に作る。

## 入力
- `README.md`（現行の「セットアップ」節、「構成」節）
- `docs/runbook.md`（現行冒頭）
- `docs/install.md`（T-0025 まで完成した状態）

## 成果物
- `README.md` の「セットアップ」節・「構成」節
- `docs/runbook.md` の冒頭
（1つの導線変更としてまとめて更新する。T-0013 が README と runbook をまとめて更新した前例に倣う）

## 受け入れ基準
- README.md が `docs/install.md` を参照している。確認コマンド: `grep -c 'docs/install.md' README.md`（結果が1以上）
- README.md のセットアップ節から旧い組み込み手順の行が消えている。確認コマンド: `grep -c 'bash scripts/install.sh /path/to/your-project' README.md`（結果が0）
- docs/runbook.md の冒頭が `docs/install.md` を参照している。確認コマンド: `grep -c 'docs/install.md' docs/runbook.md`（結果が1以上）
- docs/runbook.md の既存見出し `## 0. 大きなゴールは先に設計する` がそのまま残っている（番号・文言を変えない）。確認コマンド: `grep -c '^## 0\. 大きなゴールは先に設計する' docs/runbook.md`（結果が1）
- README.md の「構成」節に `install.md` の記載が追加されている（セットアップ節の参照と合わせて2箇所以上になる）。確認コマンド: `grep -c 'install.md' README.md`（結果が2以上）

## 決定済み
- README の「セットアップ」節は次のように変える：
  - 「このリポジトリ自体を試す」用の2行（`git clone ... && cd ai-harness`、`bash scripts/smoke.sh`）はそのまま残す
  - 他プロジェクトへの組み込み手順（`bash scripts/install.sh /path/to/your-project` の行と、その後の note・trust の行）は削除する
  - 代わりに「他のプロジェクトへ組み込む場合（まっさらな新規ディレクトリ／既存リポジトリのどちらか）は `docs/install.md` を参照」という1文を追加する
- README の「構成」節にある `docs/` の説明行（`vault-spec.md（仕様の正本）、runbook.md、decisions.md`）に `install.md` を追加する
- docs/runbook.md の冒頭（`# Runbook（人が日々やること）` の直後、`## 0. 大きなゴールは先に設計する` より前）に、「まだインストールしていない場合は先に `docs/install.md` を読む」という趣旨の1行を追加する。既存の見出し番号・文言は変えない
- `docs/install.md` の内部構成（パターン1/2の見出し名）自体は変更しない。本タスクはあくまで導線（参照の追加・重複削除）のみを行う
