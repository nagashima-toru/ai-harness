# T-04 verifier/planner 向け ALLOWED の Bash 判定を analyze_bash_writes に載せ替える

## 目的
verifier・planner の Bash で、書き込み動詞の語（`git add`・`rm -rf`・`->` など）を grep のパターンに含むだけの読み取りコマンドが拒否される誤検知を解消する。許可ディレクトリへの `mkdir -p` が拒否される誤検知も同様（issue #91、#85 の後半）。`main()` の ALLOWED 判定の Bash 分岐を `analyze_bash_writes` の結果で判定する。git 操作・削除・許可外への書き込みは引き続き拒否する。

## 入力

- `scripts/smoke.sh`：既存の verifier/planner の Bash ケース（`verifier が Bash で git commit → 拒否`、`(issue #54 placeholder)` の6件など）

## 決定済み
- **判定**（`agent` が `ALLOWED` にある時の Bash だけ。Write 系の分岐は変えない）：
  - `analyze_bash_writes(cmd)` が None なら、現行の判定（`BASH_WRITE_PATTERNS`・root 外許可・許可ディレクトリへのリダイレクトのみ許可・`DESTRUCTIVE_BASH_PATTERN`）をそのまま使う
  - リストが返った時は、次の順に判定する
    1. 空リストなら許可する（読み取りだけ）
    2. verb に `git-add`・`git-commit`・`git-write` が1つでもあれば拒否する（verifier・planner は git の書き込み操作をしない。現行と同じ）
    3. 全 target が root の外（`is_outside_root`）なら許可する（現行の issue #27 の挙動を引き継ぐ）
    4. root 内の target がすべて許可ディレクトリ（`ALLOWED[agent]` の前方一致）にあり、かつ root 内の target の verb がすべて `redirect`・`mkdir`・`touch` なら許可する
    5. それ以外は拒否する。`rm`・`mv`・`cp`・`tee`・`sed-i`・`chmod`・`chown` は、許可ディレクトリ内でも従来どおり拒否側に倒す
  - 拒否時の reason は現行の文言（`{agent} の Bash では書き込み・破壊的操作を行えません（... へのリダイレクトのみ可）`）を変えない
- `analyze_bash_writes` 自体と他の判定（`targets_vault_rules`・`targets_transcript_dir`・`targets_creator_denied_paths`・`find_done_task_write`・main 直接コミット拒否）は変えない（main 直接コミット拒否は T-07 で行う）。`analyze_bash_writes` を変える必要が出たら `blocked` にして question に書く
- 対象外：`awk -F: '$1>430'` のような awk の比較演算子は、awk が解析不能の集合に入るため従来判定のまま（拒否）。awk のスクリプトは `print > "file"` で書き込めるので、ここは緩めない
- **smoke に足すケース**：既存の `(issue #54 placeholder)` の最後のケース（`verifier が <n> を含む git commit → 破壊的操作として拒否`）の直後に置く
  - 名前は `(bash-parse-allowed) <説明> → 許可` / `(bash-parse-allowed) <説明> → 拒否` の形にする
  - `run_guard` を使い、その位置で有効な `expect_guard` を使う（2引数版でも4引数版でもよい）
  - パスは root 相対。`vault/verdicts/P-X/...` は計画票が無いので done 判定に当たらない
  - 許可（4件。いずれも現行コードでは拒否されることを planner が確認済み）：
    1. verifier：`grep -n "git add" .claude/skills/run/SKILL.md`
    2. verifier：`mkdir -p vault/verdicts/P-X`
    3. planner：`grep -n "rm -rf" docs/vault-spec.md`
    4. planner：`grep -n "doing->review" docs/vault-spec.md`
  - 拒否（9件。現行でも拒否される）：
    1. verifier：`git add vault/verdicts/P-X/T-01.json`
    2. verifier：`rm vault/verdicts/P-X/T-01.json`
    3. verifier：`echo x > README.md`
    4. verifier：`cp /tmp/a vault/verdicts/P-X/T-01.json`
    5. verifier：`tee vault/verdicts/P-X/T-01.json`
    6. verifier：`bash -c "echo x > README.md"`（インタプリタ：従来判定）
    7. verifier：`echo "$(git commit -m x)"`（コマンド置換：従来判定）
