# T-04 vault-spec の archive の説明を配置とスクリプトに合わせる

## 目的
仕様の正本 `docs/vault-spec.md` の archive の説明（1節の表の行と、7節の model_stats の集計対象）を、種別ごとのサブディレクトリの配置と `scripts/archive_plans.sh`（新しい `--keep` 件を残して古い計画を移す）に合わせ、移した後はフックの done 判定の対象外になることを明記する。

## 入力
- `docs/vault-spec.md` 1節の表（15行目 `vault/archive/` の行）、7節の model_stats の段落（140行目付近）、12節の done 判定の行
- `scripts/archive_plans.sh`（T-01 の成果物）と T-01 タスク票の「決定済み」（候補の条件・「新しい」の基準）
- 計画票 `vault/plans/P-20261003-archive-old-logs.md` の「ゴール」（人の回答）と「分割方針」

## 成果物
- `docs/vault-spec.md`（1節の表の1行と、その直後の段落、7節の1段落を書き換える。1ファイル）

## 受け入れ基準
- 1節の旧い説明が残っていない：`grep -c 'done になった計画一式を月次でまとめる先' docs/vault-spec.md` の出力が `0`
- 1節に配置を書いている：`grep -c 'vault/archive/<年-月>/{plans,tasks,verdicts,log}/' docs/vault-spec.md` の出力が `1` 以上
- 残す件数を書いている：`grep -c '新しい順に --keep（既定5）件を残す' docs/vault-spec.md` の出力が `1` 以上
- 「新しい」の基準を書いている：`grep -c 'log の最初の日時行' docs/vault-spec.md` の出力が `1` 以上
- 7節に archive の log を明示して集計する例がある：`grep -c 'model_stats.py vault/archive/\*/log/\*.md' docs/vault-spec.md` の出力が `1` 以上
- 移した後は done 判定の対象外であることを書いている：`grep -c 'agent_write_guard.py の done 判定の対象外' docs/vault-spec.md` の出力が `1` 以上
- 見出しの数が変わらない：`grep -c '^## ' docs/vault-spec.md` の出力が `13`

## 決定済み
- 1節の表の `vault/archive/` の行を、パス列 `` `vault/archive/<年-月>/{plans,tasks,verdicts,log}/` ``、内容列「done かつ PR がマージ済みの計画一式の移動先（`vault/` と同じ種別ごとのサブディレクトリ。詳細は表の後の段落）」に置き換える。表の列数（2列）は変えない
- 1節の表の後（「計画をまたぐキューは持たない。」の段落の前でも後でもよい）に archive の段落を1つ足し、次を書く
  - 移動は人が `scripts/archive_plans.sh --apply` で行う（手順は `docs/runbook.md` 5節）。エージェントは `--list`・`--dry-run` だけを使う
  - 対象：計画票が `status: done`・タスク表が全行 `done`・`main` でも `status: done`（マージ済み）・log に日時行がある計画を候補にし、新しい順に --keep（既定5）件を残す。それより古い全部を移す。現在のブランチの計画は候補に入れず、5件に数えない
  - 「新しい」の基準：log の最初の日時行（`- YYYY-MM-DD HH:MM ` で始まる最初の行）の日時。同じなら計画 ID の文字列順で後ろのものを新しいとみなす
  - `<年-月>` は計画 ID の日付部分から決める
  - 移した後のファイルは agent_write_guard.py の done 判定の対象外（フックは `vault/tasks/`・`vault/verdicts/` だけを見る）。人の回答：`vault/archive/` 配下はいざという時の参照用で、消しても問題ない。編集のチェックは不要。1節の表の行に「参照用で、消しても運用に影響しない」の趣旨を一言添える（フック側の対応は行わない）
- 「新しい順に --keep（既定5）件を残す」「log の最初の日時行」「agent_write_guard.py の done 判定の対象外」は、この文字列のまま（バッククォートで囲まずに）書く
- 7節の model_stats の段落の「`vault/archive/` 配下の log は既定の対象に含めず、引数で明示的に渡した時だけ集計する。」の後ろに、例として `python3 scripts/model_stats.py vault/archive/*/log/*.md` を足す（log のファイル名が `<計画ID>.md` のまま残るので計画 ID が取れる旨も一言）
- 12節（agent_write_guard の判定表）は変えない。対象外であることは1節で述べるだけにする
- 他の節は変えない。`docs/runbook.md` は T-03 の成果物なので触らない
