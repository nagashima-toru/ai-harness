# T-01 smoke.sh の git worktree remove から -q を外しリダイレクトを揃える

## 目的
git 2.43 の `git worktree remove` は `-q` を受け付けず（`error: unknown switch `q'`）、smoke.sh の後片付けの worktree 削除が失敗している。`-q` を外して削除を成功させ、リダイレクトの無い1箇所のエラー出力も止める（GitHub Issue #181）。

## 入力
- `scripts/smoke.sh`（`git -C ... worktree remove -q --force ...` の10行。計画時点の行番号は 215・241・317・327・350・366・468・657・681・2006）

## 成果物
- `scripts/smoke.sh`（1ファイル）

## 受け入れ基準
- `scripts/` と `.claude/` に `worktree remove -q` が残っていない。確認：`grep -rn 'worktree remove -q' scripts .claude` の出力が空（終了コード1）
- `(stop_gate worktree)` の後の行が `git -C "$WTMAIN" worktree remove --force "$LEAF" >/dev/null 2>&1` になっている。確認：`grep -cF 'git -C "$WTMAIN" worktree remove --force "$LEAF" >/dev/null 2>&1' scripts/smoke.sh` が `1`
- smoke.sh の変更は `-q` の削除10箇所と `>/dev/null 2>&1` の追加1箇所だけである。確認：`git diff --numstat main -- scripts/smoke.sh` の出力が `10	10	scripts/smoke.sh`（区切りはタブ。追加10行・削除10行）、かつ `git diff -U0 --word-diff=porcelain main -- scripts/smoke.sh | grep -c '^--q'` が `10`、かつ `git diff -U0 --word-diff=porcelain main -- scripts/smoke.sh | grep -vE '^([^-+]|--q ?$|\+>/dev/null 2>&1$|--- a/|\+\+\+ b/)'` の出力が空
- smoke が全件通る。確認：`bash scripts/smoke.sh 2>&1 | tail -1` が `fail=0` を含む
- smoke の出力に `-q` 起因の git のエラーが出ない。確認：`bash scripts/smoke.sh 2>&1 | grep -c 'unknown switch'` が `0`（計画時点では `1`）

## 決定済み
- 変更は `worktree remove -q --force` を `worktree remove --force` に置き換える（10箇所すべて）ことと、2006行目付近の `git -C "$WTMAIN" worktree remove -q --force "$LEAF"` の行末に ` >/dev/null 2>&1` を足すことだけ。ほかの行（コメント・空白・911・928行目の既に `-q` 無しの行を含む）は変えない
- `-q` の代わりに別の静音オプションを足さない。出力の抑止はリダイレクト `>/dev/null 2>&1` で行う（他の9箇所と同じ書き方）
- 確認範囲は Issue の範囲である `scripts/` と `.claude/`。`vault/`（過去の計画・ログ）や `docs/` は実行されるコードではないので対象外（計画時点で `docs/`・README にも該当の記述は無い）
- `scripts/discard_worktree.sh` は既に `-q` 無しなので変えない
- 計画ブランチは `main` から切られており、このタスクは計画で唯一のタスクなので、差分の確認は `main` との比較で行う
- 作業環境の git は 2.43.0 で、変更前の smoke は `pass=524 fail=0`、`unknown switch` は出力に1回出る
