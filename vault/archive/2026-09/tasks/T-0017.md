# T-0017 `/design` の配布と周知、planner のタスク数上限を追加する

## 目的
`/design` スキルの追加を、インストール先への配布（`scripts/install.sh`）と利用者向けの説明（`README.md`・`docs/runbook.md`・`CLAUDE.md`）に反映する。あわせて `.claude/agents/planner.md` の粒度基準に「1計画あたりのタスク数上限」を追加する。

## 入力
- T-0015・T-0016 の成果物（`vault/templates/design.md`、`vault/designs/.gitkeep`、`.claude/skills/design/SKILL.md`）
- `scripts/install.sh`（複製対象の現状。`vault/rules/` 追加時（T-0012）と同じパターンで `copy_if_absent` を使う）
- `README.md`（「## 使い方」表、「## 拡張ポイント（ルール）」節、「## 構成」ツリー）
- `docs/runbook.md`（番号付き手順の書式）
- `CLAUDE.md`（現状41行。60行以内を維持する）
- `.claude/agents/planner.md`（「## 粒度の基準」節）

## 成果物
複数ファイルへの追記（1セットの変更として扱う）：`scripts/install.sh`、`README.md`、`docs/runbook.md`、`CLAUDE.md`、`.claude/agents/planner.md`

## 受け入れ基準
- `.claude/agents/planner.md` の「## 粒度の基準」に「1計画は5〜7タスクまで。超える場合は次フェーズの候補を計画票の末尾に書くだけにし、票は起こさない」旨の1行がある。確認：`grep -c '5〜7タスク' .claude/agents/planner.md` が1以上
- `scripts/install.sh` の複製対象に `vault/designs/.gitkeep` と `vault/templates/design.md` が追加されている。確認：`grep -c 'designs/.gitkeep' scripts/install.sh` と `grep -c 'templates/design.md' scripts/install.sh` がともに1以上
- `README.md` に `/design` の説明と使い分けの線引き（`/plan` との違い）が追記されている。確認：`grep -c '/design' README.md` が1以上
- `docs/runbook.md` に `/design` の使い方が追記されている。確認：`grep -c '/design' docs/runbook.md` が1以上
- `CLAUDE.md` に `/design` の記述があり、全体が60行以内。確認：`grep -c '/design' CLAUDE.md` が1以上 かつ `wc -l < CLAUDE.md` が60以下
- `bash scripts/smoke.sh | tail -1` が `fail=0` を含む（既存の検証が壊れていない）

## 決定済み
- `install.sh` の複製対象は既存の `for f in tasks/.gitkeep plans/.gitkeep ...` のループに `designs/.gitkeep` と `templates/design.md` を加える形にする（`vault/rules/` 追加時と同じパターン。`copy_if_absent` により既存ファイルは上書きしない）
- `README.md` の追記位置：「## 使い方」表に `/design` の行を1行追加し、その直下か「## 拡張ポイント（ルール）」節の前に「使い分け」を3〜5行で追記する（受け入れ基準7行超・成果物が複数ファイル・人に聞くことがある、のいずれかで `/design`、それ以外は `/plan` 直行）。「## 構成」ツリーの `skills/` の説明に `design` を加える
- `docs/runbook.md` の追記位置：「1. ゴールを入れる」の前後に「0. 大きなゴールは先に設計する（`/design <ゴール>`）」のような項目を追加してよい。既存の番号付き手順の番号は変えない範囲で調整する
- `CLAUDE.md` は現在41行。「## スキル」節に `/design` の1行を追加する程度に留め、60行を超えないようにする
- このタスクでは `run-queue`・`verifier`・`.claude/hooks/` は変更しない（プランの決定事項どおり）

## 進捗
- `bash scripts/rules.sh creator` を実行。出力は空だったため何もしていない
- `.claude/agents/planner.md` の粒度基準に「1計画は5〜7タスクまで。超える場合は次フェーズの候補を計画票の末尾に書くだけにし、票は起こさない」を追加
- `scripts/install.sh` の vault 複製ループに `designs/.gitkeep` と `templates/design.md` を追加
- `README.md`：使い方表に `/design` の行、その下に `/design` と `/plan` の使い分けを3行で追記。構成ツリーの vault 行に `designs/`、skills の列挙を `design, plan, run-queue` に更新
- `docs/runbook.md`：「## 0. 大きなゴールは先に設計する」を「1. ゴールを入れる」の前に追加（既存の番号は変更していない）
- `CLAUDE.md`：スキル節に `/design` の1行を追加（42行、60行以内）
- 受け入れ基準6件の確認コマンドをすべて実行し通過。あわせて一時ディレクトリへ `install.sh` を実行し、`vault/designs/.gitkeep`・`vault/templates/design.md`・`.claude/skills/design/SKILL.md` が複製されることを確認。`bash scripts/smoke.sh` は pass=40 fail=0
