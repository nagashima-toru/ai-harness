# T-04 install.sh・uninstall.sh で導入先の .gitignore の .claude/worktrees/ を足し・戻す

## 目的
導入先で creator の worktree（`.claude/` の下の worktrees ディレクトリ）が git の未追跡ファイルとして見えないよう、`scripts/install.sh` が導入先の `.gitignore` にその行を（無ければ）足し、`scripts/uninstall.sh` が足した分だけを戻す（Issue #191 の1）。導入先の既存の `.gitignore` の行は壊さない。

## 入力
- `scripts/install.sh`（マニフェスト `.claude/harness-manifest.json` の書き方、`--update` の動き）
- `scripts/uninstall.sh`（マニフェストとの照合、最後にマニフェストを消す流れ）
- ai-harness 自身の `.gitignore`（同じ行がすでにある）
- `docs/install.md` の「パターン1」の「4. `.gitignore` を作る」
- `scripts/smoke.sh` の `== uninstall.sh ==` の節（`smoke_tmpdir` での一時ディレクトリの作り方）

## 成果物
- `scripts/install.sh`（主な成果物）
- `scripts/uninstall.sh`
- `scripts/smoke.sh`（テストの追加）
- `docs/install.md`

## 受け入れ基準
- `bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` で終わる
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (install-gi) 0[1-6] '` の出力が `6`（決定済みのテスト 01〜06 がすべて通る）
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`
- `grep -cx '.claude/worktrees/' docs/install.md` の出力が `1`（「4. `.gitignore` を作る」の例の行）
- `git diff --merge-base work/p-20261012-unblock-resume-and-install-fixes --name-only -- scripts/install.sh scripts/uninstall.sh` の出力に `scripts/install.sh` と `scripts/uninstall.sh` の2行がある

## 決定済み
- 足す行は `.claude/worktrees/` の1行（ai-harness 自身の `.gitignore` と同じ文字列）。「すでにある」とは、導入先の `.gitignore` に、前後の空白を除いてこの文字列と完全に一致する行があること（`.claude/worktrees` のような末尾の `/` の無い行や、より広いパターンは「無い」として扱い、行を足す）
- install.sh（`--update` の有無を問わず毎回）：
  - `.gitignore` が無ければ、この1行だけのファイルを作る。マニフェストに `"gitignore": "created"` を記録する
  - あって行が無ければ、末尾に改行が無い時は改行を1つ足してから、この1行を末尾に追記する。マニフェストに `"gitignore": "appended"` を記録する
  - あって行がすでにあれば何もしない。マニフェストの `gitignore` キーは、前のマニフェストにあればその値を引き継ぎ、無ければ書かない（2回目以降の install で、利用者が元から持っていた行を「ハーネスが足した」と誤って記録しないため）
  - 足した・作った時は標準出力に `gitignore  .gitignore に .claude/worktrees/ を追記` の形の1行を出す（文言は多少変えてよい）
  - マニフェストは今の `version`・`files`・`settings_src` のキーをそのまま残し、`gitignore` キーを足すだけにする
- uninstall.sh：マニフェストの `gitignore` が `created` か `appended` の時だけ、導入先の `.gitignore` から `.claude/worktrees/` と完全に一致する行を（最後の1行だけ）取り除く。取り除いた後、`created` で、残りに空白以外の行が無ければ `.gitignore` 自体を削除する。それ以外の行・行の順序は変えない。`gitignore` キーが無い・`.gitignore` が無い・行が無い時は何もしない。標準出力に `remove .gitignore` か `unmerge .gitignore` の形の1行を出す（文言は多少変えてよい）
- `docs/install.md`：「パターン1」の「4. `.gitignore` を作る」の例の heredoc に `.claude/worktrees/` の行を足し（`.claude/settings.json` の行などと同じくバッククォートで囲まない素の1行）、install.sh がこの行を（無ければ）自動で足し、アンインストールで戻すことを1〜2文で書く。本文の地の文でこのパスをバッククォートで囲まない（smoke の `(ref-1)` は文書中のバッククォートで囲まれた `.claude/` で始まるパスの実在を検査し、リポジトリの直下に worktrees ディレクトリは無いので NG になる）。「ai-harness と同じ4行」のような行数の記述は実際の行数に合わせて直す
- smoke のテストは、`scripts/smoke.sh` の `echo "== 標準ルール6本を配らない（install / --update / uninstall） =="` の行の直前に、`echo "== install.sh の .gitignore =="` から始まる1つのブロックとして足す（ほかのタスクが別の場所にテストを足すので、この位置から動かさない）。導入先は既存の節と同じく `smoke_tmpdir` で作る。テスト名は `(install-gi) 01 …`〜`(install-gi) 06 …` とし、番号ごとに `expect_eq` を1つだけ書く（1つの expect_eq で複数の値を空白区切りで比べてよい）：
  - 01：`.gitignore` の無い導入先に install → `.gitignore` の中身がちょうど `.claude/worktrees/` の1行で、マニフェストの `gitignore` が `created`
  - 02：末尾に改行の無い `node_modules/` だけの `.gitignore` がある導入先に install → 中身が `node_modules/` と `.claude/worktrees/` の2行（この順）で、マニフェストの `gitignore` が `appended`
  - 03：`.claude/worktrees/` の行をすでに持つ導入先に install → その行が1行のままで、マニフェストに `gitignore` キーが無い。続けて uninstall してもその行が残る
  - 04：02 の導入先を uninstall → `.gitignore` が残り、中身が `node_modules/` の1行（`.claude/worktrees/` の行が無い）
  - 05：01 の導入先に `install.sh --update` をもう一度実行 → `.claude/worktrees/` の行が1行のままで、マニフェストの `gitignore` が `created` のまま
  - 06：05 の後の導入先を uninstall → `.gitignore` が無い
