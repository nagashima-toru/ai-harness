# T-04 README.md・docs/install.md を新方式に更新する

## 目的
`README.md` と `docs/install.md` から `vault/todo.md` の記述を消し、計画票（`/plan`→承認→`/run`）を
中心にした説明・手順に書き直す。`scripts/install.sh`（T-02）が作る新しい空ディレクトリ構成を反映する。

## 入力
- `README.md`（改訂対象。特に「使い方」表、「仕組み」の図、「構成」節）
- `docs/install.md`（改訂対象。特にパターン1手順3「ハーネスを複製する」、パターン2手順1）
- T-02 で改訂済みの `scripts/install.sh`
- T-03 で改訂済みの `.claude/ai-harness.md`
- `.claude/skills/plan/SKILL.md`・`.claude/skills/run/SKILL.md`

## 成果物
- `README.md`、`docs/install.md`

## 受け入れ基準
- `grep -rc 'vault/todo.md' README.md docs/install.md` の出力がすべて0
- README.md の「使い方」表が `/run-queue` ではなく `/run` を挙げている。確認：`grep -c '/run-queue' README.md` が0 かつ `grep -c '/run' README.md` が1以上
- README.md の「構成」節の `vault/` 説明から `todo.md（正本）` の記述が消えている。確認：`grep -c 'todo.md' README.md` が0
- docs/install.md の「パターン1」手順3の複製物説明が `todo.md` に触れず、`vault/{plans,tasks,verdicts,log,designs,archive,templates,rules}` の空ディレクトリ構成の説明に置き換わっている。確認：`grep -c 'todo.md' docs/install.md` が0
- `bash scripts/smoke.sh | tail -1` に `fail=0` が含まれる

## 決定済み
- README.md の「仕組み」の図は `/plan <ゴール>` → ブランチ作成 → 計画票 draft → `/plan approve` →
  `/run` → 検証 → done/PR、という流れに書き換える（`vault/todo.md（正本）` の箱は削除し、`計画票が状
  態の正本` という説明に置き換える）
- README.md の「構成」節の `vault/` 行は「`plans/`（計画票=状態の正本）、`tasks/`、`designs/`、
  `verdicts/`、`log/`、`templates/`、`archive/`、`rules/`」の説明に更新する
- docs/install.md はパターン1・パターン2の両方から `todo.md` 言及を除去する。「ハーネスを更新する
  （2回目以降）」節は挙動を変えていないので文言はそのままでよい
- `/run-queue` という語は README.md・docs/install.md のどちらにも残さない
- `docs/runbook.md`・`docs/decisions.md` は T-05 で扱うため、このタスクでは触らない

## 進捗
- 読んだルール: roles.md, creator.md（既読）
- `README.md`：「使い方」表を `/run-queue`→`/run`、`/plan approve` の todo.md 登録記述をブランチ作成に
  変更。並行セッションの一文を追加。「仕組み」の図を `/plan`→ブランチ作成→計画票draft→
  `/plan approve`（status変更）→`/run`→検証→done/PR/blocked の流れに全面書き換え。
  「構成」節の `vault/` 行を `plans/`（計画票=状態の正本）中心の説明に更新
- `docs/install.md`：パターン1手順3の複製物説明を「`vault/{plans,tasks,verdicts,log,designs,
  archive,templates,rules}` の空ディレクトリ」＋「キューのファイルは配らない」に更新。パターン2の
  `skip (exists)` 表の例を「標準ルール4本など」に、手順3の git 管理節の `vault/` 内訳から `todo.md`
  を削除
- 「ハーネスを更新する」「インストール後の次の一歩」節は挙動が変わっていないため無変更
- 受け入れ基準の確認コマンドを実行し、5件すべて通した
  - `grep -rc 'vault/todo.md' README.md docs/install.md` → 両方0
  - `/run-queue`=0 / `/run`=5（README）
  - README `todo.md`=0 / install.md `todo.md`=0
  - `bash scripts/smoke.sh | tail -1` → `smoke: pass=95 fail=0`
