# T-06 既存の設計文書 D-001〜D-016 を削除する

## 目的
D-016 の決定事項を `docs/decisions.md` に追記し終えた（T-05）後に、`vault/designs/` の既存の設計文書をすべて削除し、旧形式の設計文書 ID への参照がリポジトリに残っていないことを確かめる。

## 入力
- `vault/designs/` の一覧（`.gitkeep` と `D-001.md`〜`D-016.md`。`D-014.md` は元から無い）
- T-01〜T-05 の成果物（計画ブランチにマージ済み）

## 成果物
- `vault/designs/`（配下の `D-*.md` の削除。`.gitkeep` は残す）

## 受け入れ基準
- 作業ツリーの `vault/designs/` には `.gitkeep` だけがある（`ls -A vault/designs` が `.gitkeep` の1行だけを出す）
- git の管理下でも `vault/designs/` には `.gitkeep` だけがある（`git ls-files vault/designs` が `vault/designs/.gitkeep` の1行だけを出す）
- リポジトリの文書・スクリプト・テンプレート・ルールに旧形式の設計文書 ID の記述が残っていない（`grep -rnE --exclude=decisions.md --exclude-dir=worktrees 'D-xxx|d-xxx|vault/designs/D-[0-9]{3}|design/d-[0-9]{3}|最大値 ?\+1|\+ 3桁|^id: D-[0-9]{3}$' README.md docs .claude scripts vault/templates vault/rules` が何も出さない）
- D-016 の決定事項が削除の前に `docs/decisions.md` へ移っている（`grep -cE '^\| 2026-10-10 \| (PR の直前に計画一式を除去する|証跡は PR に残す|取り出しの置き場は|設計文書は最終フェーズで削除する|設計文書の ID は `D-<YYYYMMDD>-<スラッグ>`)' docs/decisions.md` が `5` を出す）
- `bash scripts/smoke.sh 2>&1 | tail -1` が `smoke: pass=<N> fail=0` を出す（参照切れ検査 (ref-1) で、削除したファイルへのパスの参照が文書に残っていないことを含む）

## 決定済み
- D-016 の決定事項（転記）：既存の設計文書も削除する（人の選択）。設計文書の削除は creator がタスクの成果物として行ってよい（`vault/designs/` は差分ゲートの禁止対象ではない。この票の「成果物」に `vault/designs/` を宣言してある）
- 削除は `git rm vault/designs/D-0*.md` など、`D-*.md` のファイルだけを指定して行い、コミットする。`rm -rf` は使わない（settings.json で拒否される）。`vault/designs/.gitkeep` は消さない
- 既存の設計文書に未着手のフェーズが残っているかは、この計画の `/plan` の前に人が確認済み（必要なものは人が Issue 化した）。このタスクでは中身を確認しない・取り出さない
- 受け入れ基準3の検査範囲から外すもの：`docs/decisions.md`（判断の記録。D-016 の決定の理由として「最大値に1を足す採番」など旧方式に触れる行があり、過去の行も書き換えない方針のため）、`.claude/worktrees/`（run が作る creator の作業コピーで、リポジトリの内容ではないため）、`vault/plans/`・`vault/tasks/`・`vault/log/`・`vault/verdicts/`（この計画自身の状態ファイルで、旧形式を説明のために含み、PR の前に `scripts/purge_plan.sh` で除去されるため）、`vault/designs/`（このタスクで空になる）
- docs に残る過去の `D-0xx` への言及（例：「D-015 フェーズ2 で廃止」「D-012 フェーズ3」）は書き換えない（D-016 の決定：読み物として残す）。受け入れ基準3の正規表現はこれらに当たらない
- 受け入れ基準3・5が満たせない原因が T-01〜T-05 の成果物（このタスクの成果物の外）にある時は、そのファイルを直さずに blocked にして question に原因の箇所を書く
