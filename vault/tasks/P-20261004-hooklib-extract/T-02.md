# T-02 agent_write_guard.py の複製関数を _hooklib の import に置き換える

## 目的
`agent_write_guard.py` に複製されている8関数を消し、`_hooklib` を import して使う形にする。`_hooklib` を読み込めない時は、終了コード2で安全側に倒す。

## 入力
- `vault/designs/D-011.md`（決定事項の表・フェーズ1）
- `.claude/hooks/_hooklib.py`（T-01 の成果物）
- `.claude/hooks/agent_write_guard.py`（消す関数：`existing_ancestor`・`git_toplevel`・`delegate_to_worktree`・`plan_raw_rows`・`frontmatter_status`・`human_messages`・`is_approve_command`・`is_unblock_command`。モジュール docstring の38〜39行目と `plan_raw_rows` の docstring に「import はしない」の記述がある）

## 成果物
- `.claude/hooks/agent_write_guard.py`（1ファイル）

## 受け入れ基準
- 構文が正しい：`python3 -B -c "import ast; ast.parse(open('.claude/hooks/agent_write_guard.py').read()); print('ok')"` の出力が `ok`
- 複製の関数定義と「import しない」「コピー」の注記が残っていない：`grep -nE '^def (existing_ancestor|git_toplevel|delegate_to_worktree|plan_raw_rows|frontmatter_status|human_messages|is_approve_command|is_unblock_command)\(|import (は)?しない|import は$|同名関数のコピー|コピーして使う' .claude/hooks/agent_write_guard.py` の出力が空
- `_hooklib` を読み込めない時は、終了コード2で理由を標準エラーに出す：`python3 -B -c "import subprocess; r = subprocess.run(['python3', '-c', 'import sys, runpy; sys.modules[\"_hooklib\"] = None; runpy.run_path(\".claude/hooks/agent_write_guard.py\", run_name=\"__main__\")'], input='{}', capture_output=True, text=True); print(r.returncode, '[agent_write_guard] _hooklib の読み込みに失敗しました' in r.stderr)"` の出力が `2 True`
- フックを実行しても `_hooklib` のバイトコードキャッシュができない：`python3 -B -c "import glob, os, subprocess; e = {k: v for k, v in os.environ.items() if k != 'PYTHONDONTWRITEBYTECODE'}; subprocess.run(['python3', '.claude/hooks/agent_write_guard.py'], input='{}', capture_output=True, text=True, env=e); print(glob.glob('.claude/hooks/__pycache__/_hooklib*'))"` の出力が `[]`
- 既存の smoke が全件通る（worktree 委譲のケースを含む）：`bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` を含む

## 決定済み
- フック先頭の書き方は次の形で固定する。3フック共通で、`<フック名>` だけを変える
  - 置く位置：モジュール docstring と標準ライブラリの import 文の直後、定数定義より前
  - 共通化しない。標準ライブラリだけで、このファイルに直接書く（D-011）
  ```python
  sys.dont_write_bytecode = True
  sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
  try:
      import _hooklib as H
  except Exception as e:  # SyntaxError なども含めて捕まえる
      sys.stderr.write(f"[agent_write_guard] _hooklib の読み込みに失敗しました: {e}\n")
      sys.exit(2)
  ```
- 呼び出し側の書き方
  - 呼び出しはすべて `H.<関数名>(...)` に書き換える。`existing_ancestor = H.existing_ancestor` のような別名は作らない
  - `plan_raw_rows(...)` は `H.raw_rows(...)` にする
  - `delegate_to_worktree(payload)` は `H.delegate_to_worktree(payload, "agent_write_guard.py")` にする（スクリプト名は文字列リテラルで渡す）
- 移さずにこのファイルに残すもの
  - `analyze_bash_writes` などの Bash 解析・`normalize`・`resolve_root`・`current_branch`・`plan_task_status` ほか、このフックだけが使う関数（D-011：共通化は複製されているものに限る）
  - 移した関数を使っていた関数の中身は、呼び出しを `H.` に変える以外は変えない
- モジュール docstring
  - 「plan_guard.py の raw_rows と同じものをこのファイル内にコピーして使う（他ファイルへの import はしない方針を踏襲…）」の文は、「タスク表の解析は共通モジュール `_hooklib.py` の `raw_rows` を使う」という趣旨に書き換える
  - 共通関数は `.claude/hooks/_hooklib.py` にあり、読み込めない時は終了コード2で終わることを1〜2行で書き足す
- 判定の挙動（許可・拒否・メッセージ）は一切変えない。smoke の期待値は変えない
- `plan_guard.py`・`stop_gate.py`・`_hooklib.py`・`scripts/smoke.sh`・docs は変更しない（T-03・T-04・T-05・T-06 の担当）。smoke への新しいケースの追加は T-05 で行う
- 動作確認で import する時は `python3 -B` を使う。`.claude/hooks/__pycache__/_hooklib*` を作ってしまったら消しておく
- コミットは受け入れ基準に無いので、creator はしない
