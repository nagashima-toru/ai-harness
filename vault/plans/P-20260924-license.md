# ゴール
GitHub Issue #17「public 化に伴うライセンス整備」に対応する。このリポジトリを private から public に変更したが `LICENSE` ファイルが無く `README.md` にもライセンス記載が無いため、他者がどう扱えるコードかを明示する。OSS ライセンスを選定して `LICENSE` を追加し、`README.md` にライセンス節を追記し、`.claude/` 配下と `vault/rules/` に外部由来のコード・雛形が含まれていないか（含まれる場合は出典・ライセンス互換性）を確認する。

## 分割方針
- ライセンス種別・著作権者表記は人に確認し、回答を各タスク票の「決定済み」に反映済み
- T-01（LICENSE 追加）を先に切り、T-02（README 追記）はその成果物を参照するため `after: T-01` にする
- T-03（外部由来コードの出典確認）は独立した調査タスクで、成果物を `docs/third-party-notices.md` に一本化する。既存の README・LICENSE には触れない
- `CONTRIBUTING.md` の要否は「必要なら検討」という条件付きの依頼であり、要否自体が人の判断待ちのため、今回はタスク化せず「人への質問」で聞き、次フェーズ候補に留める（成果物を1つに特定できないため）
