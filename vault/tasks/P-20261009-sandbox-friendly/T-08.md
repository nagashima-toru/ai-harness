# T-08 uninstall.sh が mktemp の失敗で中断し、一時ファイルを $TMPDIR の下に作るようにする

## 目的
`scripts/uninstall.sh` の一時ファイルを `$TMPDIR`（無ければ `/tmp`）の下に作り、サンドボックスの中でも作れるようにする。作れない時は、ファイルを1つも消す前に中断の文言を出して終わる（T-01 の `scripts/smoke.sh` と同じ方針）。これで smoke の uninstall.sh のケースがサンドボックスの中で落ちなくなる。

## 入力
- `scripts/uninstall.sh`（`"$(mktemp)"` は58行目の `SETTINGS_SRC_TMP` の1か所。その前の32〜52行目でマニフェストに載ったファイルを消し、54行目で CLAUDE.md のマーカーブロックを除いている）
- `vault/plans/P-20261009-sandbox-friendly.md` の分割方針（「調べて分かったこと」）
- `vault/tasks/P-20261009-sandbox-friendly/T-01.md` の決定済み（同じ方針の smoke.sh の直し方。参考）

## 成果物
- `scripts/uninstall.sh`（1ファイル）

## 受け入れ基準
確認コマンドは worktree のルートを作業ディレクトリにして実行する（verifier は `cd <worktree>` してから実行する）。5〜7行目は、2〜4行目が全部真の時だけ、決定済みの「確認の準備」の2つのコマンドを実行してから、この順で実行する。
- 構文が正しい：`bash -n scripts/uninstall.sh` の出力が空で終了コードが0
- `mktemp` を直接コマンド置換で呼んでいない：`grep -cF '$(mktemp' scripts/uninstall.sh` の出力が `0`
- 中断付きの呼び出しと関数がある：`grep -cF 'SETTINGS_SRC_TMP="$(uninstall_tmpfile)" || abort_tmp' scripts/uninstall.sh` の出力が `1`、`grep -cF 'uninstall_tmpfile() { mktemp "${TMPDIR:-/tmp}/uninstall.XXXXXX"; }' scripts/uninstall.sh` の出力が `1`
- 一時ファイルはファイルを消すより前に作る：`grep -nF -e 'SETTINGS_SRC_TMP="$(uninstall_tmpfile)"' -e 'os.remove(p)' scripts/uninstall.sh | head -1` の出力が `SETTINGS_SRC_TMP=` を含む
- 一時ファイルを作れない時は中断の文言を出す：`env TMPDIR=/nonexistent-p20261009 bash scripts/uninstall.sh /tmp/claude/P-20261009-sandbox-friendly-T-08/dst 2>&1 | grep -cF 'uninstall: 一時ファイルを作れません（TMPDIR=/nonexistent-p20261009）。中断します'` の出力が `1`
- 中断した時はマニフェストを消していない：`test -f /tmp/claude/P-20261009-sandbox-friendly-T-08/dst/.claude/harness-manifest.json` の終了コードが0
- 一時ファイルを作れる時は最後まで通る：`bash scripts/uninstall.sh /tmp/claude/P-20261009-sandbox-friendly-T-08/dst 2>&1 | grep -cx 'remove .claude/harness-manifest.json'` の出力が `1`

## 決定済み
- `MANIFEST_FILE` の存在の確認（`if [ ! -f "$MANIFEST_FILE" ]; then ... exit 1; fi`）の直後、`# マニフェストに記録されたファイルのうち…` のコメントと最初の `python3 -c` より前に、次の4行をこのとおりの順で置く
  - `uninstall_tmpfile() { mktemp "${TMPDIR:-/tmp}/uninstall.XXXXXX"; }`
  - `abort_tmp() { echo "uninstall: 一時ファイルを作れません（TMPDIR=${TMPDIR:-}）。中断します" >&2; exit 2; }`
  - `SETTINGS_SRC_TMP="$(uninstall_tmpfile)" || abort_tmp`
  - `trap 'rm -f "$SETTINGS_SRC_TMP"' EXIT`
- 58〜59行目の元の `SETTINGS_SRC_TMP="$(mktemp)"` と `trap 'rm -f "$SETTINGS_SRC_TMP"' EXIT` は消す（上へ移す）。その前の `# .claude/settings.json（settings_src を…）` のコメントと、続く `if python3 -c ...` 以降は変えない
- 移す理由：今の位置では、一時ファイルを作れない時に、マニフェストに載ったファイルを消し CLAUDE.md を書き換えた後で `set -e` により途中で終わり、`.claude/harness-manifest.json` だけが残った中途半端な状態になる。何も変える前に中断する
- テンプレートの名前は `uninstall.XXXXXX` に固定する（`$TMPDIR` が未設定の時は `/tmp`）。理由：macOS の `mktemp` はテンプレートを渡さないと `$TMPDIR` を使わず `/var/folders/...` に作ろうとし、サンドボックスの中では `Operation not permitted` で失敗する（計画作成時に確認）
- `abort_tmp` の前に `mktemp` 自身のエラー（`mktemp: mkstemp failed on ...`）が標準エラーに出てよい（消さない）
- 出力の文言・終了コード（引数の誤り2、対象やマニフェストが無い時1）・消す対象は変えない。`scripts/smoke.sh`（T-01）・`scripts/install.sh`（T-07）・`scripts/archive_plans.sh`（T-09）は変えない
- 確認の準備（creator・verifier とも、受け入れ基準5行目の前に毎回この2つを順に実行する。7行目の起動でマニフェストが消えるため、作り直す）
  1. `mkdir -p /tmp/claude/P-20261009-sandbox-friendly-T-08/dst/.claude`
  2. `python3 -m json.tool .claude/settings.json /tmp/claude/P-20261009-sandbox-friendly-T-08/dst/.claude/harness-manifest.json`
  - フィクスチャのマニフェストは `.claude/settings.json` の写しで、`files` キーも `settings_src` キーも無い。uninstall.sh は何も消さず、CLAUDE.md が無いので `skip ...CLAUDE.md` を出し、settings.json は案内（`note  .claude/settings.json は手動確認してください…`）だけを出し、最後にマニフェストを消して `remove .claude/harness-manifest.json` を出す（計画作成時に、mktemp をテンプレート付きに差し替えて確認した）
  - install.sh（T-07）を使わずにフィクスチャを作るのは、T-07 と並行で進めるため。`cp` ではなく `python3 -m json.tool` で写すのは、verifier の書き込みガードが `cp` の読み取り元の repo 内のパスも書き込み先とみなして拒否するため
- `/tmp/claude/P-20261009-sandbox-friendly-T-08/` の下のファイルは消さない（人にも消させない）
- `/nonexistent-p20261009` は存在しないディレクトリとして使う（作らない）。`env` で始めるのは許可リストの `Bash(env *)` で通すため
- uninstall.sh は `<target-dir>` の下にだけ書くので、受け入れ基準5〜7行目の起動はサンドボックスの中で実行してよい。`bash scripts/smoke.sh` の全件の実行は、creator・verifier ともサンドボックスの中で行わない（全件は計画の run の後に人が確かめる）。2〜4行目のどれかが偽なら5〜7行目は実行せず偽とする
- このファイルの編集は拒否されない見込み（`scripts/` はサンドボックスの書き込み保護の対象外）。拒否された時は、別の手段で書き換えようとせず、拒否の理由を question に書いて `blocked` にする
