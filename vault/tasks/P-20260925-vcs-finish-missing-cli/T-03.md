# T-03 design スキルに GitHub/GitLab MCP 代替手順を明記する

## 目的
`bash scripts/vcs_finish.sh` が `gh`/`glab` コマンド不在（exit 127、または T-01 で追加した明
示エラー）で失敗した場合に、GitHub MCP ツール等で同内容の PR を作成してよいことを `design` ス
キルの手順として明文化し、毎回の独自判断をなくす。

## 入力
- `.claude/skills/design/SKILL.md`（変更対象。手順8に `bash scripts/vcs_finish.sh` の実行があ
  る）
- `scripts/vcs_finish.sh`（T-01 完了後の版）
- GitHub issue #37（`gh issue view 37`）：代替手順の提案文言の元ネタ
- `.claude/skills/run/SKILL.md`（T-02 完了後の版。同じ趣旨の追記なので文面の粒度を揃える参考
  にする。ただし design 側は「PR を作って提示し、止まる」という文脈なので、その文脈に合わせて
  書く）

## 成果物
- `.claude/skills/design/SKILL.md`

## 受け入れ基準
- `scripts/vcs_finish.sh` が「コマンドが見つからない」旨のエラー（exit 127、または T-01 で追加
  した明示エラー）で失敗した場合に GitHub MCP ツールで代替してよい旨の記述がある。確認：
  `grep -n "MCP" .claude/skills/design/SKILL.md` がヒットする
- 具体的なツール名の例が書かれている。確認：`grep -n "mcp__github"
  .claude/skills/design/SKILL.md` がヒットする
- `gh pr create` に渡すはずだった情報（ブランチ名・PR タイトル・本文）を MCP ツール呼び出しに
  引き継ぐ旨が書かれている。確認：`grep -n "引き継" .claude/skills/design/SKILL.md` がヒット
  する
- GitLab（`glab`）についても、MCP 等の代替手段があれば使ってよい旨と、無ければ人に案内して止
  まる旨の両方が書かれている。確認：`grep -n "glab" .claude/skills/design/SKILL.md` がヒット
  し、かつ同じ追記箇所に「人」への言及があることを目視で確認する
- `gh pr merge`/`glab mr merge` を**実行してよい**という記述が追加されていない。確認：
  `grep -n "gh pr merge\|glab mr merge" .claude/skills/design/SKILL.md` に実行を指示する記述
  が無いことを目視確認する（既存の「実行しない」という方針説明への言及は可）

## 決定済み
- 追記箇所は手順8（`bash scripts/vcs_finish.sh` を実行し、PR/MR を提示して止まる手順）の中。
  既存の手順番号・見出しは変えず、その中か直後に代替手順の段落を追加する形でよい
- 追記する内容の骨子（この通りの文面でなくてよいが、趣旨を含めること。T-02 の `run` 側と同じ
  趣旨で、文脈だけ design 用に合わせる）：
  - `bash scripts/vcs_finish.sh` が `command not found`（exit 127 相当）、または新しく追加さ
    れた「`gh`/`glab` が見つからない」旨の明示エラーで失敗した場合、GitHub MCP ツール（例：
    `mcp__github__create_pull_request` 等、実行環境で使える GitHub MCP ツール）で同内容の PR
    を作成してよい
  - その際、`gh pr create` に渡すはずだったブランチ名・タイトル・本文などの情報を、MCP ツール
    の引数にそのまま引き継ぐ
  - GitLab（`glab`）が同様に失敗した場合も、GitLab MCP 等の代替手段があればそれを使ってよい。
    使える代替手段が無い環境では、人にブランチ名と状況を案内して止まる
  - この代替経路を使っても `gh pr merge`/`glab mr merge` は実行しない（マージは人が行うという
    既存方針は変わらない。design スキルは元々マージを実行しない）
- 対象は「コマンド自体が無い」場合の代替であり、`gh`/`glab` が認証エラー・ネットワークエラー等
  で失敗するケースへの対応は今回のスコープ外
- T-02（`run` スキル）と内容の骨子は共通だが、成果物ファイルが別なので別タスクとして扱う。T-02
  の文面をコピーしてよい
