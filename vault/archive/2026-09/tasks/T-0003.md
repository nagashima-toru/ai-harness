# T-0003 planner に「run-queue で必ず変わるファイルの差分不変を受け入れ基準にしない」ルールを追記

## 目的
planner が「満たせない受け入れ基準」を書かないよう、.claude/agents/planner.md の「粒度の基準（必ず守る）」節と docs/vault-spec.md 第9節（粒度の基準）に、run-queue の手順で必ず変わるファイル（vault/todo.md、vault/log/queue.md、vault/tasks/<id>.md の進捗）を「変更していない」と差分で検査する受け入れ基準を書かない旨のルールを追記する。

## 入力
- `.claude/agents/planner.md`（「## 粒度の基準（必ず守る）」節）
- `docs/vault-spec.md`（「## 9. 粒度の基準（planner と人が共有する）」節）
- `vault/tasks/T-0002.md`（根拠事例。読むだけ、修正しない。特に「決定済み」の run-queue に関する記述と「進捗」欄の顛末）

## 成果物
- `.claude/agents/planner.md`（「粒度の基準」節への追記のみ）
- `docs/vault-spec.md`（第9節への1〜2行の追記のみ）
の2ファイル

## 受け入れ基準
- `.claude/agents/planner.md` の「粒度の基準」節に、run-queue の手順で必ず変わるファイル（vault/todo.md を含む）の差分不変を受け入れ基準に書かない旨のルールが追加されている。確認：`grep -A15 '^## 粒度の基準' .claude/agents/planner.md | grep -q 'vault/todo.md'`
- 同じ追記箇所に、形式や特定行の不変を検査したい場合は見出し行・列構成など変わらない部分に限定した確認コマンドにする旨が含まれている。確認：`grep -A15 '^## 粒度の基準' .claude/agents/planner.md | grep -q '見出し行'`
- `docs/vault-spec.md` 第9節に同趣旨が1〜2行で追記されている。確認：`grep -A10 '^## 9\. 粒度の基準' docs/vault-spec.md | grep -q '差分'`
- `.claude/agents/planner.md` の frontmatter（`tools:` 行を含む）は変更していない。確認：`git diff -- .claude/agents/planner.md | grep '^[+-]tools:'` の出力が空
- `.claude/hooks/stop_gate.py` は変更していない。確認：`git diff --quiet -- .claude/hooks/stop_gate.py`
- `vault/tasks/T-0001.md` と `vault/tasks/T-0002.md` は変更していない。確認：`git diff --quiet -- vault/tasks/T-0001.md vault/tasks/T-0002.md`

## 決定済み
- 追記位置：`.claude/agents/planner.md` は「## 粒度の基準（必ず守る）」の既存5項目の末尾に1項目（箇条書き1〜3行程度）を追加してよい。既存項目の順序・文言は変えない
- 追記位置：`docs/vault-spec.md` は「## 9. 粒度の基準（planner と人が共有する）」の既存4項目の末尾に1〜2行を追加する。第10節（Stop フックの判定）より前に収める
- 対象ファイルの具体例は「vault/todo.md、vault/log/queue.md、vault/tasks/<id>.md の進捗」の3つを列挙してよい（ゴールで指定された通り）
- 「見出し行・列構成など変わらない部分に限定した確認コマンド」の例：vault/todo.md なら `## タスク`/`## 計画` の見出し行や `| id |` の列ヘッダ行、vault/log/queue.md なら見出し行、タスク票なら `## 決定済み` 等の見出し行。例は簡潔に1つ挙げれば足り、網羅は不要
- 根拠事例（T-0002 で基準5「vault/todo.md は変更していない（git diff --quiet）」が run-queue の状態遷移で満たせず blocked になった件）に触れる場合は、planner.md か vault-spec.md のどちらか片方に1行程度で軽く言及すれば十分。必須ではない
- 文言は日本語で、ゴールに書かれた趣旨をそのまま使ってよい。ゴールの文をほぼそのまま転記しても構わない
- planner.md の「## 読むもの」「## 手順」「## 禁止」「## 出力」の各節、および frontmatter は変更しない
- 既存タスク票（T-0001.md、T-0002.md）や `.claude/hooks/stop_gate.py`、planner の `tools:` frontmatter は一切変更しない（受け入れ基準4〜6で機械確認する）
- git commit はしない（人が確認してからコミットする）

## 進捗
- planner.md「粒度の基準」末尾に1項目追加（対象3ファイル、T-0002 の事例、見出し行・列構成に限定する確認コマンドの例）
- vault-spec.md 第9節末尾に1項目追加（同趣旨を2行）
- 受け入れ基準6件の確認コマンドをすべて実行し通過
