# T-02 plan・design・run の SKILL.md に開始条件と MCP 代替時の head を足す

## 目的
`/plan` 手順A-2・`/design` 手順1 の開始条件に「`HARNESS_PUSH_BRANCH` が設定され、現在のブランチがその値で、HEAD がローカルのベースブランチと同じコミットなら、ベース上とみなしてブランチを切る」を足し、`run` 手順7・`design` 手順8 の MCP 代替時の head を `HARNESS_PUSH_BRANCH` に合わせる。

- `grep -nE '^2\. .*HARNESS_PUSH_BRANCH.*git rev-parse HEAD.*git rev-parse --verify' .claude/skills/plan/SKILL.md` が1行を出し、その行に「どちらの条件も満たさなければ従来どおり止まる」旨と、ローカルのベースブランチが無ければ止まる旨が書かれている
- `grep -nE '^1\. \*\*ブランチを作る\*\*.*HARNESS_PUSH_BRANCH.*git rev-parse HEAD.*git rev-parse --verify' .claude/skills/design/SKILL.md` が1行を出し、その行に plan と同じ条件と止まる場合が書かれている
- `grep -lF 'head（`HARNESS_PUSH_BRANCH` があればその値、無ければ現在のブランチ）' .claude/skills/run/SKILL.md .claude/skills/design/SKILL.md` が2つのファイル名を出す

- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`

## 決定済み
- 開始条件は「現在のブランチがベースブランチ」または「`HARNESS_PUSH_BRANCH`（`echo "${HARNESS_PUSH_BRANCH:-}"` の出力の前後の空白を除いた値。空なら未設定）が設定され、現在のブランチ（`git branch --show-current`）がその値で、`git rev-parse HEAD` の出力と `git rev-parse --verify <ベースブランチ>` の出力が同じ」のどちらか。後者の時も現在の HEAD から `work/<計画IDの英小文字>`（plan）・`design/d-…`（design）を切る。どちらでもなければ従来どおり「ベースブランチ（`<値>`）に戻ってから …を実行してください」と伝えて止まる。`git rev-parse --verify <ベースブランチ>` が失敗した時（ローカルにベースブランチが無い）も止まる
- 条件と確認コマンドは、plan は手順A-2 の行（`2. ` で始まる行）、design は手順1 の行（`1. **ブランチを作る**` で始まる行）の中に書く（子の箇条書きに分けない）。文中では `HARNESS_PUSH_BRANCH`・`git rev-parse HEAD`・`git rev-parse --verify` の順に出す
- 比較はローカルの `<ベースブランチ>` の ref だけと行う。`origin/<ベース>` との比較や fetch はしない（書かない）
- 「環境変数に無く、実行環境の指示で push 先が決められている時（クラウドセッションなど）は、オーケストレーターがその値を `env HARNESS_PUSH_BRANCH=<指定ブランチ> …` でコマンドに渡す（開始条件の確認と `vcs_finish.sh` の両方）」の一文を、plan（手順A-2）・design（手順1 か手順8）・run（手順7 の `vcs_finish.sh` の呼び出しの近く）の3本に書く。この中にバッククォートで `env HARNESS_PUSH_BRANCH=<指定ブランチ>` を含める。`env` で始めると許可リストの `Bash(env *)` で通ることも書いてよい
- run 手順7 の MCP 代替の段落の「head（現在のブランチ）」を「head（`HARNESS_PUSH_BRANCH` があればその値、無ければ現在のブランチ）」に置き換える
- design 手順8 の MCP 代替の段落（「ブランチ名・タイトル・本文などの情報を…引き継ぐ」）に、「head（`HARNESS_PUSH_BRANCH` があればその値、無ければ現在のブランチ）」の文言を入れる。base（ベースブランチ）も書いてよい
- `HARNESS_PUSH_BRANCH` 上の直接コミットはフックで拒否しない（スキルに拒否を書かない）。ローカルのブランチ名（`work/…`・`design/…`）は変えない
- `.claude/ai-harness.md`・`.claude/agents/` は変えない
