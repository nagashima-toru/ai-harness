# T-03 install.sh・uninstall.sh から vault/archive を除く

## 目的
archive の廃止に合わせて、導入先に `vault/archive/` を作らないようにし、install.sh・uninstall.sh のコメントと出力から archive の記述を除く。

## 入力
- `vault/designs/D-016.md` の「フェーズ2」
- `scripts/install.sh`（冒頭と `manifest_paths` の前のコメント、`vault/` の空ディレクトリを作るループ、`.gitkeep` などを複製するループ）
- `scripts/uninstall.sh`（冒頭のコメントと、最後の `note` の echo）
- `scripts/smoke.sh` の `== install.sh の CLAUDE.md 扱い ==` 節

## 成果物
- `scripts/install.sh`（主な成果物）
- `scripts/uninstall.sh`（コメントと note の文言だけ）
- `scripts/smoke.sh`（`(inst-arch)` のテストを1件足す）

## 受け入れ基準
1. install.sh と uninstall.sh に `archive` の語が無い。確認：`grep -n 'archive' scripts/install.sh scripts/uninstall.sh` の出力が空
2. 空のディレクトリへ install すると `vault/archive/` が作られず、ほかの vault の空ディレクトリ（plans・tasks・verdicts・log・designs・templates・rules）は作られることを smoke で確かめ、ok になる。確認：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (inst-arch) install.sh は vault/archive/ を作らない$'` が `1`
3. uninstall.sh の最後の note が archive を除いた利用者資産の一覧を出す。確認：`grep -c '^echo "note  vault/ の利用者資産（plans/tasks/verdicts/log/designs・vault/rules/ のルール）には触れていません"$' scripts/uninstall.sh` が `1`
4. smoke 全体が通る。確認：`bash scripts/smoke.sh 2>&1 | tail -1` が `smoke: pass=<数> fail=0` の形

## 決定済み
- install.sh の変更は次の4か所：`for d in plans tasks verdicts log designs archive templates rules` から `archive` を除く／`.gitkeep` などを複製するループの一覧から `archive/.gitkeep` を除く／`manifest_paths` の前のコメント「利用者の資産（vault/plans, tasks, verdicts, log, archive, designs の中身、…）」から `archive` を除く／ほかに `archive` を含むコメントがあれば除く
- uninstall.sh の変更は、冒頭のコメントの `plans/tasks/verdicts/log/designs/archive` を `plans/tasks/verdicts/log/designs` にすることと、最後の echo を受け入れ基準3の行そのものにすることだけ。削除の動作は変えない
- smoke の `(inst-arch)` は `== install.sh の CLAUDE.md 扱い ==` 節の中、`(g)` の2件の後・`rm -rf "$ITMP"` の前に置き、その節で install 済みの `$ITMP` を使う。確かめる内容は「`$ITMP/vault/archive` が存在しない」かつ「`$ITMP/vault/` の下に plans・tasks・verdicts・log・designs・templates・rules のディレクトリが全部ある」。テスト名は `(inst-arch) install.sh は vault/archive/ を作らない`（受け入れ基準2の確認コマンドがこの名前に一致する）
- `vault/archive/.gitkeep`（このリポジトリの実ファイル）は消さない。この計画のマージ後に人が `purge_plan.sh --merged --apply` で `vault/archive/` ごと消す
- 導入先に既にある `vault/archive/` を `--update` で消す処理は足さない（利用者の資産には触れない方針のまま）
- smoke の `== install.sh のマニフェスト ==` 節の、`vault/archive/` で始まるパスがマニフェストに無いことの検査はそのまま残す（パスの例として使っているだけ。D-016 の決定済み）
- docs/install.md の archive の記述はこのタスクでは直さない（T-06 で直す）
