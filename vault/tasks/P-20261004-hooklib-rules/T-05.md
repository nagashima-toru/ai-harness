# T-05 current_plan.sh と archive_plans.sh の frontmatter の awk で値の引用符を外し先頭の語を読む

## 目的
`scripts/current_plan.sh` と `scripts/archive_plans.sh` の `fm_status` が frontmatter を読む awk に、値の前後の `"`・`'` を外す処理を足し、値の後ろに語が続く行（`status: approved # メモ`）は先頭の語を読むようにして、`_hooklib.py` の `frontmatter_value`（T-01）と同じ規則にする。引用符付きの `status: "approved"` の計画票が、フックとスクリプトで同じく approved と判定されるようにする。

## 決定済み
- 値の読み方：`id:`・`status:` の行は `^key:[ \t]*[^ \t]+` に一致すれば読み、値は最初の空白までの先頭の語にする（今の `[ \t]*$` で終わる完全一致をやめる）。具体的には、正規表現を `/^id:[ \t]*[^ \t]+/`・`/^status:[ \t]*[^ \t]+/` に直し、`sub(/[ \t]*$/, "", line)` を `sub(/[ \t].*$/, "", line)` に置き換える（`sub(/^key:[ \t]*/, ...)` の後に行う）。Python の `^key:\s*(\S*)` と同じ
- 足す処理は次の1行で固定する（`_hooklib` の `str.strip("\"'")` と同じく、前後の `"`・`'` を全部外す）。awk のプログラムは bash の単一引用符の中にあるので、`'` は `\047` で書く
  ```awk
  gsub(/^["\047]+|["\047]+$/, "", line)
  ```
  - `current_plan.sh`：id の読み取りと status の読み取りのそれぞれで、先頭の語を取る `sub(/[ \t].*$/, "", line)` の直後に足す（2か所）
  - `archive_plans.sh`：`fm_status` の先頭の語を取る `sub(/[ \t].*$/, "", line)` の直後、`print line` の前に足す（1か所）
- `current_plan.sh` の id は、引用符を外した結果が空文字なら id 無しとして扱い（`gotid` を立てない）、ファイル名のフォールバックに任せる。status は空文字なら approved ではないので、追加の扱いは要らない
- frontmatter の他の読み方は変えない（D-011：awk 側は引用符を外す処理を足すだけでよい）。1行目が厳密に `---`・次の `---` で止まる、の規則はそのまま。`\r` の除去もそのまま
- `current_plan.sh` の先頭コメント（4行目）は、`# frontmatter の判定規則は .claude/hooks/_hooklib.py の frontmatter_value と同じ：` に直す（この文言のまま。受け入れ基準で grep する）。続くコメントに「値の前後の " と ' は外す」趣旨の1行を足す
- `archive_plans.sh` の「読み方は scripts/current_plan.sh と同じ」のコメントは、そのままで正しいので変えない
- `archive_plans.sh` の `table_counts` は T-08 で直す。このタスクでは触らない
- 引用符付きの計画票に対する archive_plans.sh の動作は、`fm_status` がスクリプト内の関数で単体では呼べないため、T-06 の smoke のケースで確かめる。このタスクでは smoke.sh を変更しない
- フック・`_hooklib.py`・smoke.sh・docs は変更しない（他タスクの担当）
- 既存の smoke が落ちた場合は、smoke.sh を直さず blocked にして、落ちたケース名と原因を question に書く
- コミットは受け入れ基準に無いので、creator はしない
