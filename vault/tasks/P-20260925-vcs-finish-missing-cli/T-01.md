# T-01 vcs_finish.sh に gh/glab の存在チェックとエラーメッセージを追加する

## 目的
`scripts/vcs_finish.sh` が `gh`/`glab` コマンド自体の無い環境で `command not found`（exit 127）
のまま失敗するのを防ぎ、原因と代替手段（MCP 等）が分かる明示的なエラーで終わるようにする。

## 入力
- `scripts/vcs_finish.sh`（変更対象。現状は `github`/`gitlab` 分岐で無条件に `gh pr create
  "$@"`／`glab mr create "$@"` を呼んでいる）
- `vault/designs/D-005.md`（背景。フェーズ1で「`gh`/`glab` 未インストール時のエラーハンドリン
  グは対象外」と明記された経緯。今回はその対象外だった部分を埋める。編集不要、参照のみ）
- GitHub issue #37（`gh issue view 37`）：今回の動機と人の提案

## 成果物
- `scripts/vcs_finish.sh`

## 受け入れ基準
- `HARNESS_VCS_HOST=github` で `gh` が見つからない状態（例: `PATH` に `gh` を含めない）で実行
  すると、終了コードが0以外になり、標準エラー出力に「gh」「見つかりません」「MCP」の3語を含
  むメッセージが出る。確認：`out=$(HARNESS_VCS_HOST=github PATH=/usr/bin:/bin bash
  scripts/vcs_finish.sh 2>&1 1>/dev/null); code=$?; echo "$out" | grep -q "gh" && echo "$out"
  | grep -q "見つかりません" && echo "$out" | grep -q "MCP" && [ "$code" -ne 0 ] && echo OK`
  の出力が `OK`
- `HARNESS_VCS_HOST=gitlab` で `glab` が見つからない場合も同様に、終了コードが0以外になり、標
  準エラー出力に「glab」「見つかりません」「MCP」の3語を含むメッセージが出る。確認：上記と同
  じ形で `HARNESS_VCS_HOST=gitlab` に差し替えて実行し、出力が `OK`
- 存在チェックは `gh pr create`／`glab mr create` を呼ぶ前に `command -v` で行っている。確認：
  `grep -n "command -v gh" scripts/vcs_finish.sh` と `grep -n "command -v glab"
  scripts/vcs_finish.sh` の両方がヒットする
- 追加したエラーメッセージは `none` 判定時の既存案内文（「ホスティングサービス（GitHub/GitLab）
  は検出されませんでした」）とは異なる文面で、意味も「ホスティングは検出できたが CLI が無い」
  ことを表している。確認：`grep -n "検出されませんでした" scripts/vcs_finish.sh` の行が既存の
  `none` 分岐の1箇所のみで、新規追加したメッセージ側には出現しないことを目視で確認する
- `gh pr merge`/`glab mr merge` を呼ぶコードが追加されていない。確認：`grep -c "pr merge\|mr
  merge" scripts/vcs_finish.sh` の出力が `0`

## 決定済み
- 存在チェックは `if ! command -v gh >/dev/null 2>&1; then ... fi` の形で `github`/`gitlab`
  それぞれの分岐の先頭（`gh pr create "$@"`／`glab mr create "$@"` を呼ぶ直前）に追加する
- 終了コードは `127`（コマンド未検出という bash 標準の意味に合わせる）。`none` 分岐の `exit 0`
  とは明確に区別する
- エラーメッセージの文言例（このとおりでなくてよいが、受け入れ基準の必須語「gh」/「glab」「見
  つかりません」「MCP」を含めること）：
  - github: `vcs_finish.sh: gh コマンドが見つかりません（GitHub は検出済みです）。GitHub CLI
    をインストールするか、GitHub MCP 等の代替手段で PR を作成してください。`
  - gitlab: `vcs_finish.sh: glab コマンドが見つかりません（GitLab は検出済みです）。GitLab CLI
    をインストールするか、GitLab MCP 等の代替手段で MR を作成してください。`
- 出力先は標準エラー（`>&2`）。標準出力には何も書かない
- `none` 分岐、および未知の `HARNESS_VCS_HOST` 値を扱う default 分岐は変更しない
- スクリプトのスタイル（`set -u`、大枠の `case` 構造、コメントの書き方）は既存のものを踏襲する
- `gh pr merge`/`glab mr merge` の実行は今回も追加しない（マージは人が行うという既存方針を維持
  する）
