## 決定済み
- 足す・書き換える関数（名前・引数は固定。3フックが T-02〜T-04 でこの名前を使う）
  - `TASK_COLUMNS = ("id", "status", "attempt", "after", "title", "question")` を定数で置く
  - `parse_tasks(plan_text)`：`plan_guard.py` の今の `parse_tasks` と同じ処理。`raw_rows(plan_text)` の各行のうち、5列未満は捨て、6列に満たない分は空文字で埋め、`dict(zip(TASK_COLUMNS, cells[:6]))` のリストを返す
  - `count_criteria(text)`：`plan_guard.py` の今の `count_criteria` をそのまま移す（本文を受け取る。ファイルパスは受け取らない。`## ` で始まる行で節を切り替え、節の中で `^(- |\d+\. )` に一致する行を数える）
  - `frontmatter_value(text, key)`：今の `frontmatter_status` の規則を key を引数にしたもの。1行目を strip して `---` でなければ None。2行目から、strip して `---` の行の手前までを見る（閉じる `---` が無ければ末尾まで）。`^<key>:\s*(\S*)` に最初に一致した行の値の前後から `"`・`'` を外す（`str.strip("\"'")`）。外した結果が空文字なら None。一致する行が無ければ None。key は `re.escape` して埋め込む
  - `frontmatter_status(text)`：`return frontmatter_value(text, "status")` にする
  - `plan_id_and_status(path)`：ファイルを読めなければ `(None, None)`。読んだ本文の1行目を strip して `---` でなければ（frontmatter が無い）`(None, None)`。そうでなければ、id は `frontmatter_value(text, "id")`、無ければファイル名から `.md` を除いたもの。status は `frontmatter_value(text, "status")`。`^---\n(.*?)\n---\n` の正規表現で探す今の実装はやめる
- 今の実装から変わる点（寛容な側に揃えた帰結。D-011 の人の回答「寛容な側に揃える」に従う）
  - 引用符付きの値（`status: "approved"`・`id: 'P-X'`）が、引用符を外した値になる
  - 閉じる `---` が無い frontmatter も末尾まで読む
  - 値の後ろに語が続く行（`status: approved x`）は先頭の語を読む
- 変えないもの
  - `raw_rows`・`approved_plans`・`existing_ancestor`・`git_toplevel`・`delegate_to_worktree`・`human_messages`・`is_approve_command`・`is_unblock_command` の中身
  - import 時に副作用を起こさない・標準ライブラリだけを使う、というモジュール docstring の約束
- 3フック（`stop_gate.py`・`plan_guard.py`・`agent_write_guard.py`）・scripts・smoke.sh・docs は変更しない（T-02〜T-07 の担当）。フックにまだ残っている `parse_tasks`・`count_criteria` などの複製はこのタスクでは消さない
- 既存の smoke が落ちた場合は、smoke.sh を直さず blocked にして、落ちたケース名と原因を question に書く
- 動作確認で import する時は `python3 -B` を使う。`.claude/hooks/__pycache__/_hooklib*` を作ってしまったら消しておく
