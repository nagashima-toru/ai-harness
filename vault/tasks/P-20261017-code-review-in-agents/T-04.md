# T-04 smoke に creator・verifier の tools の Skill の検査を足す

## 目的
creator・verifier が `/code-review` を呼ぶのに要る `Skill` ツールが、エージェント定義の tools から消えたら smoke で止まるようにする（原則2：守らせたい規律は仕組みで強制する）。

## 入力
- `scripts/smoke.sh`（`(agents-1)` の検査とその周辺、`expect_eq`・`$TMP` の使い方）
- `.claude/agents/creator.md`・`.claude/agents/verifier.md`（T-01・T-02 で tools に `Skill` を足した後の版）

## 成果物
- `scripts/smoke.sh`（1ファイル）

## 受け入れ基準
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (agents-2) '` の出力が `1` である
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (agents-3) '` の出力が `1` である
- `grep -c '^agtools_check() ' scripts/smoke.sh` の出力が `1` で、`(agents-2)` と `(agents-3)` の両方がこの関数の出力で判定している（Read で確かめる）
- `bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` で終わる

## 決定済み
- `(agents-1)` の検査の直後に、関数 `agtools_check()` を1つ足す。行は `agtools_check() { # $1=ルート。...` の形で始める（`^agtools_check() ` に一致させる）。引数のルートの `.claude/agents/creator.md` と `.claude/agents/verifier.md` のそれぞれについて、frontmatter の `tools:` で始まる行を取り、カンマ区切りの要素（前後の空白を除く）に `Skill` がちょうど一致する要素が無ければ、そのファイルのリポジトリ相対パスを1行ずつ出す。両方にあれば何も出さない。ファイルが無い時もそのパスを出す
- `(agents-2)`：`expect_eq "(agents-2) creator・verifier の定義の tools に Skill がある" "" "$(agtools_check "$ROOT")"` の形で、このリポジトリ自身を検査する
- `(agents-3)`：`$TMP` の下に一時ディレクトリ（例：`"$TMP/agtools"`。`mkdir -p` で作る）を作り、`.claude/agents/creator.md` に `tools: Read, Grep, Glob, Bash, Write, Edit`（Skill 無し）、`.claude/agents/verifier.md` に `tools: Read, Grep, Glob, Bash, Write, Skill` を書いたフィクスチャに対して、出力が `.claude/agents/creator.md` の1行だけになることを `expect_eq` で確かめる（検査が実際に欠けを検出することの確認）
- 後片付けは足さない（`$TMP` は smoke の既存の `trap` が消す）
- planner の定義（`.claude/agents/planner.md`）は検査しない（planner には Skill を足していない）
- install 先（`.claude/harness-manifest.json` がある環境）でも検査を飛ばさない（導入先でも creator・verifier の定義は同じものが配られる）。ただし導入先で利用者が tools を変えた時に smoke が落ちるのは、その変更を知らせる意味で許容する
- grep の `\b` などの GNU 拡張に頼らず、`python3` か `awk` かシェルの文字列処理で書く（既存の smoke と同じく、外部コマンドは `git`・`python3`・coreutils の範囲）

## 進捗
- 読んだルール: vault/rules/common/vision.md
- scripts/smoke.sh の (agents-1) の直後に agtools_check() と (agents-2)(agents-3) を追加
- 確認: agents-2 ok、agents-3 ok、agtools_check 定義1件、smoke 末尾 "smoke: pass=569 fail=0"
