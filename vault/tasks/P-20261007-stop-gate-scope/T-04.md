# T-04 docs/runbook.md の無人実行の説明に HARNESS_STRICT_STOP の既定を書く

## 目的
`docs/runbook.md` 3節「キューを回す」の無人実行の説明に、T-02 で入れた `scripts/run_unattended.py` の `HARNESS_STRICT_STOP` の既定（未設定なら `1` を入れて子に渡す）と、従来の動きに戻す方法を書く。

## 入力
- `vault/designs/D-013.md` の「フェーズ1 Stop フックの適用範囲と無人実行での厳格化」（決定済み）
- `scripts/run_unattended.py`（T-02 の後の版の docstring）
- `docs/runbook.md` 3節

## 成果物
- `docs/runbook.md`（このファイルだけ。3節の無人実行の箇条書きだけを変える）

## 受け入れ基準
- 3節に決定済みの1行がある：`sed -n '/^## 3\./,/^## 4\./p' docs/runbook.md | grep -cF '環境変数 `HARNESS_STRICT_STOP`：未設定ならラッパーが `1` を入れて子プロセスに渡す'` の出力が `1`
- 同じ行か直後の行に、`HARNESS_STRICT_STOP=0` を明示すれば従来の動き（`stop_hook_active` が真なら許可）になることが書かれている：`sed -n '/^## 3\./,/^## 4\./p' docs/runbook.md | grep -cF 'HARNESS_STRICT_STOP=0'` の出力が `1`（内容は Read で確認）
- 書いた既定が実装と一致する：`env -u HARNESS_STRICT_STOP HARNESS_RUN_CMD='printenv HARNESS_STRICT_STOP' python3 scripts/run_unattended.py` の標準出力が `1`
- 既存の smoke が全件通る：`bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` を含む

## 決定済み
- 置き場所：3節の無人実行の箇条書きのうち、`HARNESS_RUN_TIMEOUT` の行の直後に、同じ字下げ（`  - `）で1行足す
- 足す行は、基準1の grep の固定文字列（`環境変数 ` から `子プロセスに渡す` まで。バッククォートを含めて一字一句同じ）で書き出す。続けて「Stop フックが `stop_hook_active` の真でも判定を続け、verdict の無い終了を止める。`HARNESS_STRICT_STOP=0` を明示すれば従来の動き（2回目の停止は通す）になる」という内容を書く
- `HARNESS_STRICT_STOP=0` の語は3節にこの1か所だけ書く（基準2は出現数1を見る）
- 承認済みの計画票が0件なら Stop フックが何もしない（`main` で未コミットの変更があっても止めない）ことを、同じ箇条書きの中か「困ったとき」に1文書いてよい（任意）。書く場合も `HARNESS_STRICT_STOP=0` の語を増やさない
- 対話実行（`/run`）での既定は変わらない（`stop_hook_active` が真なら許可）。対話の行は変えない
- 他の節は変えない
