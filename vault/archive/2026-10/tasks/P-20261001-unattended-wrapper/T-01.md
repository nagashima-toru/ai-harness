# T-01 scripts/run_unattended.py を新規作成する（タイムアウト付きで HARNESS_RUN_CMD を実行）

## 目的
無人実行（cron・CI）で `claude -p "/run"` がハングしても、一定時間で子プロセスごと止めて終了コード124で返すラッパーを用意する（D-010 フェーズ7、issue #79）。

## 入力
- `vault/designs/D-010.md` フェーズ7のゴール文と決定済み
- `scripts/` 直下の既存 `*.py`（書き方の参考。例：`scripts/merge_claude_md.py`）
- `scripts/install.sh`（`scripts/*.py` を自動配布する仕組みの確認）

## 成果物
- `scripts/run_unattended.py`（新規1ファイル）

## 受け入れ基準
- `HARNESS_RUN_CMD='sleep 30' HARNESS_RUN_TIMEOUT=1 python3 scripts/run_unattended.py` が10秒以内に終了コード124で終わる。確認：実行して `echo $?` が 124
- `HARNESS_RUN_CMD='sh -c "exit 3"' python3 scripts/run_unattended.py` の終了コードが 3 になる。確認：実行して `echo $?` が 3
- タイムアウト時に標準エラーへ `run_unattended: timeout 1s` の1行が出る（`HARNESS_RUN_TIMEOUT=1` の場合）。確認：`HARNESS_RUN_CMD='sleep 30' HARNESS_RUN_TIMEOUT=1 python3 scripts/run_unattended.py 2> /tmp/P-20261001-unattended-wrapper-T-01.txt` の後、`grep -x 'run_unattended: timeout 1s' /tmp/P-20261001-unattended-wrapper-T-01.txt` がヒットする
- `HARNESS_RUN_CMD`・`HARNESS_RUN_TIMEOUT` を未設定にした時の既定値が、コード上で `claude -p "/run"` と 3600 になっている。確認：`grep -n '3600' scripts/run_unattended.py` がヒットし、`grep -n 'claude -p' scripts/run_unattended.py` がヒットする（動作確認は上の実行で行い、既定の `claude` は呼ばない）
- import が python3 の標準ライブラリだけである。確認：`grep -nE '^(import|from) ' scripts/run_unattended.py` の出力が標準ライブラリのみ
- `bash scripts/smoke.sh` の最終行が `fail=0` になる

## 決定済み
- 検査対象ファイルの範囲：変更してよいのは `scripts/run_unattended.py` と、このタスク票自身（`vault/tasks/P-20261001-unattended-wrapper/T-01.md` の「進捗」）だけ。宣言外ファイルの変更は verifier が `git status --porcelain` で検査する（`vault/log/`・`vault/verdicts/`・計画票は run が更新するので除外）。`scripts/smoke.sh`（T-02 の担当）・`docs/runbook.md`・SKILL.md は変更しない
- 実装は python3 の標準ライブラリだけ（macOS には `timeout` コマンドが標準で無いため）。`subprocess.Popen(..., start_new_session=True)` で新しいプロセスグループを作り、`os.killpg` で止める
- `HARNESS_RUN_CMD` は `shlex.split` で分割して実行する（シェルを経由しない）。既定は `claude -p "/run"`（`shlex.split` で `['claude', '-p', '/run']`）
- `HARNESS_RUN_TIMEOUT` は秒（整数）。既定 3600。数値でない・0以下の値は標準エラーにメッセージを出して終了コード2で終わる
- タイムアウト時：プロセスグループに SIGTERM → 10秒待つ → まだ終わらなければ SIGKILL → 終了コード124。標準エラーに `run_unattended: timeout <秒>s` を1行出す。vault のファイル（log など）には書かない（状態の書き込みはオーケストレーターに集約するため）
- 時間内に終わった時は子プロセスの終了コードをそのまま返す。シグナルで死んだ子（`returncode` が負）は `128 + シグナル番号` にして返す
- コマンドが見つからない（`FileNotFoundError`）時は標準エラーにメッセージを出して終了コード127
- 孫プロセスの終了確認は T-02（smoke.sh）が行う。ここではグループ全体に送ることだけを守る
- 対話実行（人が `/run` を打つ場合）の運用は変えない。Agent 呼び出しをバックグラウンドで監視する方式は実装も調査もしない
- 確認に実際の `claude` は呼ばない。`scripts/*.py` は `install.sh` が自動で配布対象にするので、`install.sh` の変更は不要
- 一時ファイルは固定パス `/tmp/P-20261001-unattended-wrapper-T-01.txt` を使い、`rm -rf` は使わない
