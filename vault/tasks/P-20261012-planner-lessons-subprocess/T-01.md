# T-01 経緯集に python3 -c 内の subprocess の教訓と経緯を足す

## 目的
`.claude/agents/planner.md` の「## やらないこと」に #196 で足した「確認コマンドを `python3 -c` の中の subprocess で外部コマンドを呼ぶ形にしない」教訓に対応する項目を、経緯集の「## ルール」節に1つ足す（Issue #195）。

## 入力
- `vault/rules/planner/ai-harness-lessons.md`（既存項目の書式。末尾の項目は「確認コマンドの grep パターンにシェルの特殊文字を入れない」）
- `.claude/agents/planner.md` の「## やらないこと」の `python3 -c` の箇条（読むだけ。変えない）

## 成果物
- `vault/rules/planner/ai-harness-lessons.md`（1ファイル。「## ルール」節の末尾に1項目を追記）

## 受け入れ基準
- 教訓の行が1行ある：`grep -c '^\*\*確認コマンドを .python3 -c. の中の subprocess で外部コマンドを呼ぶ形にしない\*\*$' vault/rules/planner/ai-harness-lessons.md` の出力が `1`
- 経緯の行が、導入先・計画・タスク・回避・Issue・取り込み先の計画と PR をこの順で1行に含む：`grep -c '^- 経緯：.*spring-batch-ai-coding-samples.*P-20261011-harness-rules.*T-05.*git show.*#187.*P-20261012-planner-no-subprocess-in-python.*#196' vault/rules/planner/ai-harness-lessons.md` の出力が `1`
- 新しい項目が既存の末尾項目（シェルの特殊文字）の直後にある：`grep -A3 '^\*\*確認コマンドの grep パターンにシェルの特殊文字を入れない' vault/rules/planner/ai-harness-lessons.md | grep -c 'python3 -c'` の出力が `1`
- 太字の教訓の項目が10個から11個になる：`grep -c '^\*\*' vault/rules/planner/ai-harness-lessons.md` の出力が `11`
- 既存の行（「## 目的」「## 確認方法」を含む）を1行も消さず、追記は3行（空行・教訓・経緯）だけ：対象 worktree で `git diff --merge-base work/p-20261012-planner-lessons-subprocess --numstat -- vault/rules/planner/ai-harness-lessons.md` の出力が、追加 `3`・削除 `0`・パス `vault/rules/planner/ai-harness-lessons.md` の1行

## 決定済み
- 追記する位置は「## ルール」節の末尾、「**確認コマンドの grep パターンにシェルの特殊文字を入れない**」の項目（とその「- 経緯：」行）の後、空行1行を挟んで置く。その後に既存の空行と「## 確認方法」が続く形にする
- 教訓の行はこの文言そのままにする：`**確認コマンドを `python3 -c` の中の subprocess で外部コマンドを呼ぶ形にしない**`（`python3 -c` はバッククォートで囲む。行頭・行末は `**`）
- 「- 経緯：」行は1行だけにし、次の語をこの順で含める：`nagashima-toru/spring-batch-ai-coding-samples` → `P-20261011-harness-rules` → `T-05` → `git show` → `#187` → `P-20261012-planner-no-subprocess-in-python` → `#196`。文例（この文のまま使ってよい）：
  `- 経緯：導入先 nagashima-toru/spring-batch-ai-coding-samples の計画 `P-20261011-harness-rules` の T-05 で、planner が書いた `python3 -c "...subprocess.check_output(['git','show',...])..."` の受け入れ基準が creator の worktree でツールの制限により拒否され、creator は `git show` を単独で実行してファイルに保存し、比較式の読み込み元を差し替えて確かめた（verifier は通った）。Issue #187 として ai-harness に移され、`P-20261012-planner-no-subprocess-in-python`（PR #196）で `.claude/agents/planner.md` に教訓を足した。`
- `.claude/agents/planner.md`、経緯集の「## 目的」「## 確認方法」と既存の項目は変えない
- 経緯集は `vault/rules/` 配下で smoke の `(ref-1)` の対象外なので、バッククォート内に存在しないパスがあっても smoke は落ちない。それでもパスとして存在しないものは上の文例以上に足さない
- 「成果物以外を変えていない」ことは差分ゲート（`scripts/transition.py`）に任せる
