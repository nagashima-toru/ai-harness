# T-04 stop_gate.py に未コミット差分の Stop 検査を追加する

## 目的
作業ステップごとのコミットを構造で強制するため、`git status --porcelain` が非空（未コミットの変更がある）ならセッションの終了をブロックする。非 git リポジトリ・クリーンな作業ツリーなら、この検査を素通りして既存の判定に進む。

## 入力
- `.claude/hooks/stop_gate.py`（改訂対象）
- `scripts/smoke.sh`（`== stop_gate.py ==` セクションに新規ケースを追加）
- `vault/designs/D-001.md` の「## フェーズ5」

## 成果物
- `.claude/hooks/stop_gate.py`（未コミット差分検査ロジックの追加）
- `scripts/smoke.sh`（新規 smoke ケース2件の追加。同一コミットで対応してよい）

## 受け入れ基準
- `git status --porcelain` の出力が非空ならブロックする。確認：新規 smoke ケース「未コミットの差分がある → ブロック」が `ok`
- 非 git リポジトリ、またはクリーンな作業ツリーならこの検査を素通りし既存の判定に進む。確認：新規 smoke ケース「クリーンな作業ツリー → 許可（既存判定へ進む）」が `ok`
- ブロック理由に、作業ステップごとにコミットしてから終了する旨の文言が含まれる。確認：`grep -c 'コミット' .claude/hooks/stop_gate.py` が1以上
- 既存の `stop_gate.py` の smoke ケース（verdict の形式検査・attempt 照合・PASS/FAIL 判定など）がすべて引き続き通る
- `bash scripts/smoke.sh | tail -1` が `fail=0` を含む

## 決定済み
- 検査を置く位置：`stop_hook_active` による早期 allow の直後、`approved` な計画票の有無を見る（`plans = approved_plans(root)` 以降の分岐）より前。doing/review タスクの有無に関わらず、作業ツリーが汚れていれば常にブロックする（コミット漏れを計画の状態に関係なく検出するため）
- 実装は `subprocess.run(["git", "status", "--porcelain"], cwd=root, capture_output=True, text=True)` を使う。`returncode != 0`（非 git リポジトリ）ならこの検査を素通りする。標準出力を `strip()` して空文字列ならクリーンとみなし素通りする
- ブロック文言の例：`[stop_gate] 未コミットの変更があります。作業ステップごとにコミットしてから終了してください（git status --porcelain の出力を確認）`
- smoke ケースの作り方：`TMP` 内で `git init -q && git config user.email t@example.com && git config user.name t` した上で、1件目は追跡されていないファイルを1つ作ってから検証（block）、2件目は `git add -A && git commit -q -m x` してクリーンな状態にしてから検証する（この時 `approved` な計画票が無い状態にしておけば、素通り後の「plans が0件 → 許可」まで確認できる）
- 既存の smoke ケース（`TMP` に git を初期化しないまま実行しているもの）が今まで通り動くことが「非 git リポジトリは素通り」の確認を兼ねる
