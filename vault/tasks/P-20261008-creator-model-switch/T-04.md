## 決定済み
- 書く場所は7節だけ。`creator=` の値の決め方は既存の「モデルの値は `.claude/agents/<name>.md` の frontmatter の `model` とする」の文と、transition.py の段落の「`creator=`・`verifier=` は…frontmatter の `model` からスクリプトが自動で付ける」の文を直す形にする（新しい段落を足してもよいが、元の文と矛盾を残さない）
- `usage_stats.py` の段落は、`model_stats.py` の出力の段落（「出力はタブ区切りで、1行目を見出し…verifier のモデル別の集計は出さない」）の直後に置く。見出しは model_stats と同じく、タブを含むバッククォートで書く
- `resolvedModel` は完全なモデル ID（例：`claude-sonnet-5`）で、log の `creator=` の alias（例：`sonnet`）とは表記が違うことを一言書く
- 1節（ディレクトリ）には scripts の一覧が無い（`model_stats.py` も載っていない）ので、1節は変えない。12節も変えない
- run の手順（`.claude/skills/run/SKILL.md`）の説明はここに重ねて書かない
- `scripts/`・`.claude/`・`docs/runbook.md` は変えない
