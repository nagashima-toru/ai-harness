# T-01 verifier.md の note の書式の例を merge-base の形にする

## 目的
`.claude/agents/verifier.md` の「手順」7の note の書式の例を、収集コミットの後でも空にならない `git diff --merge-base work/<計画IDの英小文字> --numstat -- README.md` の形にする（GitHub Issue #183）。

## 入力
- `.claude/agents/verifier.md`（「## 手順」の7、29行目）
- `.claude/agents/planner.md` の「## やらないこと」の、差分の確認を `main` と比べない指針（`git diff --merge-base work/<計画IDの英小文字> --name-only` の形の説明）

## 成果物
- `.claude/agents/verifier.md`（1ファイル。「手順」7の1行だけを変える）

## 受け入れ基準
- `grep -c 'git diff --merge-base work/.計画IDの英小文字. --numstat -- README.md' .claude/agents/verifier.md` の出力が `1`
- `grep -c 'git diff --numstat -- README.md' .claude/agents/verifier.md` の出力が `0`
- 対象 worktree の中で `git diff --merge-base work/p-20261011-verifier-note-merge-base --numstat -- .claude/agents/verifier.md` を実行した出力が、`1	1	.claude/agents/verifier.md`（追加1行・削除1行）の1行だけである（収集コミットの後でも、この形の差分が空にならないことの確認を兼ねる）
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (agents-1) '` の出力が `1`
- `bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` を含む

## 決定済み
- 変えるのは29行目の書式の例の中のコマンド部分だけ。変更後の29行目は次の1行と完全に一致させる（エスケープしたバッククォート `\`` の書き方と `/ 出力: 1 0 README.md` は今のまま残す）：
  `7. 各行の `note` に、確認に使ったコマンド（または確認方法）と出力の要点を必ず書く（空にしない）。書式の例：`実行コマンド: \`git diff --merge-base work/<計画IDの英小文字> --numstat -- README.md\` / 出力: 1 0 README.md`。出力は判定に使った部分だけを1〜3行に要約する`
- 収集コミットの説明や理由の文を verifier.md に足さない（Issue #183 は例を揃えることだけを求めている）。ほかの行・節は変えない。
- `<計画IDの英小文字>` はプレースホルダのまま書く（具体的な計画 ID に置き換えない）。smoke の `(ref-1)` は `<` を含むバッククォート内の文字列を検査しないので、プレースホルダのままで NG にならない。
- smoke の `(agents-1)` は verifier.md に「起点コミット」の語が無いことを見る。この語を書かない。
- 3つ目の基準は対象 worktree の中で実行する前提（計画ブランチ上で実行すると空になる）。出力の区切りはタブ。
- `.claude/agents/planner.md` の同種の例は T-02、`docs/vault-spec.md` は T-03 で扱うので、このタスクでは変えない。

## 進捗
- 読んだルール: vault/rules/common/vision.md
- verifier.md 29行目の例を merge-base の形に変更。全基準の確認コマンドを実行し通過（1 / 0 / numstat 1行 / ref-1=1 / agents-1=1 / fail=0）
