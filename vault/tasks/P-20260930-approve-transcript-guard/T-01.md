# T-01 settings.json の deny に gh pr merge・glab mr merge・claude を追加し smoke.sh に確認を足す

## 目的
エージェントがマージを実行することと、入れ子で `claude -p "/plan approve ..."` を起動して子セッションの会話記録に人の発言を偽造することを、`.claude/settings.json` の deny で止める。D-010 フェーズ4（#75 その1）の最初の防御。

## 入力
- `vault/designs/D-010.md` フェーズ4（決定済み）
- `.claude/settings.json`（`permissions.deny`）
- `scripts/smoke.sh` の `== merge_settings_json.py ==` 節付近と、settings.json を読む既存ケース

## 成果物
- `.claude/settings.json` の変更と `scripts/smoke.sh` への確認ケース追加（1PR分の関連する2ファイル変更）

## 受け入れ基準
- `permissions.deny` に `Bash(gh pr merge*)` がある。確認：`jq -e '.permissions.deny | index("Bash(gh pr merge*)")' .claude/settings.json` が終了コード0で数値を出す
- `permissions.deny` に `Bash(glab mr merge*)` がある。確認：`jq -e '.permissions.deny | index("Bash(glab mr merge*)")' .claude/settings.json` が終了コード0で数値を出す
- `permissions.deny` に `Bash(claude *)` がある。確認：`jq -e '.permissions.deny | index("Bash(claude *)")' .claude/settings.json` が終了コード0で数値を出す
- 既存の deny エントリ15件が残り、合計が18件になる。確認：`jq '.permissions.deny | length' .claude/settings.json` の出力が `18`
- `scripts/smoke.sh` に `(approve-settings)` 接頭辞のケースが3つ（上記3エントリ）あり、`bash scripts/smoke.sh > /tmp/P-20260930-approve-transcript-guard-T-01-smoke.txt 2>&1` の後、`grep -c '^  NG' /tmp/P-20260930-approve-transcript-guard-T-01-smoke.txt` が `0`、`tail -1 /tmp/P-20260930-approve-transcript-guard-T-01-smoke.txt` が `smoke: pass=<N> fail=0`

## 決定済み
- 追加する3エントリの文字列はこのとおり（前後の空白・末尾の `*` も含めて一致させる）：`Bash(gh pr merge*)`・`Bash(glab mr merge*)`・`Bash(claude *)`。`deny` 配列の末尾に足す
- `allow` の `Bash(gh pr *)` は変えない（deny が allow より優先される）。allow の変更（`npm` 等を外す）は D-010 フェーズ10の担当で、ここでは触らない
- `docs/runbook.md` の `claude -p "/run"`（人が cron・CI から起動する無人実行）は、エージェントのセッション外の操作なので影響しない。runbook は変更しない
- smoke.sh のケースは `expect_eq`（`== merge_claude_md.py ==` 節で定義）または既存の `jq` を使うケースの書き方に合わせる。settings.json のパスは smoke.sh 内で使われている `$ROOT/.claude/settings.json` の形に揃える
- `merge_settings_json.py` は src の deny を導入先に足すだけなので変更しない。既存の merge 系ケースが deny の件数など固定値で失敗したら、期待値だけを追随させる
- `permissions.deny` はフックで守れない範囲（`python3 -c` から子プロセスを起動するなど）が残る。これは残存リスクとして今回は扱わない（勝手に広げない）
