# T-06 pr_body.py が transition.py の done のコミット（review→done・複数 id）も辿れるようにする

## 目的
`scripts/pr_body.py` のタスク履歴表の commit 列は、件名が `^<計画ID>/<id>: done$` のコミットだけを探すため、`scripts/transition.py` が作る done のコミット（`<計画ID>/<id>: review→done`、複数 id なら `<計画ID>/T-01,T-02: review→done`）を辿れない。両方の件名に当たるよう、探すパターンを直す（フェーズ5で run が transition.py を使い始める前に直しておく）。

## 入力
- `scripts/pr_body.py`（`commit_of` の `git log --grep`）
- `scripts/transition.py` のコミットの件名の作り方（`"%s/%s: %s→%s" % (plan_id, ",".join(ids), old, target)`）
- `docs/vault-spec.md` の1節（タスク履歴表の説明）
- `vault/tasks/P-20261007-transition-worktree/fixtures/pr_body.sh`（確認用のフィクスチャ。作るコミットの件名と期待値はファイル先頭のコメント）

## 成果物
- `scripts/pr_body.py`（このファイルだけ。ほかのファイルは変えない）

## 受け入れ基準
- 従来の件名・transition.py の件名・複数 id の件名のどれでも done のコミットが出る：`bash vault/tasks/P-20261007-transition-worktree/fixtures/pr_body.sh` の出力に `exit=0` があり、stdout 節に `| T-01 | A | <want_T-01 の値> | - |`・`| T-02 | B | <want_T-02 の値> | - |`・`| T-03 | C | <want_T-03 の値> | - |`・`| T-04 | D | <want_T-04 の値> | - |` の4行がある
- done でないコミット・別の id・行末の違う件名には当たらない：同じ出力の stdout 節に `| T-05 | E | - | - |` があり、T-02 の行のハッシュが `want_T-02` の値（行末が違う c8 ではない）
- 使い方と出力の形が変わらない：`python3 scripts/pr_body.py` の終了コードが2。`python3 scripts/pr_body.py P-20261007-diff-gate` の出力の1行目が `## タスク履歴` で、表の見出しが `| id | title | commit | verdict |`
- 既存の smoke が変わらず通る：`bash scripts/smoke.sh 2>&1 | tail -1` の出力が `smoke: pass=594 fail=0`

## 決定済み
- `commit_of` の `git log` を `--extended-regexp`（`-E`）にし、パターンを `^<計画ID>/([^:]*,)?<id>(,[^:]*)?: (review→)?done$` にする。これで `<計画ID>/<id>: done`（従来の run）・`<計画ID>/<id>: review→done`（transition.py）・`<計画ID>/T-01,T-02: review→done`（複数 id）のどれにも当たり、`T-05` が `T-050` に当たることはない（id の直後は `,` か `:` に限る）
- 計画 ID と id は、ERE の特殊文字（`.[]()*+?{}|^$\`）の前に `\` を付けてからパターンに入れる（`re.escape` は ERE で意味が変わる文字にも `\` を付けるので使わない）
- 当たるコミットが複数あれば、今と同じく `-n 1` で最新の1つを出す
- `transition.py` のコミットの件名と、フェーズ2の smoke のケースは変えない
- 先頭の docstring に、探す件名の形（従来の `: done` と transition.py の `: review→done`、複数 id）を1〜2行で書き足す
- 標準ライブラリだけ・Python 3.9 で動く書き方。出力の形・引数・終了コードは変えない
- smoke のケース（両方の件名で履歴表に done のコミットが出ること）は T-04 で `scripts/smoke.sh` に足す。`docs/vault-spec.md` 1節の「`<計画ID>/<id>: done` コミット」の記述は T-05 で直す。このタスクでは `scripts/smoke.sh`・`docs/vault-spec.md`・`scripts/vcs_finish.sh`・`scripts/transition.py` を変えない。フィクスチャ `pr_body.sh` は変えない
