# T-02 archive_plans.sh と smoke の archive_plans 節を消す

## 目的
`scripts/archive_plans.sh` を廃止し、scripts 配下からその参照を無くす。archive_plans.sh で確かめていた「引用符付きの status を読む」検査は purge_plan.sh --merged で確かめ直す。

## 入力
- `vault/designs/D-016.md` の「フェーズ2」
- `scripts/archive_plans.sh`
- `scripts/smoke.sh` の `== archive_plans.sh ==` 節（`ar_init`・`ar_plan`・`ar_commit`・`ar_branch`・`ar_run`・`ar_clean` と `(ar-1)` 以降）と、`== hooklib-rules（D-011 フェーズ2） ==` 節の `# e` の項目（`ar_*` を使う `(hooklib-rules) archive_plans.sh: ...` のテスト）
- T-01 で足した `scripts/purge_plan.sh --merged --list`

## 成果物
- `scripts/archive_plans.sh`（主な成果物。ファイルを削除する）
- `scripts/smoke.sh`（archive_plans 節の削除と hooklib-rules の `# e` の差し替え）

## 受け入れ基準
1. `scripts/archive_plans.sh` が作業ツリーにも git の管理にも無い。確認：`git ls-files scripts/archive_plans.sh` の出力が空、`ls scripts/archive_plans.sh` が終了コード2（No such file）
2. scripts 配下と .claude 配下に `archive_plans` の語が無い。確認：`grep -rn 'archive_plans' scripts .claude` の出力が空
3. smoke の hooklib-rules 節に、引用符付きの `status: "done"` の計画を `purge_plan.sh --merged --list` が対象にし、インデントした done でない行を持つ計画を対象にしないことを確かめるテストがあり、ok になる。確認：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (hooklib-rules) purge_plan.sh --merged --list: status: "done"（引用符付き）の計画を対象にする$'` が `1`
4. T-01 の `(pm-1)`〜`(pm-6)` が全部 ok のまま。確認：`bash scripts/smoke.sh 2>&1 | grep -cE '^  ok   \(pm-[1-6]\) '` が `6`
5. smoke 全体が通る。確認：`bash scripts/smoke.sh 2>&1 | tail -1` が `smoke: pass=<数> fail=0` の形

## 決定済み
- `scripts/archive_plans.sh` は `git rm` で消す（中身を空にして残さない）
- smoke の `echo "== archive_plans.sh =="` から次の `echo "== _hooklib.py =="` の直前までを丸ごと消す（`AR_OUT`・`AR_ERR` の変数と `ar_*` の関数を含む）
- hooklib-rules 節の `# e` は、`ar_*` を使わない形に書き直す。用意は元のテストと同じ趣旨：計画 `P-20260101-q`（frontmatter が `status: "done"`、タスク表が全行 done）と、計画 `P-20260102-q2`（status は done だが、タスク表の行頭を半角空白でインデントした review の行を持つ）を main にコミットし、作業ブランチ `work/p-20260109-cur` に切り替えて `bash "$ROOT/scripts/purge_plan.sh" --merged --list` を実行する。期待値は標準出力が `P-20260101-q` の1行だけ。テスト名はそのまま次にする：`(hooklib-rules) purge_plan.sh --merged --list: status: "done"（引用符付き）の計画を対象にする`
- 一時リポジトリは smoke の `$TMP` の下に作る。git のコミットには T-01 の節の `pp_git`（user.name/email を付ける関数）を使ってよい（hooklib-rules 節は purge_plan.sh 節より後にある）
- `(ms-2)`（`model_stats.py` が既定で `vault/archive/` 配下を読まないことのテスト）と、install.sh のマニフェストのテスト（`vault/archive/` で始まるパスがマニフェストに無いことの検査）は、パスの例として archive を使っているだけなのでそのまま残す（D-016 の決定済み）
- `scripts/model_stats.py` は変えない（docstring の `vault/archive/` の記述も残す。D-016 の決定済み「model_stats.py のコードは変えない」）
- docs・README の `archive_plans` の記述はこのタスクでは直さない（T-04〜T-06 で直す）。`scripts/install.sh`・`scripts/uninstall.sh` の archive の記述も T-03 で直す
- 導入先に既に配られた `archive_plans.sh` を `install.sh --update` で消す仕組みは足さない（ゴールの範囲外）
- （/plan unblock の回答）T-04・T-05 で docs の archive_plans 参照は除去済み。最新の計画ブランチから作り直し、smoke 全体の fail=0 を確認する
