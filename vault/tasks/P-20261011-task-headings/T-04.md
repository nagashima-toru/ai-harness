# T-04 creator.md に「## 進捗」見出しが無い時の追記の手順を書く

## 目的
タスク票に「## 進捗」の見出しが無い時、creator が見出し無しで末尾に追記すると「決定済み」節の変更と判定され差分ゲートで差し戻される（Issue #166）。見出しごと足してから追記する手順を creator の定義に書く。

## 入力
- `.claude/agents/creator.md`（「## 手順」の4）
- `scripts/diff_gate.py`（`_split_sections`・`_non_progress`：直前の節の本文の末尾の空行まで比べる）

## 成果物
- `.claude/agents/creator.md`（1ファイル）

## 受け入れ基準
- `grep -c '見出しごと末尾に足してから追記する' .claude/agents/creator.md` の出力が `1`
- `grep -c '既存の行を1文字も変えず、末尾に空行1つを挟んで' .claude/agents/creator.md` の出力が `1`
- 上の2つの文言が「## 手順」節の中にある（`grep -n` の行番号が `## 手順` の行と次の `## ` 見出し行の間にある）
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`
- `bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` で終わる

## 決定済み
- 「## 手順」の4（「進めながら「進捗」に箇条書きで追記する。…」）の後ろに、次の内容の文を足す。2つの文言 `見出しごと末尾に足してから追記する` と `既存の行を1文字も変えず、末尾に空行1つを挟んで` をそのまま含める：タスク票に「## 進捗」の見出しが無ければ、既存の行を1文字も変えず、末尾に空行1つを挟んで `## 進捗` の行を足し、見出しごと末尾に足してから追記する（見出しが無いまま追記したり空行を挟まなかったりすると、直前の「決定済み」節の変更と判定され差分ゲートで差し戻される）
- 手順の番号は振り直さない（4の中に書き足すか、4の直下の箇条にする）
- 「## 書き込んでよいもの」の「進捗」の行に「（見出しが無ければ見出しを足すことを含む）」と補ってよいが必須ではない
- ほかの節は変えない
- バッククォートで囲むパスは実在するものだけにする（`(ref-1)` が検査する）
- 「成果物のみで他ファイル不変」の確認は書かない（差分ゲートに任せる）

## 進捗
- 読んだルール: vault/rules/common/vision.md
- .claude/agents/creator.md の手順4に、見出しが無い時の追記手順を足した
- 受け入れ基準5件の確認コマンドを実行し全て通過（grep 1/1、行番号は手順節内の21行目、ref-1 は1、smoke は pass=502 fail=0）
