# ゴール

`docs/vision.md` を新規作成し、「目的」「原則」「非ゴール」の見出しでこのハーネスの理念を書く。「目的」にはこのハーネスが解決する問題（AI エージェントの成果物を別コンテキストの検証エージェントが受け入れ基準で採点し、PASS しない限り完了扱いにしない、状態をファイルに集約してセッション断でも再開できるようにする、等）を書く。「原則」には既に README・docs/decisions.md・vault-spec.md から読み取れる恒久的な方針（作成→検証の二段構成／状態はvault/のファイルに集約／5状態固定で変更は必ずログに残す／質問は着手前にまとめて聞き着手後はblockedで止める／人が最終決定権を持つ／ドメイン知識はvault/rules/の拡張点に分離する／1セッション=1計画=1ブランチ）を1件1行で列挙する。「非ゴール」にはマルチユーザー化・SaaS化・GUI化をしないこと、汎用のプロジェクト管理・タスク管理ツールになることを目指さないこと、Claude Code以外のランタイムへの対応を現時点では目指さないことを書く。README.md の「目的」節（既存4行のbulleted list）はそのまま残し、末尾に `docs/vision.md` へのリンクを1行追加する。

本計画は `vault/designs/D-009.md` のフェーズ1（唯一のフェーズ、依存なし）を実行する。
