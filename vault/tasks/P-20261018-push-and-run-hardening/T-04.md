# T-04 計画の差分が `/code-review` を通過する

## 目的
T-01〜T-03 で変えた計画全体の差分を `/code-review` で確かめ、致命的な指摘があれば直す。直した後も計画全体の動作（smoke）が壊れていないことを確かめる。

## 入力
- 計画全体の差分：`git -C <worktree のパス> diff --merge-base <ベースブランチ>`
- `.claude/agents/creator.md`・`.claude/agents/verifier.md` の「コードレビューを参照する基準」の節
- T-01〜T-03 のタスク票（`vault/tasks/P-20261018-push-and-run-hardening/`）

## 成果物
- 主な成果物：計画の差分への修正（致命的な指摘が無ければ変更なし）
- 変えてよいファイル（先行タスクの「成果物」の宣言のすべて）：
  - `scripts/vcs_finish.sh`
  - `scripts/smoke.sh`
  - `docs/vault-spec.md`
  - `.claude/skills/run/SKILL.md`
  - `.claude/agents/planner.md`

## 受け入れ基準
- `/code-review` で計画の差分に致命的な指摘が残っていない
- smoke 全体が通る：`bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` で終わる
- 上流あり・先行の push の検査が通る：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (push-9) '` の出力が `1`
- 文書のパス参照が壊れていない：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`
- 古い記述（上流が無い時だけ push する）がリポジトリに残っていない：`grep -rn --exclude-dir=vault --exclude-dir=.git --exclude-dir=worktrees '上流が無' .` の出力が空

## 決定済み
- レビューの範囲は、ベースブランチ（`HARNESS_BASE_BRANCH`、前後の空白を除いて空なら `main`）との分岐点からの計画全体の差分（`git -C <worktree のパス> diff --merge-base <ベースブランチ>`）とする
- 計画一式4種（`vault/plans/`・`vault/tasks/`・`vault/verdicts/`・`vault/log/`）はレビューの対象にしない
- 致命的な指摘が無ければ成果物を変えず、「進捗」への記録だけでよい（「進捗」の追記が収集コミットになるので、新規コミット無しの blocked にはならない）
- 差分の外（既存コード）への指摘・致命的でない指摘・設計や仕様の変更が要る指摘の扱いは、`.claude/agents/creator.md`・`.claude/agents/verifier.md` の「コードレビューを参照する基準」の節に従う
- 古い記述の検索で除外するディレクトリと理由は T-01 と同じ：`vault/`（計画票・タスク票が古い記述を引用している）、`.git`（git の内部）、`worktrees`（メインリポジトリの `.claude/worktrees/` にあるほかの worktree）
