# T-0012 install.sh にルール拡張ポイントの複製対象を追加する

## 目的
`scripts/install.sh` が `vault/rules/` の雛形（README・4ディレクトリの `.gitkeep`）、`vault/templates/rule.md`、`scripts/rules.sh` をインストール先へ複製するようにする。

## 入力
- `scripts/install.sh`（現状の複製ロジック。`copy_if_absent` 関数、`.claude/`・`vault/`・`scripts/smoke.sh`・`docs/vault-spec.md`・`CLAUDE.md` の複製部分）
- `vault/rules/README.md`、`vault/rules/{common,creator,verifier,planner}/.gitkeep`、`vault/templates/rule.md`、`scripts/rules.sh`（既存。複製対象として存在確認済み）
- `docs/roadmap-rules-extension.md` の「## ⑦ install.sh と README」節（T-a の受け入れ基準の候補・決定済み）

## 成果物
- `scripts/install.sh`（複製対象の追加のみ。`scripts/smoke.sh` には手を入れない）

## 受け入れ基準
- `scripts/install.sh` が `vault/rules/README.md`、`vault/rules/common/.gitkeep`、`vault/rules/creator/.gitkeep`、`vault/rules/verifier/.gitkeep`、`vault/rules/planner/.gitkeep`、`vault/templates/rule.md`、`scripts/rules.sh` を `copy_if_absent` で複製している（確認：`grep -c 'copy_if_absent' scripts/install.sh` が変更前より増えている、かつ `grep -c 'vault/rules' scripts/install.sh` ≥ 1）
- 空の一時ディレクトリへ `bash scripts/install.sh <tmp>` を実行すると、上記7ファイルすべてが `<tmp>` 配下に存在する（確認コマンド：`tmp=$(mktemp -d) && bash scripts/install.sh "$tmp" && ls "$tmp/vault/rules/README.md" "$tmp/vault/rules/common/.gitkeep" "$tmp/vault/rules/creator/.gitkeep" "$tmp/vault/rules/verifier/.gitkeep" "$tmp/vault/rules/planner/.gitkeep" "$tmp/vault/templates/rule.md" "$tmp/scripts/rules.sh"`）
- 同じ一時ディレクトリへ2回目の `bash scripts/install.sh "$tmp"` を実行すると、出力に上記7ファイルぶんの `skip` 行が含まれ `copy` 行は含まれない（確認コマンド：`bash scripts/install.sh "$tmp" | grep -E 'rules|rule.md'` の各行が `skip` で始まる）
- `git diff --stat -- scripts/smoke.sh` の出力が空である（`scripts/smoke.sh` を変更していない）

## 決定済み
- 複製対象は `vault/rules/README.md`、`vault/rules/common/.gitkeep`、`vault/rules/creator/.gitkeep`、`vault/rules/verifier/.gitkeep`、`vault/rules/planner/.gitkeep`、`vault/templates/rule.md`、`scripts/rules.sh` の7ファイルで確定。`vault/rules/` 配下のそれ以外のファイル（人が書く実ルール）は複製・上書きの対象にしない
- 実装方法は既存の `vault/` 複製ループ（`for f in tasks/.gitkeep ...`）へ項目を追加するか、新規ループを1つ足すかは実装者の判断でよい。いずれも `copy_if_absent` を経由させること
- `vault/rules/{common,creator,verifier,planner}/` ディレクトリ自体は `copy_if_absent` 内の `mkdir -p "$(dirname "$2")"` で作られるため、別途 `mkdir -p` を足す必要はない
- `scripts/rules.sh` は `.claude/hooks/*.py` のような実行権限付与（`chmod +x`）は不要（呼び出し側は常に `bash scripts/rules.sh ...` で実行する）
- `scripts/smoke.sh` へのテストケース追加はこのタスクでは行わない（ロードマップの決定どおり）

## 進捗
- `bash scripts/rules.sh creator` を実行（着手時のルール読み込み手順）。出力は空だったため何もしていない
- `scripts/install.sh` を更新。`vault/` 複製ループに `templates/rule.md`・`rules/README.md`・`rules/{common,creator,verifier,planner}/.gitkeep` を追加、`scripts/rules.sh` を `smoke.sh` と並べて複製対象に追加
- コメントを2箇所追記（複製対象の説明、vault/rules/ の複製方針）
- 受け入れ基準4件の確認コマンドをすべて実行し通過：copy_if_absent=7件（既存6件から増加）、vault/rules 言及1件、一時dirへの1回目実行で7ファイルすべて存在、2回目実行で7ファイルすべてskip、`git diff --stat -- scripts/smoke.sh` は空。`bash scripts/smoke.sh` は変わらず pass=40 fail=0
