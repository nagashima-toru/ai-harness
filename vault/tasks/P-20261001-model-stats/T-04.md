# T-04 smoke.sh に model_stats と補足付き log のテストを足す

## 目的
model_stats.py の集計と SKILL.md の記述を smoke で固定し、`creator=`/`verifier=` 付きの log が log を読むフックを壊さないことを担保する。

## 入力
- `scripts/smoke.sh`（末尾の `run_unattended.py` 節の書き方・`pass`/`fail` の使い方に合わせる）
- `scripts/model_stats.py`（T-02）、`.claude/skills/run/SKILL.md`（T-03）、`docs/vault-spec.md` 7節（T-01）
- `.claude/hooks/stop_gate.py`・`.claude/hooks/plan_guard.py`・`.claude/hooks/agent_write_guard.py`（log を扱う箇所の確認）

## 成果物
- `scripts/smoke.sh`（新しい節 `== model_stats.py ==` の追加のみ。既存節は変えない）

## 受け入れ基準
- フィクスチャ log（sonnet で1回目 PASS 1件、haiku で2回目 PASS 1件と blocked 1件。`worktree path=...` 行と、`creator=` の無い既存形式のタスクを混ぜる）に対する `model_stats.py` の出力が、見出し行と各モデル行の期待値（タブ区切り・小数2桁）と一致することを確認する検査が追加されている
- 引数なしの `python3 scripts/model_stats.py` が現在の `vault/log/*.md` に対して終了コード0になり、`vault/archive/` 配下は既定の対象に含まれないことを確認する検査が追加されている
- `.claude/skills/run/SKILL.md` に `creator=` と `verifier=` の記述があり、`docs/vault-spec.md` に `verifier=` の記述があることを確認する検査が追加されている
- `creator=<モデル>`・`verifier=<モデル>` 付きの遷移行を含む log とタスク表のある一時リポジトリ（または一時ディレクトリ）で `stop_gate.py`・`plan_guard.py` を実行しても、補足のせいで失敗しない（クラッシュせず、期待する allow/block の判定が変わらない）ことを確認する検査が追加されている
- `bash scripts/smoke.sh | tail -1` が `smoke: pass=<n> fail=0` になり、終了コードが0である

## 決定済み
- smoke.sh に触るのはこの計画でこのタスクだけ。T-01〜T-03 は smoke.sh を変更しない
- 追加は末尾の `echo; echo "smoke: pass=..."` の直前に新節として入れる。既存の検査・カウンタの仕組み（`PASS_N`・`FAIL_N`）に従う
- フィクスチャは一時ディレクトリに作り、検査後に削除する。実際の `vault/log/` は書き換えない
- 期待値は集計の定義から計算する（sonnet：tasks=1・first_pass_rate=1.00・avg_attempt=1.00・blocked_rate=0.00。haiku：tasks=2・first_pass_rate=0.00・avg_attempt は最後の遷移行の attempt の平均・blocked_rate=0.50。フィクスチャの attempt に合わせて計算して書く）
- log を読むフックのうち、log の内容を解析するものがあるかは入力のフックを読んで確認する。`stop_gate.py` は log に追記するよう指示文に書くだけで内容を読まない想定だが、実際に新しい補足付きの log を置いた状態で実行して確認する検査にする。フックの本体は変更しない（変更が必要になったら blocked にして question に書く）
- 集計の定義・出力形式・既定対象は `docs/vault-spec.md` 7節と D-010 フェーズ8 の決定済みに従う。verifier のモデル別の集計は出さない

## 進捗
- 読んだルール: git.md, roles.md, creator.md, git-workflow.md
- scripts/smoke.sh 末尾に `== model_stats.py ==` 節を追加（ms-1 集計出力一致、ms-2 引数なし rc0・archive 除外、ms-3 SKILL.md/vault-spec の記述、ms-4 補足付き log で stop_gate/plan_guard の判定不変）
- 集計キーは最後の doing→review の creator（spec 7節）なので、フィクスチャの blocked は review→blocked にした
- `bash scripts/smoke.sh | tail -1` → smoke: pass=370 fail=0
