## 受け入れ基準
- Bash コマンドが `git commit` を含み、対象ディレクトリの現在のブランチが `main` の時、`agent_type` を問わず（メインエージェント含む）deny する判定が追加されている。確認：新規 smoke ケース `main で git commit → 拒否` が block
- 現在のブランチが `main` 以外（例：`work/...`）の場合はこの判定では拒否しない（他の既存判定は従来どおり）。確認：新規 smoke ケース `work ブランチで git commit → 許可` が allow
- 対象ディレクトリが git リポジトリでない、または現在のブランチを取得できない場合はこの判定をスキップする（fail-open）。確認：既存の `== agent_write_guard.py ==` の全ケース（非 git な `$TMP` を使うもの）が従来どおり通る

- `bash scripts/smoke.sh | tail -1` が `fail=0` を含む

## 決定済み
- 判定の実装方針：`active_doing_review_task_ids` の後段、既存の「改ざん防止：agent_type を問わず vault/rules/ 拒否」ブロックと同じ場所（`agent not in ALLOWED` の早期リターンより前）に、新しい独立した判定を追加する。実装イメージ：
  ```python
  GIT_COMMIT_PATTERN = r"\bgit\s+commit\b"

  def current_branch(root):
      import subprocess
      try:
          out = subprocess.run(
              ["git", "-C", root, "rev-parse", "--abbrev-ref", "HEAD"],
              capture_output=True, text=True, timeout=5,
          )
      except Exception:
          return None
      if out.returncode != 0:
          return None
      branch = out.stdout.strip()
      return branch or None
  ```
  `tool == "Bash"` かつ `re.search(GIT_COMMIT_PATTERN, cmd)` の時だけ `current_branch(root)` を呼び、戻り値が文字列 `"main"` と一致する場合だけ deny する。`None`（非 git リポジトリ・エラー・detached HEAD で判定不能）の場合は何もしない（次の判定に進む）
- deny メッセージの例：`f"[agent_write_guard] main への直接コミットはできません。ブランチを切ってください（work/p-xxx-<slug>）: {cmd[:120]}"`
- この判定は `vault/rules/` 判定とは独立。両方に該当する場合は先に判定した方が deny すればよく、順序の厳密な取り決めは無い
- smoke.sh の新規ケースは、既存の `$TMP`（非 git ディレクトリ）とは別に専用の一時ディレクトリを使う（既存ケースを壊さないため）。手順の目安：
  ```bash
  GTMP="$(mktemp -d)"
  git -C "$GTMP" init -q -b main
  git -C "$GTMP" -c user.email=t@example.com -c user.name=t commit -q --allow-empty -m init
  expect_guard "main で git commit → 拒否" deny \
    "$(printf '%s' '{"tool_name":"Bash","tool_input":{"command":"git commit -m x"}}' | CLAUDE_PROJECT_DIR="$GTMP" python3 "$GUARD_HOOK")"
  git -C "$GTMP" checkout -q -b work/test
  expect_guard "work ブランチで git commit → 許可" allow \
    "$(printf '%s' '{"tool_name":"Bash","tool_input":{"command":"git commit -m x"}}' | CLAUDE_PROJECT_DIR="$GTMP" python3 "$GUARD_HOOK")"
  rm -rf "$GTMP"
  ```
  （`agent_type` を付けない＝メインエージェント想定。`expect_guard` 名は上記の日本語文言に正確に一致させる）
- `.claude/settings.json` の追加行は、既存の `"Bash(git push * -f*)",` の直後に `"Bash(git push --force-with-lease*)",` を挿入する
- `stop_gate.py`・`vault/rules/creator/git-workflow.md`・`run-queue` SKILL・`install.sh`・ドキュメント類は変更しない（それぞれ T-0031・T-0033〜T-0035 の範囲）
- git commit はしない（人が確認してからコミットする）
