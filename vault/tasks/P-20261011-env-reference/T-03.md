# T-03 README.md から docs/configuration.md へリンクする

## 目的
利用者が `README.md` から環境変数リファレンス `docs/configuration.md` に辿れるようにする。

## 入力
- `README.md`（「- 人が日々やることは `docs/runbook.md`…」の箇条書きと、構成の表の `docs/` の行）
- `docs/configuration.md`（T-01 の成果物）
- `vault/designs/D-20261011-user-guide.md`（決定事項：導入先に配らない）

## 成果物
- `README.md`（1ファイル）

## 受け入れ基準
- README の箇条書きに `docs/configuration.md` へのリンクがある：`grep -cF -e '- 指定できる環境変数（`HARNESS_*`）の一覧は [docs/configuration.md](docs/configuration.md) を参照' README.md` が `1`
- README の構成の表に行がある：`grep -cxF '| `docs/configuration.md` | 環境変数リファレンス |' README.md` が `1`
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` が `1`
- `bash scripts/smoke.sh 2>&1 | tail -1` が `smoke: pass=<数> fail=0` の形
- `docs/configuration.md` を導入先に配らない（install.sh の配布対象を変えていない）：`grep -c 'configuration.md' scripts/install.sh` が `0`

## 決定済み
- 箇条書き：「- 無人で回す場合は `python3 scripts/run_unattended.py` を…」の行の直後に、次の1行をこの文言のまま足す：
  `- 指定できる環境変数（`HARNESS_*`）の一覧は [docs/configuration.md](docs/configuration.md) を参照`
- 構成の表：`| `docs/runbook.md` | 運用手順 |` の行の直後に `| `docs/configuration.md` | 環境変数リファレンス |` を足す
- それ以外の README の記述は変えない
- `scripts/install.sh` は変えない（設計文書の決定事項：`docs/configuration.md` は導入先に配らず ai-harness リポジトリで読む）。受け入れ基準5はゴールの範囲としてリポジトリの配布スクリプトを見るもの
- フェーズ2の `docs/guide.md` へのリンクはこのタスクでは足さない（次の計画）
