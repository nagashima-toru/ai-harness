## 決定済み
- 12節の「### サンドボックス（OS による書き込みと通信の制限）」の見出しを「### サンドボックス（使っていない）」に変え、本文（見出しの次から「### 提案ファイル方式」の直前まで）を次の内容に置き換える（空行は見出しの後と本文の後に1つずつ）
  - 本文の1行目は、次の「」の中をこのまま書く（`.claude/settings.json` と `sandbox` はバッククォートで囲む）：「このリポジトリでは Claude Code のサンドボックスを使っていない（`.claude/settings.json` に `sandbox` キーは無い）。」
  - 箇条書き「理由」：サンドボックスが守っていたのは `vault/rules/` と会話記録（`~/.claude/projects/`）への Bash の書き込みで、D-015 でどちらも守る対象から外した。一方で `.claude/` の保護パス・`.git`・`gh` の TLS・`mktemp` での詰まりと、サンドボックスの外で動かすコマンドの例外の積み増しを生んでいた（この箇条書きに `excludedCommands` の語は書かない）
  - 箇条書き「一時ファイル」：スクリプトは今までどおり `mktemp [-d] "${TMPDIR:-/tmp}/<名前>.XXXXXX"` の形で作り、作れない時は中断する（D-013 の書き方を戻さない）
  - 箇条書き「導入先」：`merge_settings_json.py` は導入先の settings.json に `sandbox` を足さない。導入先で有効にする手順は `docs/install.md` の「サンドボックスを有効にする（任意）」
  - 箇条書きは上の3つだけ（本文の1行目と合わせて4行。小節は見出し・空行を含めて `sed` の出力で8行以下になる）
- 2節の done（review→done）の説明：「サンドボックスの中で後始末に失敗した時は、run が `bash scripts/discard_worktree.sh` で消す（`.claude/skills/run/SKILL.md` の「worktree の後始末（サンドボックス）」、12節の「サンドボックス」）。」の1文だけを削る。ほかの文は変えない
- 5節の `done` の説明（`permissions.deny` で `gh pr merge` を止める段落）：「あわせて `Bash(claude *)` も deny する。」から「…防ぐため。」までの2文だけを削る。`Bash(gh pr merge*)`・`Bash(glab mr merge*)` の文は残す
- 12節の「Bash の書き込み対象の解析」の「残る弱点：」の最初の文（「Bash とその子プロセスの … 解析は当面削らず残す）。」）を「サンドボックスは使っていない（「サンドボックス（使っていない）」の小節）ので、Bash の書き込みへの守りはこの解析だけになる。」に置き換える。「以下は Bash の解析としての弱点：」以降は変えない
- 上に挙げた以外の節（`vault/rules/` の保護・提案ファイル方式・会話記録の検査など）は変えない。それらは D-015 フェーズ2〜5 で直す
- 見出しの名前を変えるのは12節のサンドボックスの小節だけで、見出しの数は変えない
