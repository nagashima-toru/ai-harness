## 目的
`vault/rules/common/git.md`（T-0030）で決めた「未コミットの変更を残したままセッションを終えてはならない」を、Stop フックで機械的に強制する。

## 受け入れ基準
- `stop_hook_active` によるバイパスの直後、既存の doing/review 判定より前に、対象ディレクトリが git リポジトリかつ `git status --porcelain` が非空なら、commit / stash / restore のいずれかで処理するよう促すメッセージでブロックする判定が追加されている。確認：新規 smoke ケース `未コミット差分あり → ブロック` が block
- 対象ディレクトリに `.git` が無い、または `git status` がエラーになる場合はこの判定をスキップし既存の判定に進む（fail-open）。確認：既存の `== stop_gate.py ==` の全ケース（非 git な `$TMP` を使うもの）が従来どおり通る
- git リポジトリで作業ツリーがクリーンな場合はこの判定でブロックせず既存の判定に進む。確認：新規 smoke ケース `未コミット差分なし → 既存判定に進む` が、doing/review 行が無い `$TMP` で allow になる
- `bash scripts/smoke.sh | tail -1` が `fail=0` を含む

## 決定済み
- 実装位置：`main()` 内、`if payload.get("stop_hook_active") and not STRICT: allow()` の直後、`root = project_dir(payload)` の後に追加する（`root` は既存の `project_dir()` の戻り値をそのまま使う）
- 実装イメージ：
  ```python
  import subprocess

  def has_uncommitted_changes(root):
      if not os.path.isdir(os.path.join(root, ".git")):
          return False
      try:
          out = subprocess.run(
              ["git", "-C", root, "status", "--porcelain"],
              capture_output=True, text=True, timeout=5,
          )
      except Exception:
          return False
      if out.returncode != 0:
          return False
      return bool(out.stdout.strip())
  ```
  `has_uncommitted_changes(root)` が真の時だけ、以下でブロックしてから残りの処理に進ませない：
  ```python
  if has_uncommitted_changes(root):
      block(
          "[stop_gate] 未コミットの変更が残っています。"
          "commit / stash（`git stash push -m \"<理由>\"`）/ restore のいずれかで処理してから終了すること。"
      )
  ```
  `.git` が無い・`git status` がエラー・タイムアウトの場合は `False` を返し（fail-open）、既存の判定（`todo.md` が無ければ allow、以下略）にそのまま進む
- smoke.sh の新規ケースは、既存の `$TMP`（非 git ディレクトリ、他の全ケースで使い回す）とは別に専用の一時ディレクトリを使う（既存ケースを壊さないため）。手順の目安：
  ```bash
  SGTMP="$(mktemp -d)"
  git -C "$SGTMP" init -q -b main
  git -C "$SGTMP" -c user.email=t@example.com -c user.name=t commit -q --allow-empty -m init
  echo dirty > "$SGTMP/x.txt"
  expect "未コミット差分あり → ブロック" block \
    "$(printf '%s' "$DEFAULT_STDIN" | CLAUDE_PROJECT_DIR="$SGTMP" HARNESS_MAX_ATTEMPTS=3 python3 "$STOP_HOOK")" "commit"
  rm -f "$SGTMP/x.txt"
  expect "未コミット差分なし → 既存判定に進む" allow \
    "$(printf '%s' "$DEFAULT_STDIN" | CLAUDE_PROJECT_DIR="$SGTMP" HARNESS_MAX_ATTEMPTS=3 python3 "$STOP_HOOK")"
  rm -rf "$SGTMP"
  ```
  （`$SGTMP` に `vault/todo.md` が無いので、既存ロジックにより doing/review 無し＝許可になる。`expect` 名は上記の日本語文言に正確に一致させる）

- git commit はしない（人が確認してからコミットする）
