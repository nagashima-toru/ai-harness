# T-02 planner.md の形式の不変を見る例を merge-base の形にする

## 目的
`.claude/agents/planner.md` の、形式の不変を見る確認コマンドの例 `git diff -- vault/plans/<計画ID>.md | grep ...`（作業ツリーと比べる形で、収集コミットの後は空になる）を `git diff --merge-base work/<計画IDの英小文字> -- ...` の形に揃える。

## 入力
- `.claude/agents/planner.md`（「## やらないこと」の1項目め、64行目。68行目の差分の確認の指針も参考）

## 成果物
- `.claude/agents/planner.md`（1ファイル。64行目の例の1か所だけを変える）

## 受け入れ基準
- `grep -c 'git diff --merge-base work/.計画IDの英小文字. -- vault/plans/' .claude/agents/planner.md` の出力が `1`
- `grep -c 'git diff -- vault/plans/' .claude/agents/planner.md` の出力が `0`
- 対象 worktree の中で `git diff --merge-base work/p-20261011-verifier-note-merge-base --numstat -- .claude/agents/planner.md` を実行した出力が、`1	1	.claude/agents/planner.md`（追加1行・削除1行）の1行だけである
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (agents-1) '` の出力が `1`
- `bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` を含む

## 決定済み
- 64行目の例の中の `git diff -- vault/plans/<計画ID>.md` を `git diff --merge-base work/<計画IDの英小文字> -- vault/plans/<計画ID>.md` に置き換えるだけ。後ろの `| grep -E '^[+-](## |\| id )'` と、例の前後の文は変えない。対象のパス（`vault/plans/<計画ID>.md`）も変えない。
- 変更後の64行目の末尾は ``例：`git diff --merge-base work/<計画IDの英小文字> -- vault/plans/<計画ID>.md | grep -E '^[+-](## |\| id )'` の出力が空`` になる。
- `<計画IDの英小文字>`・`<計画ID>` はプレースホルダのまま書く。`(ref-1)` は `<` を含むバッククォート内の文字列を検査しない。
- 収集コミットの説明を64行目に足さない（68行目の指針に説明がある）。ほかの行は変えない。
- smoke の `(agents-1)` は planner.md に「起点コミット」の語が無いことを見る。この語を書かない。
- `docs/vault-spec.md` の同じ例は T-03 で扱うので、このタスクでは変えない。
- 3つ目の基準は対象 worktree の中で実行する前提（計画ブランチ上で実行すると空になる）。出力の区切りはタブ。
