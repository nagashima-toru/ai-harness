# T-02 導入先の既存の settings.json に sandbox が入らないことを smoke で確かめる

## 目的
`scripts/smoke.sh` に、ハーネス側の `.claude/settings.json` に `sandbox` があっても、導入先の既存の `.claude/settings.json` には `merge_settings_json.py`・`install.sh`・`install.sh --update` のどれでも `sandbox` キーが足されないことを確かめるケースを足す。

## 入力
- `vault/designs/D-013.md` の「フェーズ5 サンドボックスを有効にする」（受け入れ基準の候補の2つ目）
- `scripts/smoke.sh` の「merge_settings_json.py」節（1295行目付近）と「install.sh の settings.json 扱い」節（1404行目付近。(o)・(p)・(al-6) のケース）
- `scripts/merge_settings_json.py`（読むだけ）
- T-01 で足した `.claude/settings.json` の `sandbox`

## 成果物
- `scripts/smoke.sh`（1ファイル。ケースの追加だけ）

## 受け入れ基準
- 既存の smoke と追加したケースが全件通る：`bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` を含む
- 決定済みの (sb-1)〜(sb-4) のケースが smoke にあり、すべて通る：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (sb-'` の出力が `4`（あわせて Read で、決定済みの4つの観点がそれぞれケースになっていることを確認）
- 追加したケースは、このリポジトリの `.claude/settings.json` に `sandbox` があることを前提にしていない：(sb-1)・(sb-2) の src は smoke の中で作った `sandbox` 入りのフィクスチャで、`$ROOT/.claude/settings.json` の `sandbox` を読む・期待値にする箇所が無い（Read で確認。`grep -n 'ROOT/.claude/settings.json.*sandbox' scripts/smoke.sh` の出力が空）
- 既存の install.sh の settings.json のケースが今どおり通る：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (o) \|^  ok   (p) \|^  ok   (al-6) '` の出力が `7`

## 決定済み
- 足すケース（名前は `(sb-<番号>)` で始める。`expect_eq` を使う。「install.sh の settings.json 扱い」節の直後に `echo "== sandbox を導入先に入れない =="` の見出しを付けて置く）：
  - (sb-1) フィクスチャの src（`$ROOT/.claude/settings.json` を読み、`sandbox` を `{"enabled": true}` に置き換えて書いたもの）に `sandbox.enabled` が `True` で入っている（前提の確認）
  - (sb-2) `sandbox` の無い既存の dst（`$ROOT/.claude/settings.json` から `sandbox` を除いて書いたもの）に、(sb-1) の src で `merge_settings_json.py` を実行した後、dst に `sandbox` キーが無い
  - (sb-3) `sandbox` の無い `.claude/settings.json` を先に置いた一時ディレクトリに `bash "$ROOT/scripts/install.sh" <一時ディレクトリ>` を実行した後、導入先の `.claude/settings.json` に `sandbox` キーが無い
  - (sb-4) (sb-3) の導入先に `install.sh --update` を実行した後も、`sandbox` キーが無い
- `sandbox` キーの有無は `python3 -c "import json;print('sandbox' in json.load(open('<パス>')))"` の形で確かめ、期待値は `False`（(sb-1) は `sandbox.enabled` を出して `True`）
- smoke は導入先にも配られるので、このリポジトリの `.claude/settings.json` に `sandbox` があるかどうかで結果が変わらないように書く（フィクスチャは `sandbox` を足したり除いたりして作る。`sandbox` が無い時に除こうとしてエラーにならないよう `pop('sandbox', None)` の形にする）
- 新規導入（導入先に `.claude/settings.json` が無い時）のケースは足さない。今の `merge_settings_json.py` は src をそのまま書くので `sandbox` が入る（計画票の人への質問1。回答に合わせて承認の前にこの票を書き直す）
- 既存のケース（(o)・(p)・(al-6) など）は変えない
- 一時ディレクトリは既存のケースと同じく `mktemp -d` で作り、後片付けも既存のケースと同じ書き方（smoke の中の `rm -rf "$WTMP"` の形）にする
- `scripts/merge_settings_json.py`・`scripts/install.sh`・`.claude/settings.json` は変えない
