# T-01 merge_claude_md.py が src からマーカーブロックだけを抜き出して使う

## 目的
`scripts/merge_claude_md.py` が src の `CLAUDE.md` 全体ではなく、マーカーブロック（`<!-- ai-harness:begin ... -->` 〜 `<!-- ai-harness:end -->`）だけを create・merge・update・skip に使うようにし、src のマーカーの外の行が導入先に配られないようにする。

## 入力
- `scripts/merge_claude_md.py`（今は `BLOCK_RE` をマーカーの有無の確認にしか使わず、src 全体を block として書いている）
- `scripts/unmerge_claude_md.py`（逆処理。参考）
- `scripts/smoke.sh` の `== merge_claude_md.py ==` 節（`(a)`〜`(d)` の検査）
- `CLAUDE.md`（このリポジトリの src。後続の T-03 でマーカーの外に `@docs/vision.md` が足される）

## 成果物
- `scripts/merge_claude_md.py`（主な成果物。1ファイル）
- `scripts/smoke.sh`（`== merge_claude_md.py ==` 節に `(mc-out)` の検査を足す）

## 受け入れ基準
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (mc-out) '` が `5`
- `bash scripts/smoke.sh 2>&1 | grep -c '^  NG '` が `0`（既存の `(a)`〜`(g)`・uninstall の `(s)` を含め、全検査が通る）
- `python3 -c "import sys; sys.path.insert(0, 'scripts'); import merge_claude_md as m; print(repr(m.extract_block('# 前置き\n<!-- ai-harness:begin v1 -->\nX\n<!-- ai-harness:end -->\n@docs/vision.md\n')))"` の出力が `'<!-- ai-harness:begin v1 -->\nX\n<!-- ai-harness:end -->\n'`
- `python3 -c "import sys; sys.path.insert(0, 'scripts'); import merge_claude_md as m; print(repr(m.extract_block('no marker\n')))"` の出力が `None`
- `python3 scripts/merge_claude_md.py scripts/rules.sh vault/tasks/P-20261010-vision-local-only/no-such/CLAUDE.md 2>&1 | grep -c 'src にハーネスのマーカーが無い'` が `1`（src にマーカーが無い時の既存の挙動が保たれる。この実行の後も `vault/tasks/P-20261010-vision-local-only/no-such/` は作られていない）

## 決定済み
- 関数 `extract_block(text: str) -> str | None` を `scripts/merge_claude_md.py` のモジュールの最上位に足す。`BLOCK_RE` の最初の一致（`<!-- ai-harness:begin` から最初の `<!-- ai-harness:end -->` まで）を取り、末尾に改行1つを付けた文字列を返す。一致が無ければ `None`。`main` はこの戻り値を block として create・merge・update・skip のすべてに使う（src のマーカーの前後の行は一切使わない）
- src にブロックが2つ以上あっても最初の1つだけを使う。dst 側の扱い（`BLOCK_RE.sub(..., count=1)` で最初のブロックだけ置換・空なら merge・それ以外は末尾に追記）、バックアップ、出力の書式（`create|merge|update|skip <dst>`）、終了コード（0・1・2）は変えない
- モジュールの docstring を「src はハーネス側の CLAUDE.md。そのうちマーカーブロックだけを使い、マーカーの外の行は配らない」という趣旨に直す
- `scripts/unmerge_claude_md.py` は変えない（dst のブロックだけを除く処理で、src を読まないため）
- smoke の `(mc-out)` は次の5件にする。名前は先頭を `(mc-out) ` にし、`expect_eq` を使う。フィクスチャは既存の `$MTMP` の下の新しいサブディレクトリ（例：`$MTMP/out`）に `printf` で作る。src のフィクスチャは `# 前置き` の行・マーカーブロック（`<!-- ai-harness:begin v1 -->`・`# 見出し`・`@.claude/ai-harness.md`・`<!-- ai-harness:end -->`）・`@docs/vision.md` の行の順にする
  1. `(mc-out) create でマーカーの外の行が配られない`：dst が無い状態で実行し、dst の中身がマーカーブロックの4行と完全に一致する
  2. `(mc-out) merge でマーカーの外の行が配られない`：既存本文のある dst に実行し、`grep -c '^@docs/vision\.md$'` と `grep -c '^# 前置き$'` がどちらも `0`
  3. `(mc-out) update でマーカーの外の行が配られない`：ブロックを含む dst（ブロックの中身を変えたもの）に実行し、出力が `update` で、`^@docs/vision\.md$` の行が `0`
  4. `(mc-out) ブロックが同じなら skip`：3 の後にもう一度実行して出力が `skip`
  5. `(mc-out) リポジトリの CLAUDE.md から create しても @docs/vision.md が入らない`：`$ROOT/CLAUDE.md` を src に、無い dst へ実行し、`^@docs/vision\.md$` の行が `0`（今は自明に通る。T-03 で意味を持つ）
- smoke の既存の検査の名前・期待値は変えない
- 一時ファイルは smoke の既存の仕組み（`$TMP`・`smoke_tmpdir`）の下に置く。`rm -rf` を新たに書かない
