## 決定済み
- 確認の範囲から外すもの（理由）：`docs/decisions.md`（判断の記録で、過去の行は書き換えない）、`vault/archive/`・`vault/plans/`・`vault/tasks/`・`vault/log/`・`vault/verdicts/`・`vault/designs/`（履歴と状態）、`vault/harness-improvements/`（提案の元。T-07 で消す）。受け入れ基準の grep はこれらを対象に入れていない。3つ目と4つ目の grep は `scripts/smoke.sh` も外す（T-04 の `(run-skill-2)` と T-05 の `(agents-1)` が「その語が無いこと」を確かめるために `gh issue create`・`起点コミット` の字面を持つため）
- `docs/vault-spec.md` の直し方
  - 1節の表に1行足す：パス `` `vault/harness-improvements/<計画ID>.md` ``、内容「run の振り返り（`.claude/skills/run/SKILL.md` 手順8）で issue の起票に失敗した時の改善提案。提案に対応した計画が、その計画の中で削除する。5状態遷移の対象ではない」。この節で `vault/harness-improvements/<計画ID>.md` の字面を使う
  - 1節の `HARNESS_PR_BODY_FILE` の段落：GitHub は `gh api -X POST repos/<owner>/<repo>/pulls -f title=<タイトル> -f head=<ブランチ> -f base=main -F body=@<パス> --jq .html_url`（REST）を呼ぶ、と書く（`gh api -X POST repos/<owner>/<repo>/pulls` の字面はこの1か所だけ）。あわせて、owner/repo は origin の URL の最後の2つの区切りから取り、取れなければ push の前に終了コード2で終わること、作った PR の URL を標準出力に出すこと、base は `main` 固定であること、計画が見つからない引数なしの時は最新コミットの件名と本文で作ること、引数がある時は `gh pr create` にそのまま渡すことを書く（実際の動きは `scripts/vcs_finish.sh` を正とする）。GitLab の記述は変えない
  - 2節の `/run` の箇条の「例外として、計画票の frontmatter の approved→done（手順7）は Edit で行い」に、その後 `git add vault/plans/<計画ID>.md` と名前を指定した `git commit` でコミットしてから `scripts/vcs_finish.sh` を呼ぶ（`vcs_finish.sh` は計画票の変更をコミットしないため）、を足す。`git add vault/plans/<計画ID>.md` の字面は vault-spec.md の中でこの1か所だけ
  - 5節の判定の順の1つ目を `vault/plans/`・`vault/log/`・`vault/verdicts/` の3つにし、「`vault/rules/` 配下は特別扱いせず、宣言があれば許し、無ければ違反（D-015 で保護をやめたため）」の1行を、`.claude/hooks/` などの特別扱いしない行の近くに足す
  - 6節の `reasons` の「次の3つの記録」を「次の2つの記録」にし、「宣言外ファイルの変更を検出した場合」の箇条を消す（宣言外の変更は差分ゲートが review・done への遷移で止める）
  - 11節：「ただし creator のタスクの成果物にはできない（…）。ルールの追加・変更はタスクにせず、人が編集する（…）」を、「creator のタスクでも「成果物」に宣言すれば変えられる（宣言の無い変更は差分ゲートが差し戻す。5節）」の趣旨に直す
  - 12節の (b) の行の対象を「Bash のコマンドを `&&`・`||`・`;`・`|`・改行で区切った各部分の先頭が `git commit`（`git -C <パス> commit` のように `git` のオプションを挟む形を含む）で、現在のブランチが `main`」にし（この字面のまま）、結果の欄の「正規表現の簡単な判定で、引用符の中などの誤検知は許容する」を「引用符の中の区切り文字では区切らず、引用符の中の文字列（`grep -n "git commit" …` など）は拒否しない。`env`・変数代入の前置き、`bash -c` やサブシェルの中は見ない」の趣旨に直す（実際の動きは `.claude/hooks/agent_write_guard.py` を正とする）
- `docs/runbook.md` の直し方
