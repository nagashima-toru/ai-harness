# T-03 run の SKILL.md に起動通知が返った時の待ち方と10分のハング基準を書く

## 目的
`run_in_background: false` を指定しても creator・verifier の Agent 呼び出しがバックグラウンドで起動して即座に戻る時に、run が完了通知を待ってから後続の手順に進み、出力ファイルの更新が10分止まればハングとして既存の手順で復旧できるようにする。

## 入力
- `vault/designs/D-20261010-async-agent-wait.md`（決定事項・フェーズ1の決定済み）
- `.claude/skills/run/SKILL.md`（手順3・手順5・「ハング時の復旧」）

## 成果物
- `.claude/skills/run/SKILL.md`（1ファイル）

## 受け入れ基準
- 手順3に、起動通知が返った時はターンを終えて完了通知を待つ行がある：`awk '/^## 3\. /{s=1;next} /^## /{s=0} s&&/起動通知/&&/完了通知/&&/ターンを終え/{n++} END{print n+0}' .claude/skills/run/SKILL.md` の出力が `1` 以上
- 手順5に、同じ趣旨の行がある：`awk '/^## 5\. /{s=1;next} /^## /{s=0} s&&/起動通知/&&/完了通知/&&/ターンを終え/{n++} END{print n+0}' .claude/skills/run/SKILL.md` の出力が `1` 以上
- 「ハング時の復旧」に、出力ファイルの最終更新から10分進まなければ TaskStop で止める行がある：`awk '/^## ハング時の復旧/{s=1;next} /^## /{s=0} s&&/10分/&&/出力ファイル/&&/TaskStop/{n++} END{print n+0}' .claude/skills/run/SKILL.md` の出力が `1` 以上
- 同期の呼び出しの目安15分と `run_in_background: false` の指定が残っている：`grep -c '応答なしとみなす目安は15分' .claude/skills/run/SKILL.md` の出力が `1`、かつ ``grep -c '`run_in_background: false` を指定し' .claude/skills/run/SKILL.md`` の出力が `2` 以上
- `grep -rln --exclude-dir=worktrees CLAUDE_CODE_DISABLE_BACKGROUND_TASKS .claude` の出力が空
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`

## 決定済み
- 手順3の2（creator の呼び出し）と手順5の1（verifier の呼び出し）の「`run_in_background: false` を指定し、完了を同期的に待つ」は消さない。その後ろか直後の項目に、「それでも Agent ツールの結果が起動通知（バックグラウンド起動）だった時は、そのタスクを結果待ちとして扱い、ターンを終えて完了通知を待つ。完了通知が来るまで手順4（手順5の場合は手順6）に進まない」旨を書く。「起動通知」「完了通知」「ターンを終え」の3語を同じ1行（1つのリスト項目）に書くこと
- 起動通知の見分け方は、Agent ツールの結果に「Async agent launched」「バックグラウンド」等の起動を表す文言があり、成果物の完了報告（creator の「blocked: ...」や完了の要約、verifier の完了の報告）が無いこと、と書く。文言の完全一致に頼らない書き方にする
- 複数タスクを1メッセージで並行に呼んだ時、一部だけ起動通知で返った場合は、起動通知で返ったタスクの完了通知がすべて来るまで、そのタスクについて後続の手順に進まない（同期で返ったタスクは従来どおり進めてよい）。手順4は計画票の上から順に1件ずつ呼ぶ既存の規則のまま
- 「ハング時の復旧」に足す内容：バックグラウンドに回った creator・verifier の呼び出しは、起動通知に含まれる出力ファイル（transcript）の最終更新時刻（`stat` などで見る）から10分進まなければハングとみなし、TaskStop で止めて、既存の1（creator）・2（verifier）と同じ手順で扱う。出力ファイルのパスが分からない時はハングを判定せず、人に状況を報告して待つ。同期で返らない呼び出しの既存の目安（「応答なしとみなす目安は15分」の文）は据え置き、文を書き換えない。「10分」「出力ファイル」「TaskStop」の3語を同じ1行に書くこと
- `--note` は既存の補足（`creator呼び出しハングにより再試行`・`creator呼び出しハング`・`verifier呼び出しハング`）をそのまま使い、新しい補足を作らない（`docs/vault-spec.md` 7節の補足の一覧を変えないため）。早見表の行も変えない
- 環境変数 `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS` を使う指示は書かない（語そのものを書かない）
- 無人実行（`scripts/run_unattended.py`、`HARNESS_RUN_TIMEOUT`）の段落は変えない
- worktree の置き場（`.claude/worktrees/`）・`worktree.baseRef`・WorktreeCreate/WorktreeRemove フックに触れる記述は足さない
- バッククォートで囲むのは実在するパス・コマンド・書式の例にとどめる（smoke の (ref-1) がバッククォート内のパスの実在を検査するため）
