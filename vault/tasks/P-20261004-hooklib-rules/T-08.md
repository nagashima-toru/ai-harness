# T-08 archive_plans.sh の table_counts がタスク表の行頭の空白を許すようにする

## 目的
`scripts/archive_plans.sh` の `table_counts`（タスク表の行数と done でない行数を数える awk）が、行頭を半角空白でインデントしたタスク表の行も数えるようにする。フックの `parse_tasks`（`raw_rows` は strip してから判定する）と同じ規則に揃え、インデントした done でない行が「全行 done」と数えられて archive されないようにする。

## 入力
- `vault/designs/D-011.md`（フェーズ2の (3)）
- `scripts/archive_plans.sh`（`table_counts`。118〜131行目付近）
- フィクスチャ（編集しない）：`vault/tasks/P-20261004-hooklib-rules/fixtures/vault/plans/P-FIXTURE-QUOTED.md`（タスク表の2行が半角空白でインデントされ、どちらも done でない）

## 成果物
- `scripts/archive_plans.sh`（`table_counts` の awk だけの変更）

## 受け入れ基準
- 構文が正しい：`bash -n scripts/archive_plans.sh` の終了コードが0
- インデントした行を数える：`bash -c "$(sed -n '/^table_counts()/,/^}/p' scripts/archive_plans.sh); table_counts vault/tasks/P-20261004-hooklib-rules/fixtures/vault/plans/P-FIXTURE-QUOTED.md"` の出力が `2 2`
- 通常の計画票の数え方は変わらない：同じ形式で `vault/plans/P-20261004-hooklib-extract.md` を渡した出力が `6 0`
- 変更が `table_counts` の中だけである：`git diff main... -- scripts/archive_plans.sh | grep -E '^[+-]' | grep -vE '^(\+\+\+|---)' | wc -l` の出力が4以下（コミット前なら `git diff HEAD -- ...` でも同じ）
- 既存の smoke が全件通る：`bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` を含む

## 決定済み
- 直し方：`if ($0 !~ /^\|/) next` の前に、`sub(/^[ \t]+/, "")` で行頭の空白を落とす。それ以外（`c1` が `T-` で始まる行だけ数える・`done` 以外を notdone に数える）は変えない
- 「## タスク表」節への限定は、この計画の範囲外なので足さない
- 引用符付きの計画票に対する archive_plans.sh 全体の動作は T-06 の smoke で確かめる。このタスクでは smoke.sh を変更しない
- フック・`_hooklib.py`・smoke.sh・docs・`current_plan.sh` は変更しない
- T-05 と同じファイルを触るので、T-05 の後に行う
- 既存の smoke が落ちた場合は、smoke.sh を直さず blocked にして、落ちたケース名と原因を question に書く
- コミットは受け入れ基準に無いので、creator はしない
