## 決定済み
- 使い方：`python3 scripts/usage_stats.py [--plan <計画ID>] [ファイルかディレクトリ ...]`
  - 引数が無ければ既定の読み込み先：`~/.claude/projects/<プロジェクトの絶対パスの英数字以外の文字（`/`・`.`・`_` など）をすべて `-` に置き換えたもの>/*.jsonl`（`re.sub(r'[^A-Za-z0-9]', '-', path)`。Claude Code の実際の変換に合わせる。人の回答）。`~` は `os.path.expanduser`（環境変数 `HOME`）で決める。プロジェクトの絶対パスは `model_stats.py` と同じく `os.path.dirname(os.path.dirname(os.path.abspath(__file__)))`（realpath にしない）
  - ディレクトリの引数はその直下の `*.jsonl` を読む（下位のディレクトリは見ない）。ファイルの引数はそのファイルを読む
  - 存在しない引数があれば、標準エラーに `usage_stats.py: 見つかりません: <パス>` を出して終了コード1で終わる（何も出力しない）。既定の読み込み先のディレクトリが無い時は、見出し行だけを出して終了コード0
  - 引数の誤り（不明なオプション・`--plan` の値が無い）は終了コード2（argparse の既定でよい）
- 読む行：各行を JSON として読み、`toolUseResult` が辞書で、`agentType`（文字列）・`resolvedModel`（文字列）・`totalTokens`（数）・`totalDurationMs`（数）・`totalToolUseCount`（数）がそろっているものだけを1回の呼び出しとして数える。`bool` は数として扱わない。それ以外の行（JSON でない・`toolUseResult` が無い／辞書でない・キーが欠けている／型が違う・空行）は黙って読み飛ばす。ファイルが UTF-8 として読めない部分も止まらないようにする（`errors="replace"` など）
- `totalToolUseCount` を読み、末尾の列 `tool_uses_avg` に出す（人の回答。D-013 の見出しに1列足す。計画票の「人への質問」3）
- 重複：`toolUseResult` に文字列の `agentId` があれば、同じ `agentId` は全ファイルを通して最初の1回だけ数える。`agentId` が無いものは毎回数える（計画票の「人への質問」4）
- `--plan <計画ID>`：`toolUseResult` の `prompt`（文字列）から正規表現 `P-\d{8}-[a-z0-9-]+/T-\d{2}` で最初に一致したものを取り、`/` より前が `<計画ID>` と一致する呼び出しだけを数える。一致が取れない呼び出しは `--plan` の時は数えない
- 出力（タブ区切り、標準出力）：
  - 1行目の見出しは `agent	model	calls	tokens_total	tokens_avg	duration_avg_s	tool_uses_avg`
  - 2行目以降は (agentType, resolvedModel) ごとに1行。並びは agent、次に model の文字列の昇順
  - `calls`：呼び出し回数。`tokens_total`：`totalTokens` の合計（整数）。`tokens_avg`：`tokens_total ÷ calls` を小数1桁（`%.1f`）。`duration_avg_s`：`totalDurationMs` の平均を秒にして小数1桁（`%.1f`）。`tool_uses_avg`：`totalToolUseCount` の平均を小数1桁（`%.1f`）
  - `resolvedModel` は変換せずそのまま出す
  - 数える呼び出しが0件なら見出し行だけ
- 読むだけで書かない（会話記録・vault のどちらにも書かない）。標準ライブラリだけを使う
- smoke のケース（`== model_stats.py ==` の節の後ろに `== usage_stats.py ==` の節を新しく置く。名前は `(us-N) ` で始め、1つの番号につき `expect_eq` は1回だけにする。サンプルの会話記録は `$TMP` の下にヒアドキュメントか `printf` で作る。実際の会話記録の形に合わせ、1行に `{"type":"user",...,"toolUseResult":{...}}` を置く）：
  - (us-1)：2種の agentType（例：creator・verifier）と2種の resolvedModel（例：`claude-haiku-x`・`claude-sonnet-x`）を混ぜた正常な行だけのファイル → 出力全体が期待値（見出し＋各行）と一致する。平均が割り切れない値を1つ以上含める
  - (us-2)：(us-1) の行に、JSON でない行・`toolUseResult` が無い行・`toolUseResult` が文字列の行・`totalTokens` が欠けた行・`totalToolUseCount` が欠けた行・空行を混ぜたファイル → 終了コード0で、出力が (us-1) と同じ
  - (us-3)：`prompt` に `P-20990101-aa/T-01` を含む呼び出しと `P-20990101-bb/T-02` を含む呼び出し、計画 ID を含まない呼び出しを混ぜ、`--plan P-20990101-aa` → aa の分だけが集計される
  - (us-4)：`HOME` を `$TMP` の下の一時ディレクトリにし、スクリプトを `<一時ディレクトリ>/root/scripts/usage_stats.py` に複写して、`$HOME/.claude/projects/<root の絶対パスの英数字以外を - にしたもの>/a.jsonl`。root のディレクトリ名に `.` と `_` を含める（例：`my_root.v2`） にサンプルを置き、引数なしで実行 → そのサンプルの集計が出る
  - (us-5)：ディレクトリを引数に渡す → 直下の `*.jsonl`（2ファイル）を合わせて集計し、`*.jsonl` 以外の拡張子のファイルは読まない
  - (us-6)：同じ `agentId` の行を2つのファイルに置く → 1回だけ数える
  - (us-7)：存在しないパスを引数に渡す → 終了コード1
- 既存の smoke の節は変えない。`HOME` の変更はサブシェルの中か `env` で渡し、後のケースに漏らさない
- `docs/` は変えない（T-04・T-05 で行う）。`scripts/model_stats.py` は変えない
