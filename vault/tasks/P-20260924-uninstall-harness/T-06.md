# T-06 scripts/smoke.sh に uninstall.sh の回帰テストを追加する

## 目的
`scripts/smoke.sh` に `uninstall.sh`（および `unmerge_claude_md.py` / `unmerge_settings_json.py`）の回帰テストを追加し、install → 一部編集 → uninstall の一連の流れで、未編集ファイルが消え編集済みファイルが残り、利用者資産が触れられないことを継続的に検証できるようにする。

## 入力
- `/home/user/ai-harness/scripts/smoke.sh`（`== install.sh のマニフェスト ==` 節などの既存の書き方、`expect_eq` ヘルパーの使い方）
- T-03〜T-04 完了後の実際の `scripts/uninstall.sh` の出力文言・終了コード

## 成果物
- `scripts/smoke.sh`（1ファイルの更新。新規ファイルは作らない）

## 受け入れ基準
- `scripts/smoke.sh` に `== uninstall.sh ==` の見出しを持つ新しいテスト節が追加されている。確認：`grep -n '== uninstall.sh ==' scripts/smoke.sh`
- install → 1ファイル編集 → uninstall の流れをテストし、未編集のマニフェスト記録ファイルが削除され、編集したファイルが残ることを `expect_eq` 等で検証するアサーションが含まれる。確認：`bash scripts/smoke.sh` を実行し、この節に対応する PASS 行がありFAILが無い
- `vault/plans` にダミーファイルを置いた状態で uninstall した後もそのファイルが残っていることを検証するアサーションが含まれる。確認：同上の実行結果にこのケースの PASS 行がある
- `CLAUDE.md`（マーカーブロックの除去）と `.claude/settings.json`（`settings_src` を使った逆処理）のいずれもこの節でテストされている。確認：`grep -n 'unmerge_claude_md\|unmerge_settings_json' scripts/smoke.sh`
- `bash scripts/smoke.sh` を実行した時、追加した節を含め全体が PASS のみで終了する。確認：`bash scripts/smoke.sh; echo $?` の終了コードが `0` で、出力に `FAIL` を含む行が無い

## 決定済み
- テストは一時ディレクトリ（`mktemp -d`）内で完結させ、`ai-harness` 自身のリポジトリには影響を与えない（既存の `install.sh` テスト節と同じ流儀）
- `expect_eq` など既存のヘルパー関数をそのまま流用してよい。無ければ既存節の書き方に合わせて同等のアサーションを書く
- テストケース数はこのタスクの受け入れ基準に書かれた4項目（未編集削除／編集済み保持／vault資産無傷／CLAUDE.md・settings.json 逆処理）を満たせば十分で、それ以上の網羅（例：マニフェスト無し時のエラー終了）は必須ではない（追加してもよいが基準には含めない）
