# T-02 smoke を通し SKILL.md の引用と提案の一致を確認する

## 目的
T-01 の提案がマージされた計画ブランチで `bash scripts/smoke.sh` が通ることを確認する。あわせて、`.claude/skills/run/SKILL.md` が `vault/rules/common/git.md` から引いている2つの文言が提案ファイルに実在すること（出典の食い違いが反映後に解消されること）を突き合わせる。

## 入力
- `scripts/smoke.sh`（/tmp の固定パスを使うので、他タスクと並行させない）
- `vault/tasks/P-20261001-git-rules-align/T-01-proposal.md`（T-01 の成果物）
- `.claude/skills/run/SKILL.md`（72行目と76行目）

## 成果物
- smoke の実行結果（`/tmp/P-20261001-git-rules-align-T-02.txt` に書き出し、最終行をこのタスク票の「進捗」に記録する）

## 受け入れ基準
- `bash scripts/smoke.sh > /tmp/P-20261001-git-rules-align-T-02.txt 2>&1` を実行した後、`tail -1 /tmp/P-20261001-git-rules-align-T-02.txt` の出力が `fail=0` で終わる（`smoke: pass=<N> fail=0` の形）
- 提案ファイルがある（`ls vault/tasks/P-20261001-git-rules-align/T-01-proposal.md` が終了コード0）
- SKILL.md 72行目の引用文言が、SKILL.md と提案ファイルの両方にある（`grep -n 'コミットは受け入れ基準に含まれている場合だけ行う' .claude/skills/run/SKILL.md` と `grep -n 'コミットは受け入れ基準に含まれている場合だけ行う' vault/tasks/P-20261001-git-rules-align/T-01-proposal.md` がそれぞれヒットする）
- SKILL.md 76行目の引用文言が、SKILL.md と提案ファイルの両方にある（`grep -n '自己判断で解決しない' .claude/skills/run/SKILL.md` と `grep -n '自己判断で解決しない' vault/tasks/P-20261001-git-rules-align/T-01-proposal.md` がそれぞれヒットする）
- SKILL.md の出典の表記が `vault/rules/common/git.md` のまま2か所ある（`grep -c 'vault/rules/common/git.md' .claude/skills/run/SKILL.md` が `2`）

## 決定済み
- このタスクではファイルを変更しない（「進捗」への記録を除く）。smoke が `fail=0` にならない場合や、文言が一致しない場合は直さない。`blocked` にして、question に失敗したテスト名または一致しなかった文言と、出力の要点を書く。T-01 の提案ファイルは T-01 の成果物なので、このタスクでは書き換えない
- 計画作成時点の `grep -c 'vault/rules/common/git.md' .claude/skills/run/SKILL.md` は `2`（72行目と76行目）。pass の件数は基準にしない（`fail=0` だけを見る）
- 書き出し先は固定パス `/tmp/P-20261001-git-rules-align-T-02.txt`。実行前の後片付け（`rm -rf` など）は要らない（`>` で上書きされる）
- 実体 `vault/rules/common/git.md` が変わったことは検査しない（反映は人が行う）
- 人への質問で案B（SKILL.md の出典を直す）が選ばれた場合、このタスク票の基準3〜5は計画を直す時に差し替える。案A のまま着手してよい
- このタスクではコミットしない（受け入れ基準にコミットが無いため）
