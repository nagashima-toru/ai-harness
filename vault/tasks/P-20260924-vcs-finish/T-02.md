# T-02 run スキルの最終手順を vcs_finish.sh 呼び出しに置き換える

## 目的
`.claude/skills/run/SKILL.md` の最終手順（全タスク `done` 後の PR 作成、および「ハーネス振り返り」節
での言及）が直接呼んでいる `gh pr create` を、`scripts/vcs_finish.sh` の実行に置き換える。

## 入力
- `.claude/skills/run/SKILL.md`（手順7「次へ・完了」、手順8「ハーネス振り返り」の該当行）
- `vault/tasks/P-20260924-vcs-finish/T-01.md`「決定済み」（`scripts/vcs_finish.sh` の呼び出し方の契約。
  T-01 の成果物と合わせて読む）
- `vault/designs/D-005.md`（決定済み）

## 成果物
- `.claude/skills/run/SKILL.md` の更新（この1ファイルのみ）

## 受け入れ基準
- `.claude/skills/run/SKILL.md` に `gh pr create` という文字列が残っていない（手順7・8内の3箇所すべ
  てを置き換える）。確認: `grep -c "gh pr create" .claude/skills/run/SKILL.md` が0
- 手順7に `scripts/vcs_finish.sh` を実行する記述がある。確認:
  `grep -n "vcs_finish.sh" .claude/skills/run/SKILL.md` がヒットする
- `none` 判定時にスクリプトが出す案内（ブランチ名・`git merge --no-ff`）をそのまま人に伝える旨の記述
  が手順7にある。確認: `grep -n "git merge --no-ff" .claude/skills/run/SKILL.md` がヒットする
- `gh pr merge`（`glab mr merge` に触れる場合も同様）への言及はすべて「実行しない」という文脈に限ら
  れる（実行コマンドとしては現れない）。確認:
  `grep -n "gh pr merge\|glab mr merge" .claude/skills/run/SKILL.md | grep -v "実行しない"` の出力が空
- 手順1〜6の見出し文言は変更されていない。確認:
  `git diff -- .claude/skills/run/SKILL.md | grep -E '^-## [1-6]\.'` の出力が空

## 決定済み
- 呼び出しは引数無し `bash scripts/vcs_finish.sh`（現状の `gh pr create` 呼び出しも引数無しだったため
  挙動は変えない）
- 手順7：`gh pr create を実行して PR を作る` の部分を `bash scripts/vcs_finish.sh を実行する` に変え、
  終了コード0で完了した場合に計画票 frontmatter の `status` を `done` にするという既存の判定はそのま
  ま使う。`none` 判定（終了コード0・案内メッセージのみ）の場合も同じく `done` にしてよいが、標準出力
  の案内（ブランチ名・`git merge --no-ff` コマンド）をそのまま人への完了報告に含める
  （`vault/designs/D-005.md` の決定：エージェントはマージを実行しない）
- スクリプトが非0で終了した場合（`gh`/`glab` の失敗）の扱いは今回規定しない。現状の `gh pr create` 失
  敗時と同じ扱い（エラーをそのまま人に報告する）でよい
- 手順8（ハーネス振り返り）冒頭の「全タスクが `done` になり `gh pr create` で PR を作成した直後」、
  および末尾の「`gh pr create` 呼び出し手順自体は変更しない」は、いずれも `scripts/vcs_finish.sh` に
  読み替える（呼び出し名が変わるだけで、振り返りの手順自体は変えない）
- 手順1〜6（計画票を見つける〜検証する〜verdictに従う）は本タスクの対象外。触れない
