# T-07 runbook 5節の存在しないパスの参照を直す

## 目的
T-04 で書き換えた `docs/runbook.md` 5節の「対象外」の段落が、存在しないディレクトリ `vault/harness-improvements/` をバッククォートで参照しているため、smoke の `(ref-1) 主な文書のバッククォート内のパスがすべて存在する` が落ちる。この参照を直し、smoke 全体を通す。

## 入力
- `docs/runbook.md`（5節の「対象外：」で始まる段落。`` `vault/harness-improvements/` も対象外。`` の部分）
- `scripts/smoke.sh` の `(ref-1)`（`refcheck` 関数。`<...>` のプレースホルダを含むパスの扱いを確かめる）
- 同じ runbook の41行目付近の `` `vault/harness-improvements/<計画ID>.md` `` の書き方（`(ref-1)` を通っている）

## 成果物
- `docs/runbook.md`（1ファイル。5節の「対象外：」の段落の1か所だけ）

## 受け入れ基準
1. runbook に、バッククォートで囲んだ `vault/harness-improvements/`（プレースホルダ無しのディレクトリ）が無い。確認：`grep -c '`vault/harness-improvements/`' docs/runbook.md` が `0`
2. 5節の「対象外：」の段落に、run の振り返りの提案ファイルも対象外であることが残っている。確認：`grep -c '^対象外：.*vault/harness-improvements/<計画ID>\.md.*も対象外' docs/runbook.md` が `1`
3. smoke の `(ref-1)` が ok になる。確認：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` が `1`
4. 節の数が変わっていない。確認：`grep -c '^## ' docs/runbook.md` が `11`
5. smoke 全体が通る。確認：`bash scripts/smoke.sh 2>&1 | tail -1` が `smoke: pass=<数> fail=0` の形

## 決定済み
- 直し方：`` `vault/harness-improvements/` も対象外。`` を `` `vault/harness-improvements/<計画ID>.md`（run の振り返りの提案ファイル）も対象外。`` にする（41行目と同じくプレースホルダ付きの形にする）。ほかの行は変えない
- `scripts/smoke.sh`・`refcheck` は変えない（文書側を直す）
- このタスクは人の指示で計画に後から足した（T-04 の基準に smoke が無く、T-02 の smoke が落ちて blocked になったため）。T-02 は T-07 の後に作り直す
