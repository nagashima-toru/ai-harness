# T-03 ai-harness.md の禁止節にフックで拒否される旨を追記する

## 目的
`.claude/ai-harness.md` の「## 禁止」にある `done` のタスク票・verdict の編集禁止の行に、T-01 で実装したフックが実際に拒否することを示す一言を追記する。

## 入力
- `.claude/ai-harness.md`「## 禁止」節（末尾の3行。`done` のタスク票・verdict を編集すること／`rm -rf`・`git push --force` などの破壊的操作（settings.json で拒否）／計画票のタスク表の列順・見出し名を変えること（フックが表を解析する））
- T-01 の成果物 `.claude/hooks/agent_write_guard.py`（実際にフックが拒否することの一次情報）

## 成果物
- `.claude/ai-harness.md`

## 受け入れ基準
- 「## 禁止」の `done` のタスク票・verdict を編集することの行に、フックで拒否される旨の一言が追記されている。確認：`sed -n '/^## 禁止/,$p' .claude/ai-harness.md > /tmp/P-20260927-done-write-guard-T-03-sec.txt` を実行した後、`grep -c 'done.*フックで拒否' /tmp/P-20260927-done-write-guard-T-03-sec.txt` の出力が `1`
- 既存の他2行（`rm -rf`・`git push --force` の行、計画票のタスク表の列順・見出し名の行）はそのまま残っている。確認：`grep -c 'rm -rf' /tmp/P-20260927-done-write-guard-T-03-sec.txt` の出力が `1以上`、かつ `grep -c '列順・見出し名を変えること' /tmp/P-20260927-done-write-guard-T-03-sec.txt` の出力が `1以上`
- 「## 禁止」以外の見出しは変更されていない。確認：`git diff -- .claude/ai-harness.md > /tmp/P-20260927-done-write-guard-T-03-diff.txt` を実行した後、`grep -E '^[+-]## ' /tmp/P-20260927-done-write-guard-T-03-diff.txt` の出力が空
- 追記後もファイル全体の箇条書き行数（`## 禁止` 節の3行）は3行のまま増減していない（既存行への追記のみで新しい行を足していない）。確認：`grep -c '^- ' /tmp/P-20260927-done-write-guard-T-03-sec.txt` の出力が `3`

## 決定済み
- 追記対象は「## 禁止」の1行目「`done` のタスク票・verdict を編集すること」だけ。この行の末尾に `（フックで拒否される）` を追記する形にする（他2行の書き方に既にある括弧書きの体裁に揃える）
- 変更後の行の例（そのまま使ってよい）：`- \`done\` のタスク票・verdict を編集すること（フックで拒否される）`
- 他2行（`rm -rf`・`git push --force` の行、計画票のタスク表の列順・見出し名の行）の文言は変更しない。新しい行を追加するのではなく、既存の1行を書き換えるだけでよい
- 「## 禁止」以外の節（「開始時に読む順」「状態遷移」「質問のしかた」「役割」「スキル」等）は変更しない
- T-01 が `done`（`.claude/hooks/agent_write_guard.py` の実装が確定した状態）になってから着手する

## 進捗
- doing 中に作成エージェントが追記。再開時はここから読む
