# T-05 settings.json に --force-with-lease の deny を追加する

## 目的
`git push --force-with-lease` を含む破壊的な force push をフックのレベルではなく Claude Code の権限設定レベルで拒否する。

## 入力
- `.claude/settings.json`（改訂対象。`permissions.deny` に1要素追加するだけ）
- `vault/designs/D-001.md` の「## フェーズ5」

## 成果物
- `.claude/settings.json`（`permissions.deny` への1行追加）

## 受け入れ基準
- `permissions.deny` に `Bash(git push --force-with-lease*)` が含まれる。確認：`python3 -c "import json;print('Bash(git push --force-with-lease*)' in json.load(open('.claude/settings.json'))['permissions']['deny'])"` が `True`
- 既存の `deny` 要素（`git reset --hard*`・`git clean *`・`git push --force*` 等）が変更・削除されていない。確認：`git diff .claude/settings.json` に `-` で始まる行（削除）が無い
- JSON として妥当である。確認：`python3 -c "import json;json.load(open('.claude/settings.json'))"` がエラーなく終了する
- `bash scripts/smoke.sh | tail -1` が `fail=0` を含む（`merge_settings_json.py` 関連のケースを含めて影響しないことを確認する）

## 決定済み
- `permissions.deny` の配列末尾（または任意の位置）に文字列 `"Bash(git push --force-with-lease*)"` を1つ追加するだけでよい。既存の `Bash(git push --force*)` 等は重複していても外さない（デザインの決定どおり）
- 他のキー（`permissions.allow`、`hooks` 等）は一切変更しない
- `scripts/merge_settings_json.py`・`scripts/install.sh` 側の対応（インストール先への反映）は不要（このマージャは `permissions.deny` の不足分を自動で補う実装に既になっている）
