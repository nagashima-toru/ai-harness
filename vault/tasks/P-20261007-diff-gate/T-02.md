## 決定済み
- 節は最後の節（`== transition.py（D-012 フェーズ2） ==`）の後、最後の `echo` と `echo "smoke: pass=$PASS_N fail=$FAIL_N"` の前に足す。見出しは `echo "== diff_gate.py（D-012 フェーズ3） =="` の字句どおり
- 判定は既存の `expect_eq`（名前・期待値・実際の値）を使う。ケース名はすべて `(diff_gate) NN ` で始め（`NN` は下の一覧の2桁の番号）、後ろに内容を書く。1つの番号に1件以上の `expect_eq` を書いてよい（その時は同じ番号で始まる名前を複数使う）
- 一時リポジトリは `$TMP/dg` の下に作る（`$TMP` は既存の `trap` で消える）。ケースごとに `rm -rf` してから作り直すヘルパー関数（例：`dg_setup`）を節の中に定義する。形はフィクスチャ `try.sh` と同じでよい：
  - `git init -q -b main` → リポジトリ内の `git config user.name`・`user.email` → タスク票 `vault/tasks/P-TEST/T-01.md`（6見出し。「成果物」に `/` で終わるディレクトリ・`.claude/hooks/` のファイル・`vault/plans/` などのパス・パスでない文字列を含む宣言）と、ほかのファイルをコミット → `git checkout -q -b work/b` → ケースの変更をコミット
  - `diff_gate.py` は `( cd "$DG" && python3 "$ROOT/scripts/diff_gate.py" P-TEST T-01 main work/b )` の形で呼び、終了コードは `$?`、出力は `$TMP` の下のファイルに受けて見る
- 必須ケース（番号と内容。名前の後半の文言は自由）：
  - 01 宣言どおりの変更（宣言したファイル・`/` で終わる宣言の配下のファイル・宣言のある `.claude/hooks/` のファイル・自分のタスク票の「進捗」への追記）で終了コード0、出力が空
  - 02 宣言外のファイルを足すと終了コード1
  - 03 02 の出力に `<そのパス>: 「成果物」に宣言されていない` の行がある
  - 04 未コミットの変更（宣言外のファイルの追加）は対象外で終了コード0
  - 05 宣言したファイルを `git mv` で宣言外の名前にすると、新しいパスが違反として出る
  - 06 自分のタスク票の「受け入れ基準」節を変えると違反（出力に `vault/tasks/P-TEST/T-01.md: タスク票の「進捗」以外の節が変わっている`）
  - 07 自分のタスク票の最初の見出しより前（1行目）を変えると違反
  - 08 ほかのタスク票（`vault/tasks/P-TEST/T-02.md`）を宣言なしで変えると違反
  - 09 「成果物」に宣言のある `vault/plans/` 配下の変更が違反（理由が `vault/plans/ 配下は宣言があっても変更できない`）
  - 10 同じく `vault/log/` 配下
  - 11 同じく `vault/verdicts/` 配下
  - 12 同じく `vault/rules/` 配下
  - 13 branch 側でタスク票の「成果物」にパスを書き足してそのファイルを足しても、そのファイルは違反のまま（base の版で判定する）
  - 14 宣言の無い `.claude/hooks/` 配下のファイルの変更は違反
  - 15 宣言の無い `.claude/settings.json` の変更は違反
  - 16 宣言の無い `.claude/agents/` 配下の変更は違反
  - 17 base にタスク票が無い id を渡すと終了コード2
  - 18 存在しない base を渡すと終了コード2
  - 19 引数が3つだと終了コード2
  - 20 `check()` を import して呼ぶと、02 と同じ変更で違反のパスのリスト（タプルの1つ目）が返る。import は `sys.dont_write_bytecode = True` の後に `sys.path.insert(0, "$ROOT/scripts")` で行う
- 実行の前後で HEAD と `git status --porcelain` が変わらないことを、どれか1つのケースで同じ番号の `expect_eq` として見てよい（必須ではない）
- 既存のケース・ヘルパー関数・節は変えない（足すだけ）。変数・関数の名前は既存と衝突しないよう `DG`・`dg_` で始める
- `scripts/diff_gate.py`・`docs/vault-spec.md`・フィクスチャは変えない
