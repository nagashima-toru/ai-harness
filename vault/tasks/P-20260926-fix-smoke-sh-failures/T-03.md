# T-03 install.sh の複製対象から .claude/worktrees/ を除外する

## 目的
`scripts/install.sh` の `.claude/` 複製ループが `.claude/worktrees/`（`.gitignore` 済みの、実行中にだけ作られる git worktree の実体ディレクトリ。中身はリポジトリ全体の入れ子コピーになりうる）を除外していないため、リポジトリ内に未削除の worktree が残っていると新規インストール先へその中身までまるごと複製してしまう不具合を直す（issue #59）。

## 入力
- `scripts/install.sh`（変更対象。136〜138行目 `for f in $(cd "$SRC/.claude" && find . -type f ! -name 'settings.local.json' ! -name 'settings.json' | sed 's|^\./||'); do copy_if_absent ...; done`）
- `.gitignore`（5行目に `.claude/worktrees/` があり、この配下がハーネス配布物ではなく実行時の一時的な worktree 実体であることの根拠）
- 再現手順（このタスク票を書いた時点で確認済み）：`RSTMP=$(mktemp -d); bash scripts/install.sh "$RSTMP"` を実行すると、`$RSTMP/.claude/worktrees/agent-.../docs/roadmap-rules-extension.md` のように、現在このリポジトリに実在する未削除 worktree（`.claude/worktrees/agent-ad253953d267a95f7/`）の中身がまるごと複製される

## 成果物
- `scripts/install.sh` の修正（1ファイル）

## 受け入れ基準
- `.claude/` の複製ループが `.claude/worktrees` を除外している。確認コマンド: `grep -n "worktrees" scripts/install.sh` の出力が1行以上
- `RSTMP=$(mktemp -d); bash scripts/install.sh "$RSTMP" >/dev/null 2>&1` を実行した後、`$RSTMP/.claude/worktrees` が作られていない。確認コマンド: `find "$RSTMP/.claude/worktrees" 2>&1` の出力が `No such file or directory` を含む（`$RSTMP` は直前のコマンドで作った一時ディレクトリを使う）
- `bash scripts/smoke.sh` を実行した時、`新規インストール先で参照される scripts がすべて揃っている` の行が `ok` から始まる。確認コマンド: `bash scripts/smoke.sh`（`== 参照される scripts の存在チェック ==` セクションの行が `ok` で始まることを出力で確認する）
- 同じ実行で `install.sh` に関する既存ケース（`(f)`〜`(l)` 等）に新規の `NG` が発生していない。確認コマンド: 同じ出力中、`== install.sh` を含むセクション見出し配下の行がいずれも `ok` で始まることを確認する
- 同じ実行の末尾 `smoke: pass=<N> fail=<M>` の `pass` が着手前HEAD時点の実行結果（152）より1件以上増えている（今回直した1ケース分。他タスクの完了状況によってはさらに増えていてもよい）。確認コマンド: 同じ実行結果の末尾行を読む

## 決定済み
- 除外方法は `find . -type f ...` の対象から `.claude/worktrees` 配下を外せればよい（例：`find . -type f -path './worktrees/*' -prune -o -type f ... -print` のように書き換える、または列挙後に `grep -v '^worktrees/'` で除く、など）。実装の細部は自由。`manifest_paths()`・`scripts_list()` など他の複製経路は `.claude/worktrees/` を元々対象にしていないため変更不要
- `.claude/worktrees/` はハーネスが配布するテンプレートの一部ではなく、`git worktree add` が実行時に作る実体ディレクトリ（`.gitignore` 済み）。除外して構わない
- 複製先に既に `.claude/worktrees/` が存在するケース（インストール先で worktree を使っている最中に `--update` する等）は今回のスコープ外。複製元（`$SRC`）からの複製を止めるだけでよく、複製先の既存ファイルを削除する処理は追加しない
- 他タスク（T-01・T-02・T-04・T-05）の成果物ファイルは変更しない（`scripts/install.sh` 以外のファイルには触れない）
- コミットの指示は無いので、コミットするかどうかは任意（する場合は `vault/rules/common/git.md` の運用に従う）
