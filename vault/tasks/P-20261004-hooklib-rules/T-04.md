# T-04 agent_write_guard.py の plan_task_status を _hooklib.parse_tasks で書き直す

## 目的
`agent_write_guard.py` の `plan_task_status` が自前で持っているタスク表の行の組み立て（5列未満を捨てる・6列に埋める・`PLAN_TASK_COLUMNS` で dict にする）を、`_hooklib.parse_tasks` に置き換えて複製をなくす。

## 入力
- `vault/designs/D-011.md`（フェーズ2）
- `.claude/hooks/_hooklib.py`（T-01 の成果物。`parse_tasks`）
- `.claude/hooks/agent_write_guard.py`（`PLAN_TASK_COLUMNS`・`plan_task_status`、モジュール docstring の「共通モジュール _hooklib.py の raw_rows を使う」の行）
- フィクスチャ：`vault/tasks/P-20261004-hooklib-rules/fixtures/`（planner が作成済み。編集しない）

## 成果物
- `.claude/hooks/agent_write_guard.py`（1ファイル）

## 受け入れ基準
- 構文が正しい：`python3 -B -c "import ast; ast.parse(open('.claude/hooks/agent_write_guard.py').read()); print('ok')"` の出力が `ok`
- 行の組み立ての複製が残っていない：`grep -nE '^PLAN_TASK_COLUMNS|cells\[:6\]' .claude/hooks/agent_write_guard.py` の出力が空
- `plan_task_status` が引用符付き・インデントした計画票の行を読み、無い計画票・無い行は None を返す：`python3 -B -c "import runpy; g = runpy.run_path('.claude/hooks/agent_write_guard.py', run_name='awg'); f = g['plan_task_status']; d = 'vault/tasks/P-20261004-hooklib-rules/fixtures'; print(f(d, 'P-FIXTURE-QUOTED', 'T-01'), f(d, 'P-FIXTURE-QUOTED', 'T-02'), f(d, 'P-FIXTURE-QUOTED', 'T-09'), f(d, 'P-NONE', 'T-01'))"` の出力が `doing blocked None None`
- モジュール docstring が `parse_tasks` を指している：`grep -n '_hooklib.py の parse_tasks を使う' .claude/hooks/agent_write_guard.py` の出力が1行で、その行番号がモジュール docstring の中（2行目の `"""` から、次に行頭に `"""` がある行まで。`grep -n '^"""' .claude/hooks/agent_write_guard.py` で確かめる）にある
- 既存の smoke が全件通る（done 判定のケースを含む）：`bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` を含む

## 決定済み
- `plan_task_status(root, plan_id, task_id)` の引数・戻り値・fail-open（計画票が無い・読めない・該当行が無い時は None）は変えない。本体は、計画票を読んで `for t in H.parse_tasks(text):` で回し、`t["id"] == task_id` なら `t["status"]` を返す形にする
- `PLAN_TASK_COLUMNS` の定義は消す（他で使っていないことを確かめてから）
- `find_plan_unblocks` の `H.raw_rows` の直接の使い方（`cells[0]`・`cells[1]` だけを見る）は変えない。行の組み立ての複製ではないため
- モジュール docstring の「タスク表の解析規則は共通モジュール _hooklib.py の raw_rows を使う」は、「タスク表の解析規則は共通モジュール _hooklib.py の parse_tasks を使う」に書き換える（この文言のまま。受け入れ基準で grep する）
- Bash の書き込み解析（`analyze_bash_writes` など）・他の判定は一切変えない（フェーズ3の対象）
- `_hooklib.py`・他の2フック・scripts・smoke.sh・docs は変更しない（他タスクの担当）
- 既存の smoke が落ちた場合は、smoke.sh を直さず blocked にして、落ちたケース名と原因を question に書く
- 動作確認で import する時は `python3 -B` を使う。`.claude/hooks/__pycache__/_hooklib*` を作ってしまったら消しておく
- コミットは受け入れ基準に無いので、creator はしない
