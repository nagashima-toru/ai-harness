# T-03 docs/install.md と install.sh 冒頭コメントを worktree.baseRef の扱いに合わせて更新する

## 目的
`docs/install.md` の settings.json に関する説明（109行目・142行目・164行目付近）と `scripts/install.sh` 冒頭コメントを、`worktree.baseRef` の自動マージ（T-01 の実装）と uninstall では残るという挙動に合わせて更新する。

## 入力
- `docs/install.md`（95〜170行目付近。109行目「`.claude/settings.json` は自動マージされない」という記述は現在の実装と矛盾しているため実態に合わせて書き換える。142行目付近の `--update` 時のマージ内容の説明、164行目付近の uninstall の `unmerge_settings_json.py` の説明）
- `scripts/install.sh`（1〜15行目の冒頭コメント）
- T-01 の成果物（`scripts/merge_settings_json.py`）の実際の挙動・出力

## 成果物
- `docs/install.md`

## 受け入れ基準
- `grep -c "worktree.baseRef" docs/install.md` が2以上
- `grep -c "自動マージされない" docs/install.md` が0（109行目付近の矛盾した記述を、実態（hooks・permissions.deny・worktree.baseRef を自動マージする）に合わせて書き換えたことの確認）
- `worktree.baseRef` について書いた行のいずれかに、uninstall では取り除かれず残る旨が書かれている。確認：`grep "worktree.baseRef" docs/install.md | grep -c "残る"` が1以上
- `scripts/install.sh` の冒頭コメント（1〜20行目）に `worktree.baseRef` という文言が含まれる。確認：`sed -n '1,20p' scripts/install.sh | grep -c "worktree.baseRef"` が1以上

## 決定済み
- 109行目付近：「`.claude/settings.json` は自動マージされない」という現行の記述は誤りなので削除・修正する。修正後は「`.claude/settings.json` は `merge_settings_json.py` が hooks・`permissions.deny`・`worktree.baseRef` を自動でマージする」という趣旨に書き換える
- 142行目付近：`--update` 時のマージ内容の箇条書きに、`worktree.baseRef`（導入先に無ければ足す。別の値が入っていれば上書きせず案内する）を追記する
- 164行目付近：uninstall の説明に、`worktree.baseRef` は `unmerge_settings_json.py` の対象外で uninstall 後も導入先に残る旨を明記する（決定済み事項。`scripts/unmerge_settings_json.py` 自体は変更しない）
- `install.sh` 冒頭コメントは、settings.json 関連の記述（4〜7行目付近）に `worktree.baseRef` の自動マージに触れる一文を足すだけでよい。スクリプト本体のロジック・引数は変更しない
- `docs/install.md` のその他の節（109〜170行目以外）や見出し構成は変更しない
- T-01 の実装（`note` の出し方、`merge`/`skip`/`create` の使い分け）を実際に読んでから、それと矛盾しない説明にする
