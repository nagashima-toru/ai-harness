# T-01 agent_write_guard.py のパス比較でシンボリックリンクを解決し worktree 誤 deny を無くす

## 目的
`.claude/hooks/agent_write_guard.py` のパス正規化（`normalize()`）がシンボリックリンクを解決しないために、macOS で worktree 内への正当な書き込みが「root の外」と誤判定され deny される不具合を直す（issue #59）。

## 入力
- `.claude/hooks/agent_write_guard.py`（変更対象。`normalize()`・`is_outside_root()`・`resolve_root()`・`git_toplevel()` の関係を読むこと）
- `scripts/smoke.sh` の `== agent_write_guard.py ==` セクション中、`(worktree)`・`(worktree nested)` の2ケース（`WMAIN`/`WLEAF`・`WMAIN2`/`WLEAF2` を使う箇所。202〜222行目付近）
- 再現手順（このタスク票を書いた時点で確認済み）：`TMP=$(mktemp -d); cd "$TMP" && git init -q -b main && git commit -q --allow-empty -m init; git rev-parse --show-toplevel` を実行すると、`$TMP` 自体（`mktemp -d` の生パス、例 `/var/folders/...`）と `git rev-parse --show-toplevel` の出力（例 `/private/var/folders/...`）が食い違う（macOS 固有。`/var` が `/private/var` へのシンボリックリンクのため）

## 成果物
- `.claude/hooks/agent_write_guard.py` の修正（1ファイル）

## 受け入れ基準
- `normalize()` 関数がパス比較の前にシンボリックリンクを解決している（`os.path.abspath` だけでなく `os.path.realpath` を使っている）。確認コマンド: `grep -n "os.path.realpath" .claude/hooks/agent_write_guard.py` の出力が1行以上
- `bash scripts/smoke.sh` を実行した時、`(worktree)` を含むテスト名の行が `ok` から始まる。確認コマンド: `bash scripts/smoke.sh`（`== agent_write_guard.py ==` セクション内の `(worktree)` を含む2行がいずれも `ok` で始まることを出力で確認する）
- 同じ実行で、`(delegate)` を含む既存のテスト名の行に新規の `NG` が発生していない（今回の変更で委譲まわりの挙動を壊していない）。確認コマンド: 同じ `bash scripts/smoke.sh` の出力中、`(delegate)` を含む行がすべて `ok` で始まることを確認する
- 同じ実行の末尾 `smoke: pass=<N> fail=<M>` の `pass` が着手前HEAD時点の実行結果（152）より2件以上増えている（今回直した2ケース分。他タスクの完了状況によってはさらに増えていてもよい）。確認コマンド: 同じ実行結果の末尾行を読む

## 決定済み
- 修正方針は「シンボリックリンク解決を追加して比較の両辺を揃える」に限定する。`resolve_root()`・`git_toplevel()`・`existing_ancestor()` のロジック自体（worktree ルート解決の呼び出し順序）は変更しない
- 具体的には `normalize(path, root)` 内で、`path` を絶対パス化した後（および `root` も）`os.path.realpath()` を通してから `os.path.relpath()` を計算する形にしてよい。`normalize()` は `is_outside_root()`・`targets_vault_rules()`・`targets_creator_denied_paths()`・`main()` 内の `ALLOWED` 判定・Bash のリダイレクト判定など複数箇所から呼ばれる共通関数なので、ここ1箇所を直せば全ての呼び出し元に効く
- Linux（symlink が絡まない環境）では `os.path.realpath()` は `os.path.abspath()` と同じ結果を返すため、既存の通っているテストへの影響は無い前提で進めてよい。実際に全体を再実行して回帰が無いことを受け入れ基準で確認する
- 他タスク（T-02〜T-05）の成果物ファイルは変更しない（`.claude/hooks/agent_write_guard.py` 以外のファイルには触れない）
- コミットの指示は無いので、コミットするかどうかは任意（する場合は `vault/rules/common/git.md` の運用に従う）
