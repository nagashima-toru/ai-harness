# T-02 docs/install.md の「複製されるもの」を固定リストに合わせる

## 目的
T-01 で `scripts/install.sh` が `.claude/` 配下をハーネス本体の固定リストだけ配るようになったので、利用者向けの説明 `docs/install.md` をそれに合わせ、配布元が独自に置いたファイルは配らないこと、旧版で配られたものの扱いを書く。

## 入力
- `docs/install.md`（34行目の「複製されるものは〜」の段落、134〜150行目の「ハーネスを更新する（2回目以降）」）
- T-01 後の `scripts/install.sh`（`CLAUDE_FILES` の定義と冒頭コメント）

## 成果物
- `docs/install.md`（1ファイル）

## 受け入れ基準
- 34行目の段落の旧い書き方（`.claude/`（`ai-harness.md` を含む））が利用者向けの文書・スクリプトに残っていない（`grep -rln 'ai-harness.md. を含む' README.md docs .claude scripts` の出力が空）
- `docs/install.md` に「配布元が独自に置いたファイルは配らない」の文言がちょうど1回ある（`grep -c '配布元が独自に置いたファイルは配らない' docs/install.md` が `1`）
- `docs/install.md` に、旧版で配られた独自ファイルの扱いの文言がちょうど1回ある（`grep -c 'マニフェストからは外れ' docs/install.md` が `1`）
- `docs/install.md` が固定リストの Skill 3本を列挙している（`grep -c '.claude/skills/design/SKILL.md' docs/install.md` が `1` 以上、`grep -c '.claude/skills/plan/SKILL.md' docs/install.md` が `1` 以上、`grep -c '.claude/skills/run/SKILL.md' docs/install.md` が `1` 以上）
- smoke の参照チェックが通る（`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` が `1`）
- smoke 全体が失敗0で終わる（`bash scripts/smoke.sh 2>&1 | tail -1` が `smoke: pass=<数> fail=0` の形）
- 計画ブランチとの分岐点からの差分に `docs/install.md` が含まれる（creator の worktree の中で `git diff --merge-base work/p-20261012-install-harness-only-files --name-only` の出力に `docs/install.md` がある）

## 決定済み
- 34行目の段落の `.claude/`（`ai-harness.md` を含む）の部分を、固定リストの11ファイルを列挙する形に書き換える。11ファイルは `.claude/ai-harness.md`、`.claude/agents/` の `creator.md`・`planner.md`・`verifier.md`、`.claude/hooks/` の `_hooklib.py`・`agent_write_guard.py`・`plan_guard.py`・`stop_gate.py`、Skill の `.claude/skills/plan/SKILL.md`・`.claude/skills/run/SKILL.md`・`.claude/skills/design/SKILL.md`。Skill 3本はこのとおりリポジトリ相対のフルパスをバッククォートで書く（基準の grep が見る）。agents・hooks はファイル名だけを書いてよい。`.claude/settings.json` は別にマージされる旨の既存の説明はそのまま。
- 同じ段落に「配布元が独自に置いたファイルは配らない」という文言をそのまま1回書く。趣旨：`.claude/` は `scripts/install.sh` の `CLAUDE_FILES` の固定リストだけを配り、導入済みのリポジトリを配布元にしても、そこに置かれた業務用の Skill・agent・hook や `vault/templates/` の独自テンプレートは配らず、マニフェストにも記録しない。
- 「ハーネスを更新する（2回目以降）」の箇条書きに1項目足し、「マニフェストからは外れ」の文言をそのまま1回書く。趣旨：旧版の install で配布元の独自ファイルが複製・記録されていた導入先では、`--update` はそのファイルを削除せずに残し、マニフェストからは外れる（以降は導入先の資産として扱われ、`uninstall.sh` でも消えない）。不要なら人が消す。
- `scripts/` 直下の説明（検索方式で配る）は変えない（計画の対象外）。
- 古い記述の確認範囲は `README.md`・`docs/`・`.claude/`・`scripts/` とし、`vault/` は除く。理由：この計画の計画票・タスク票自身が旧い書き方を引用しているため。
- バッククォートで書くパスは実在するもの（T-01 の時点で既にあるファイル）だけにする。`(ref-1)` が存在しないパスを NG にする。
