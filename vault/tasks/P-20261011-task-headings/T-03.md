# T-03 planner.md の「『進捗』は空のまま」を見出しだけ書く意味の文に直す

## 目的
planner の定義の「『進捗』は空のまま」が「見出しごと省いてよい」と読まれ、「## 進捗」の無いタスク票が作られた（Issue #166）。見出しだけを書き本文を空にする、という意味が一意に読める文に直す。

## 入力
- `.claude/agents/planner.md`（「## 手順」の3、「## 書き終えた後の確認」）
- `vault/templates/task.md`（6見出し）

## 成果物
- `.claude/agents/planner.md`（1ファイル）

## 受け入れ基準
- `grep -rn '「進捗」は空のまま' .claude docs scripts vault/templates vault/rules README.md` の出力が空
- `grep -c '「## 進捗」は見出しだけを書き、本文は空にする（見出しを省かない）' .claude/agents/planner.md` の出力が `1`
- `grep -c '各タスク票に6見出し（「## 進捗」を含む）がそろっているか' .claude/agents/planner.md` の出力が `1`
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`
- `bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` で終わる

## 決定済み
- 「## 手順」の3の末尾の「「進捗」は空のまま」を、`「## 進捗」は見出しだけを書き、本文は空にする（見出しを省かない）` に置き換える（この文言をそのまま書く）
- 「## 書き終えた後の確認」に、`各タスク票に6見出し（「## 進捗」を含む）がそろっているか` を含む箇条を1つ足す（この文言をそのまま書く）。T-01 で `plan_guard.py` が欠けを止めるようになる旨を添えてよいが必須ではない
- ほかの節（「## やらないこと」など）は変えない
- 確認範囲から `vault/plans/`・`vault/tasks/` を除く理由：この計画の計画票とタスク票が、直す前の文言を引用として含むため。`.git` は対象外
- バッククォートで囲むパスは実在するものだけにする（`(ref-1)` が検査する）
- 「成果物のみで他ファイル不変」の確認は書かない（差分ゲートに任せる）
