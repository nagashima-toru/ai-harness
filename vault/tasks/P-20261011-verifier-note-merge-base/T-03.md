# T-03 vault-spec.md の形式の不変を見る例を merge-base の形にする

## 目的
`docs/vault-spec.md` の、形式の不変を見る確認コマンドの例 `git diff -- vault/plans/<計画ID>.md | grep ...` を `git diff --merge-base work/<計画IDの英小文字> -- ...` の形に揃え、ゴールの範囲（手順書・仕様・ルール・スクリプト）に作業ツリーと比べる形の例が残らないようにする。

## 入力
- `docs/vault-spec.md`（8節の248行目）
- `.claude/agents/planner.md` の64行目（T-02 で直した同じ例。揃える形の参考）

## 成果物
- `docs/vault-spec.md`（1ファイル。248行目の例の1か所だけを変える）

## 受け入れ基準
- `grep -rnE 'git diff (--[a-z-]+ )?-- ' .claude docs README.md vault/rules vault/templates scripts` の出力が空（ゴールの範囲に作業ツリーと比べる形の例が残っていない）
- `grep -c 'git diff --merge-base work/.計画IDの英小文字. -- vault/plans/' docs/vault-spec.md` の出力が `1`
- 対象 worktree の中で `git diff --merge-base work/p-20261011-verifier-note-merge-base --numstat -- docs/vault-spec.md` を実行した出力が、`1	1	docs/vault-spec.md`（追加1行・削除1行）の1行だけである
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` の出力が `1`
- `bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` を含む

## 決定済み
- 248行目の例の中の `git diff -- vault/plans/<計画ID>.md` を `git diff --merge-base work/<計画IDの英小文字> -- vault/plans/<計画ID>.md` に置き換えるだけ。後ろの `| grep -E '^[+-](## |\| id )'` と、例の前後の文は変えない。
- 変更後の248行目の末尾は ``（例：`git diff --merge-base work/<計画IDの英小文字> -- vault/plans/<計画ID>.md | grep -E '^[+-](## |\| id )'`）`` になる。
- `<計画IDの英小文字>`・`<計画ID>` はプレースホルダのまま書く。`(ref-1)` は `<` を含むバッククォート内の文字列を検査しない。収集コミットの説明は足さない。ほかの行は変えない。
- 1つ目の基準は、T-01（`.claude/agents/verifier.md`）と T-02（`.claude/agents/planner.md`）の変更が計画ブランチに入った後の状態で通る（このタスクは両方の後に着手する）。
- 1つ目の基準の範囲から除くもの（理由）：`vault/plans/`・`vault/tasks/`・`vault/log/`・`vault/verdicts/`・`vault/designs/` は計画・記録で、古い形を引用するのが当然なため。`vault/rules/planner/ai-harness-lessons.md` と `.claude/agents/creator.md` 57行目の経緯の記録は、このパターンに当たらないので変えなくてよい。
- `.claude/skills/run/SKILL.md` 172行目・`docs/vault-spec.md` 70行目・142行目の `git diff` はコミットどうし（またはマージ衝突中のメインの作業ツリー）を比べる形で範囲外。変えない。
- 3つ目の基準は対象 worktree の中で実行する前提（計画ブランチ上で実行すると空になる）。出力の区切りはタブ。

## 進捗
- 読んだルール: vault/rules/common/vision.md
- docs/vault-spec.md 248行目の例を --merge-base 形に変更。基準1〜5の確認コマンドすべて通過（1:空, 2:1, 3:1行 1 1, 4:ref-1 が1, smoke fail=0）
