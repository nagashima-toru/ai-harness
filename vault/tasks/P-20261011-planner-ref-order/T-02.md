# T-02 /plan の粒度の確認に新規ファイルへの参照順の確認を足す

## 目的
`/plan` の手順A-5（粒度の確認）で、計画の中で新しく作るファイルへのバッククォート参照が、そのファイルを作るタスクより前のタスクに入っていないかも確かめるようにする（Issue #172）。

## 入力
- `.claude/skills/plan/SKILL.md`（「## A. 計画を作る」の手順5）
- `scripts/smoke.sh` の `refcheck`（2701行付近。`(ref-1)` の対象文書の一覧）

## 成果物
- `.claude/skills/plan/SKILL.md`（1ファイル）

## 受け入れ基準
- 手順A-5 の行に、新しく作るファイルへの参照順の確認がある：`grep -c '^5\. .*そのファイルを作るタスクより前のタスク' .claude/skills/plan/SKILL.md` が `1`
- 手順A-5 の行に、既存の粒度基準の確認が残っている：`grep -c '^5\. .*受け入れ基準3〜7行、成果物1つ、依存に循環なし' .claude/skills/plan/SKILL.md` が `1`
- 手順の番号付きの行の数が変わっていない：`grep -c '^[0-9]*\. ' .claude/skills/plan/SKILL.md` が `18`
- `bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (ref-1) '` が `1`
- `bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` で終わる

## 決定済み
- 追記先は「## A. 計画を作る」の `5. ` で始まる1行そのもの。新しい行や箇条を足さず、その行の中（「…依存に循環なし）」の後、「満たしていなければ planner に修正を依頼する」の前が目安）に文を足す。手順の番号は変えない
- 足す文には「そのファイルを作るタスクより前のタスク」という語をそのまま書くこと。趣旨：あわせて、計画の中で新しく作るファイルのパスへのバッククォート参照が、smoke の `(ref-1)` の対象文書（`scripts/smoke.sh` の `refcheck` が見る文書）を成果物に持つタスクのうち、そのファイルを作るタスクより前のタスク（`after` でそのタスクに依存させていないタスク）に入っていないかも確かめる（入っていると `(ref-1)` が NG になり、受け入れ基準どうしが矛盾する）
- 既存の文言「受け入れ基準3〜7行、成果物1つ、依存に循環なし」は変えない
- 新しく書く文の中のバッククォートで囲むパスは実在するものか雛形（`<` を含むもの）にする。例として存在しないパスをバッククォートで書かない
- 番号付きの行の数 `18` は着手前の値（A の 1〜11 と B の 1〜7）。変えないこと
- `.claude/agents/planner.md` 側の規則は T-01 が足す。このタスクでは planner.md を変えない（T-01 と独立に進められるよう、planner.md の新しい項目の文言を引用しない）
- smoke は1分強かかる。2つの smoke の基準は別々に実行してよい
