# T-02 runbook.md の vault/archive/ をバッククォートのパス参照でない書き方にする

## 目的
一括削除（`bash scripts/purge_plan.sh --merged --apply`）で vault/archive/ が無くなった後も、smoke の `(ref-1) 主な文書のバッククォート内のパスがすべて存在する` が `docs/runbook.md` を理由に落ちないようにする。5節の、`--apply` が vault/archive/ を消すという説明は残す。

## 入力
- `docs/runbook.md`（5節「一括削除の手順」。61行目と85行目）
- `scripts/smoke.sh` の `refcheck`（2471行目付近。バッククォートで囲まれ、`vault/`・`scripts/`・`docs/`・`.claude/` で始まり、`<*{$` と空白を含まない文字列を実在するパスとして検査する）
- `scripts/purge_plan.sh`（`--merged --apply` の動き）

## 成果物
- `docs/runbook.md`（1ファイル）

## 受け入れ基準
- `docs/runbook.md` にバッククォートで囲んだ `vault/archive/` が無い。確認：`grep -nF '`vault/archive/`' docs/runbook.md` が何も出力しない
- 5節の、一括削除が vault/archive/ も消すという説明が2か所とも残っている。確認：`grep -cF 'と vault/archive/ を、人が `scripts/purge_plan.sh --merged` でまとめて削除する' docs/runbook.md` が `1`、`grep -cF '`--apply` は対象の4種に加えて vault/archive/ も丸ごと消える' docs/runbook.md` が `1`
- 一括削除した一時 worktree で、smoke の参照切れの検査が `docs/runbook.md` の vault/archive/ を報告しない。確認（対象の作業ツリーのルートで、次の単一コマンドを順に実行する）：`mkdir -p /tmp/claude/P-20261010-purge-prereq-T-02`、`git worktree remove --force /tmp/claude/P-20261010-purge-prereq-T-02/wt`（無ければ失敗してよい）、`git worktree prune`、`git worktree add --detach /tmp/claude/P-20261010-purge-prereq-T-02/wt HEAD`、`env -C /tmp/claude/P-20261010-purge-prereq-T-02/wt bash scripts/purge_plan.sh --merged --apply | tail -1` が `vault/archive/` を出し、`bash /tmp/claude/P-20261010-purge-prereq-T-02/wt/scripts/smoke.sh 2>&1 | grep -c 'runbook.md:[0-9]*: vault/archive/'` が `0`
- 一括削除していない作業ツリーで smoke が全部通り、参照切れの検査も ok。確認：`bash scripts/smoke.sh 2>&1 | grep -F '(ref-1)'` の行が `ok` で始まり（行頭の空白を除く）、`bash scripts/smoke.sh 2>&1 | tail -1` が `fail=0` を含む

## 決定済み
- 直し方：61行目の `` と `vault/archive/` を、 `` を `と vault/archive/ を、` に、85行目の `` に加えて `vault/archive/` も `` を `に加えて vault/archive/ も` にする（バッククォートだけを外す）。ほかの語・ほかの行は変えない。61行目の計画一式4種のパス（`vault/plans/<計画ID>.md` など。`<` を含むので検査の対象外）と `scripts/purge_plan.sh --merged` のバッククォートはそのまま残す
- 78行目（コードブロックの中の `git commit -m "一括削除: main にマージ済みの計画一式と vault/archive/ を削除"`）は、行の中にバッククォートが無く検査の対象外なので変えない
- `refcheck` の除外リストを足す・雛形の形にする、はしない（smoke.sh はこのタスクの成果物ではない）
- 受け入れ基準3の「対象の作業ツリー」：creator は自分の worktree のルート、verifier は渡された worktree（`git -C <worktree のパス> worktree ...` の形で実行してよい）。`/tmp/claude/...` に書けない時は、代わりに対象の作業ツリーの `.claude/worktrees/purge-check-T-02`（`.gitignore` 済み）を使ってよい
- 一時 worktree は detached HEAD で作る。一括削除（`git rm`）は一時 worktree の中だけで行い、対象の作業ツリーでは `purge_plan.sh --merged --apply` を実行しない。確認が終わったら `git worktree remove --force /tmp/claude/P-20261010-purge-prereq-T-02/wt` で片づける（`rm -rf` は使わない。親ディレクトリは残してよい）
- 受け入れ基準3は runbook.md の vault/archive/ だけを見るので、T-01（vault-spec.md）や `vault/log/.gitkeep` の有無に左右されない
- 計画時点で一時 worktree の手順を実行した結果：`purge_plan.sh --merged --apply` の最後の行は `vault/archive/`、smoke の ref-1 は `docs/runbook.md:61: vault/archive/` と `docs/runbook.md:85: vault/archive/` を報告していた

- 基準1・2・4を実行して通過。基準3は編集を反映した一時 worktree（HEAD に編集をコミット）で確認し、purge の最終行は vault/archive/、smoke の該当報告は0件。一時 worktree は削除済み
