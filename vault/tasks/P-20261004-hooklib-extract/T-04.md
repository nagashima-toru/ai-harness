# T-04 stop_gate.py の複製関数を _hooklib に置き換え .git 判定を rev-parse に直す

## 目的
`stop_gate.py` に複製されている5関数を消し、`_hooklib` を import して使う形にする。あわせて、`has_uncommitted_changes` が `.git` がディレクトリかどうかで git リポジトリを判定しているのを、`git rev-parse --is-inside-work-tree` に直す。これで、worktree（`.git` がファイル）でも未コミット検査が効くようにする。

## 入力
- `vault/designs/D-011.md`（決定事項の表・フェーズ1）
- `.claude/hooks/_hooklib.py`（T-01 の成果物）
- `.claude/hooks/stop_gate.py`
  - 消す関数：`existing_ancestor`・`git_toplevel`・`delegate_to_worktree`・`plan_id_and_status`・`approved_plans`
  - 直す関数：`has_uncommitted_changes`（146行目が `.git` のディレクトリ判定）
  - 「import しない」「コピー」の記述がある場所：モジュール docstring の13〜14行目と、`plan_id_and_status` の docstring

## 成果物
- `.claude/hooks/stop_gate.py`（1ファイル）

- 構文が正しい：`python3 -B -c "import ast; ast.parse(open('.claude/hooks/stop_gate.py').read()); print('ok')"` の出力が `ok`
- 複製の関数定義・「import しない」「コピー」「複製」の注記・`.git` のディレクトリ判定が残っていない：`grep -nE '^def (existing_ancestor|git_toplevel|delegate_to_worktree|plan_id_and_status|approved_plans)\(|import (は)?しない|import は$|同名関数のコピー|コピーして使う|そのまま複製|isdir\(os\.path\.join\(root, "\.git"\)\)' .claude/hooks/stop_gate.py` の出力が空

## 決定済み
- フック先頭の書き方は次の形で固定する
  - 置く位置：モジュール docstring と標準ライブラリの import 文の直後、`MAX_ATTEMPTS` などの定数定義より前
  - 共通化しない。標準ライブラリだけで、このファイルに直接書く（D-011）
  - except 節で使えるのは `json`・`os`・`sys` だけ。定数 `STRICT` はまだ定義されていないので、環境変数を直接読む
  ```python
  sys.dont_write_bytecode = True
  sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
  try:
      import _hooklib as H
  except Exception as e:  # SyntaxError なども含めて捕まえる
      sys.stderr.write(f"[stop_gate] _hooklib の読み込みに失敗しました: {e}\n")
      try:
          _payload = json.load(sys.stdin)
      except Exception:
          _payload = {}
      if isinstance(_payload, dict) and _payload.get("stop_hook_active") and os.environ.get("HARNESS_STRICT_STOP", "0") != "1":
          sys.exit(0)
      sys.exit(2)
  ```
- 呼び出し側の書き方
  - 呼び出しはすべて `H.<関数名>(...)` に書き換える。別名は作らない
  - `delegate_to_worktree(payload)` は `H.delegate_to_worktree(payload, "stop_gate.py")` にする
- `has_uncommitted_changes(root)` の直し方
  - 最初に `git -C <root> rev-parse --is-inside-work-tree` を実行する（`capture_output=True, text=True, timeout=5`）。終了コードが0で、標準出力を strip したものが `true` の時だけ、続けて `git -C <root> status --porcelain` を見る
  - それ以外（例外・非0・`true` 以外の出力）は、従来どおり False を返す（fail-open）
  - `os.path.isdir(os.path.join(root, ".git"))` の判定は消す
  - docstring に「worktree（`.git` がファイル）でも判定する」と1行書き足す
- 移さずにこのファイルに残すもの
  - `parse_tasks`・`count_acceptance_criteria`・`project_dir` は挙動が他のフックと違うので、このファイルに残す（フェーズ2の対象）
  - `validate_verdict`・`block`・`allow`・`main` も残す。中身は変えない
- モジュール docstring
  - 「実装は agent_write_guard.py の delegate_to_worktree と同じパターンをそのまま複製したもの（…他ファイルへの import はしない）。」の文は、「委譲の実装は共通モジュール `_hooklib.py` の `delegate_to_worktree` を使う」という趣旨に書き換える
  - 共通関数が読み込めない時は、終了コード2で終わることを書き足す（`stop_hook_active` が真で `HARNESS_STRICT_STOP` が `1` でなければ0）
- `.git` 判定の修正と import の置き換え以外で、判定の挙動（ブロック・メッセージ）は変えない。smoke の期待値は変えない
- worktree で未コミットがブロックされることを確かめる smoke のケースは、T-05 で足す。このタスクでは `scripts/smoke.sh` を変更しない
- `agent_write_guard.py`・`plan_guard.py`・`_hooklib.py`・docs は変更しない（他タスクの担当）
- 動作確認で import する時は `python3 -B` を使う。`.claude/hooks/__pycache__/_hooklib*` を作ってしまったら消しておく
- コミットは受け入れ基準に無いので、creator はしない
