# T-02 smoke.sh に worktree.baseRef の3ケースを足す

## 目的
`scripts/smoke.sh` の「== merge_settings_json.py ==」節に、T-01 で実装した `worktree.baseRef` マージの3パターン（キー無し→merge、別の値→note、既に一致→skip）を検証するケースを追加する。

## 入力
- `scripts/smoke.sh`（490〜514行目付近の「== merge_settings_json.py ==」節。既存ケース (m)〜(n) と同じ、`$STMP` 配下に python で settings.json を書く書き方に合わせる）
- `scripts/merge_settings_json.py`（T-01 で実装済みの `worktree.baseRef` マージ処理と出力形式）

## 成果物
- `scripts/smoke.sh`

## 受け入れ基準
- `bash scripts/smoke.sh | tail -1` の出力が `fail=0` で終わる
- `worktree` キーを持たない dst に実行すると `worktree.baseRef` が `"head"` になり出力が `merge` になることを検証する `expect_eq` を、ラベル `(v)` で追加している。確認：`grep -c 'expect_eq "(v)' scripts/smoke.sh` が1以上
- `worktree.baseRef` が `"fresh"` の dst に実行すると値が変わらず `note` 行が出ることを検証する `expect_eq` を、ラベル `(w)` で追加している。確認：`grep -c 'expect_eq "(w)' scripts/smoke.sh` が1以上
- `worktree.baseRef` が既に `"head"` で hooks・deny も揃っている dst に実行すると出力が `skip` になることを検証する `expect_eq` を、ラベル `(x)` で追加している。確認：`grep -c 'expect_eq "(x)' scripts/smoke.sh` が1以上
- 既存の `expect_eq` 行（ラベル (a)〜(u)）を削除・変更していない。確認：`git diff main -- scripts/smoke.sh | grep -E '^-.*expect_eq "\([a-u]\)'` の出力が空

## 決定済み
- 追加位置は既存の「== merge_settings_json.py ==」節（既存ケース (m)(n) の直後、`rm -rf "$STMP"` より前。`bash -n scripts/smoke.sh` で該当行番号を確認してから編集する）。新しい節は作らない
- 一時ファイルの作り方は既存ケース (n) と同じで、`$STMP` 配下に python の `-c` スニペットで settings.json を書く
- ラベルは `(v)`（キー無し→merge）・`(w)`（別の値→note）・`(x)`（既に一致→skip）の3つを使う。以降の節にある既存ラベル（`install.sh の settings.json 扱い` 節の (o)(p) など）は変更しない
- `note` 行の文言一致までは検証しなくてよい。`note` で始まり `worktree.baseRef` を含む行が1行以上出ることの確認で足りる
- T-01 の実装（関数名・出力形式）が前提。T-01 の成果物を読んでから着手する
