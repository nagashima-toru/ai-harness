# T-0034 `run-queue` SKILL.md にブランチ・コミット・PR の手順を追記する

## 目的
`vault/rules/creator/git-workflow.md`（T-0031）で決めた手順と、フックが実際に強制するようになった内容（T-0032・T-0033）を、`/run-queue` の実行手順そのものに反映する。作成エージェントがスキルを読むだけでブランチ作成・ステップごとのコミット・PR作成・例外時の停止を行えるようにする。

## 入力
- `vault/rules/common/git.md`（T-0030）・`vault/rules/creator/git-workflow.md`（T-0031）
- `.claude/skills/run-queue/SKILL.md`（改訂対象）
- `.claude/hooks/agent_write_guard.py`・`.claude/hooks/stop_gate.py`（T-0032・T-0033 で追加された挙動。内容の重複説明はしない）

## 成果物
- `.claude/skills/run-queue/SKILL.md`（更新）

## 受け入れ基準
- 「1. 取り出す」または新設する手順に、タスクが属する計画を特定し、その計画のブランチ（`work/p-xxx-<slug>`）が無ければ `main` から作成してチェックアウトする手順が追記されている。確認：`grep -c 'work/p-xxx' .claude/skills/run-queue/SKILL.md` が1以上
- 「作業ステップごとにコミットする」手順が明記されている。確認：`grep -c 'ステップごとにコミット' .claude/skills/run-queue/SKILL.md` が1以上
- 計画内の全タスクが `done` になったら push して `gh pr create` し、マージ可能と人に報告して止まる（`gh pr merge` は実行しない）手順が追記されている。確認：`grep -c 'gh pr create' .claude/skills/run-queue/SKILL.md` と `grep -c 'gh pr merge は実行しない' .claude/skills/run-queue/SKILL.md` がそれぞれ1以上
- 「注意」の「git のコミットはタスク票の受け入れ基準に含まれている場合だけ行う」という記述が消え、git ルールに従う旨に置き換わっている。確認：`grep -c '受け入れ基準に含まれている場合だけ行う' .claude/skills/run-queue/SKILL.md` が0、`grep -c 'vault/rules/creator/git-workflow.md' .claude/skills/run-queue/SKILL.md` が1以上
- コンフリクト・想定外の差分に遭遇したら自己判断で処理せず、対象タスクを `blocked` にして人に報告する旨が追記されている。確認：`grep -c 'コンフリクト' .claude/skills/run-queue/SKILL.md` が1以上

## 決定済み
- 追記位置の目安：ブランチ作成の手順は「## 1. 取り出す」の手順3〜5の間（タスクを取った直後、doing にする前後どちらでもよいが、doing にする前に計画とブランチを確定させる）に1手順として追加する。ステップごとのコミットは「## 2. 作る」の各ステップ（成果物作成・受け入れ基準確認・進捗追記）の後に1手順として追加する。PR作成は「## 5. verdict に従う」の `PASS` 分岐（`done` にした直後）に追記する。例外（コンフリクト等）は「## 2. 作る」の手順5（`blocked` にする分岐）に git 由来の理由を追加する形で触れる
- 具体的な追記文言は `vault/rules/creator/git-workflow.md`（T-0031）の該当箇所を要約して転記してよい（詳細説明は git-workflow.md に譲り、SKILL.md 側は手順として簡潔に書く。全文コピーは不要）
- 「注意」の該当行は「git のコミット・ブランチ・PR は `vault/rules/common/git.md`・`vault/rules/creator/git-workflow.md` に従う」に置き換える
- 「注意」の他の既存行（Stop フックの説明・`done` のタスク票を編集しない・`vault/rules/` を編集しない）は変更しない
- `vault/rules/*`・フック本体・`install.sh`・ドキュメント類は変更しない（それぞれ T-0030〜T-0033・T-0035 の範囲）
- git commit はしない（人が確認してからコミットする）
