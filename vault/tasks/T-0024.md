- `## パターン1` の手順は次の順で書く（コマンド例を添える）：
  1. 空ディレクトリを作成して `cd` する
  2. `git init` する（新規リポジトリとして扱う）
  3. `bash /path/to/ai-harness/scripts/install.sh .` を実行する（複製されるものは `scripts/install.sh` 冒頭コメントのとおりで、本タスクでは変更しない）

  6. その場で `claude` を一度対話起動してフォルダを信頼する
  7. `bash scripts/smoke.sh` を実行して検証する
  8. 最初のアクションとして `/plan <ゴール>` を打つ、と1行で締める（詳細手順は `docs/runbook.md` に譲り、ここでは繰り返さない）
- `## パターン2` と `## インストール後の次の一歩` は T-0025 が別タスクとして追記する。本タスクではそれらの見出し自体を作らない。
- 用語・コマンド表記は README や runbook の書き方（コードブロック、`bash` 明示）に合わせる。
