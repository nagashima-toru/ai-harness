# T-06 run SKILL.md 注意節のコミットの主語を creator にする

## 目的
`.claude/skills/run/SKILL.md` 111行目（「## 注意」節）の「git のコミットはタスク票の受け入れ基準に含まれている場合だけ行う」には主語が無い。読み手のオーケストレーターが、手順6.3.1 で自分が行う未コミット分のコミットと矛盾して読めるので、主語を creator と明示する。

## 入力
- `.claude/skills/run/SKILL.md` 108〜112行目（「## 注意」節）と72行目（手順6.3.1）

## 成果物
- `.claude/skills/run/SKILL.md`（111行目の書き換え）

## 受け入れ基準
- 主語の無い旧行が無い（`grep -c '^- git のコミットはタスク票の受け入れ基準に含まれている場合だけ行う$' .claude/skills/run/SKILL.md` が `0`）
- 主語が creator の行がある（`grep -n '^- creator のコミットはタスク票の受け入れ基準に含まれている場合だけ行う' .claude/skills/run/SKILL.md` がヒットし、その行に `6.3.1` が含まれる）
- 変更が111行目の1行に限られている（`git diff -U0 main -- .claude/skills/run/SKILL.md` の出力のハンク見出し（`@@` で始まる行）が1つだけで、`-111` と `+111` を含む）
- 72行目・76行目の出典表記は変わっていない（`grep -c 'vault/rules/common/git.md' .claude/skills/run/SKILL.md` が `2`）

## 決定済み
- 111行目を「- creator のコミットはタスク票の受け入れ基準に含まれている場合だけ行う（オーケストレーターが手順6.3.1 で worktree の未コミット分をコミットするのはこの対象外）」の趣旨に置き換える。基準の語（行頭の「- creator のコミットはタスク票の受け入れ基準に含まれている場合だけ行う」と `6.3.1`）はそのまま書く
- 1行のまま書き換え、改行しない。「## 注意」節の他の行と、72行目・76行目（出典の表記を含む）は変更しない（人の回答：案A。SKILL.md の出典表記は直さない）
- この行に `vault/rules/common/git.md` などの出典を足さない（基準4の件数を2のまま保つため）
- 基準3の `git diff -U0 main` は、このファイルを変更するタスクがこの計画で T-06 だけなので、誤検知は起きない
- smoke.sh はこのタスクの基準に含めない（T-07 で流す。smoke は SKILL.md に `creator=`・`verifier=` があるかを見るが、111行目の変更はそれに影響しない）
- このタスクではコミットしない（受け入れ基準にコミットが無いため）
