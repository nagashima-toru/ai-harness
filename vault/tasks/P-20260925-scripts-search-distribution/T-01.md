# T-01 install.sh の scripts 配布を検索方式にする

## 目的
`scripts/install.sh` の `manifest_paths()` と通常複製（`copy_if_absent` の呼び出し）を、`scripts/` 直下のファイル名列挙から `*.sh`・`*.py` の検索方式に変える。除外リストを用意し、冒頭コメントを実態に合わせる。

## 入力
- `scripts/install.sh`（`manifest_paths()` 50〜68行目、通常複製 131〜141行目、冒頭コメント4行目）
- `vault/designs/D-007.md` フェーズ1（決定事項）

## 成果物
- `scripts/install.sh`

## 受け入れ基準
- 新規ディレクトリへ `bash scripts/install.sh <target>` を実行すると、リポジトリの `scripts/*.sh`・`scripts/*.py` がすべて `<target>/scripts/` に配置される。確認：`T=$(mktemp -d); bash scripts/install.sh "$T" >/dev/null; for f in scripts/*.sh scripts/*.py; do test -f "$T/$f" || echo "missing $f"; done` が何も出力しない
- 同じ実行で `<target>/.claude/harness-manifest.json` の `files` に `scripts/vcs_finish.sh` が sha256 付きで載る。確認：`python3 -c "import json,re;d=json.load(open('$T/.claude/harness-manifest.json'))['files'];print(bool(re.fullmatch('[0-9a-f]{64}',d.get('scripts/vcs_finish.sh',''))))"` が `True`
- `scripts/install.sh` から、スクリプト名を1つずつ書いた `copy_if_absent "$SRC/scripts/<名前>"` の行が無くなっている。確認：`grep -cE 'copy_if_absent "\$SRC/scripts/[a-z_]+\.(sh|py)"' scripts/install.sh` が `0`
- 冒頭コメントの「複製するもの」が個別列挙をやめ、検索方式を示す文言 `scripts/*.sh` を含む。確認：`grep -c 'scripts/\*\.sh' scripts/install.sh` が1以上
- 変更後も既存の `scripts/smoke.sh`（T-02 が足す新ケースより前の状態）が全件 pass する。確認：`bash scripts/smoke.sh | tail -1` が `fail=0`

## 決定済み
- 検索対象は `scripts/` 直下の `*.sh`・`*.py` だけ（サブディレクトリは見ない）。`manifest_paths()` では既存の hooks 等と同じ形（`find scripts -maxdepth 1 -type f \( -name '*.sh' -o -name '*.py' \)`）でよい
- 除外リストは install.sh 内のシェル変数 `SCRIPTS_EXCLUDE=""`（スペース区切りのファイル名、当面は空）として持ち、`manifest_paths()` と通常複製の両方が同じ変数を見る
- 通常複製では、検索した各ファイルに対して既存の `copy_if_absent` をそのまま呼ぶ（上書きしない挙動は変えない）。132〜140行目の個別の `copy_if_absent "$SRC/scripts/<名前>" ...` の行はループに置き換える
- `docs/vault-spec.md` など `scripts/` 以外の配布方式は今回変えない
- `scripts/uninstall.sh`（マニフェスト駆動）は変更しない
- `.claude/settings.json` の `worktree.baseRef` の扱い（フェーズ2）はこのタスクの範囲外。触れない
- 冒頭コメント（4行目）の scripts 該当部分の書き換えは自由記述でよいが、`scripts/*.sh` という文字列を含めること（受け入れ基準の grep に合わせる）
