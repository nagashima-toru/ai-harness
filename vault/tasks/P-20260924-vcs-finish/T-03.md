# T-03 design スキルの最終手順を vcs_finish.sh 呼び出しに置き換える

## 目的
`.claude/skills/design/SKILL.md` の最終手順（設計文書提示後の PR 作成案内）が直接呼んでいる
`gh pr create` を、`scripts/vcs_finish.sh` の実行に置き換える。あわせて、実行主体を「人が
`gh pr create` を実行する」から「エージェントが `scripts/vcs_finish.sh` を実行する」に変え、`run` の
手順7と同じパターンに揃える。

## 入力
- `.claude/skills/design/SKILL.md`（手順8「提示して止まる」）
- `vault/tasks/P-20260924-vcs-finish/T-01.md`「決定済み」（`scripts/vcs_finish.sh` の呼び出し方の契約）
- `vault/designs/D-005.md`（決定済み）

## 成果物
- `.claude/skills/design/SKILL.md` の更新（この1ファイルのみ）

## 受け入れ基準
- `.claude/skills/design/SKILL.md` に `gh pr create` という文字列が残っていない。確認:
  `grep -c "gh pr create" .claude/skills/design/SKILL.md` が0
- 手順8で、エージェントが `scripts/vcs_finish.sh` を実行する記述に書き換わっている（人が
  `gh pr create` を実行する記述のままではない）。確認:
  `grep -n "vcs_finish.sh" .claude/skills/design/SKILL.md` がヒットする
- `none` 判定時にスクリプトが出す案内（ブランチ名・`git merge --no-ff`）をそのまま人に伝えて止まる旨
  の記述がある。確認: `grep -n "git merge --no-ff" .claude/skills/design/SKILL.md` がヒットする
- `gh pr merge` を実行する記述は追加していない（マージは人が行うという既存方針を維持する）。確認:
  `grep -c "gh pr merge" .claude/skills/design/SKILL.md` が0

## 決定済み
- 現状の手順8は「人がこの設計文書をレビューして `gh pr create` で PR を作り `main` にマージしてか
  ら」という、人が PR 作成まで行う記述になっている。これを「エージェントが `bash scripts/vcs_finish.sh`
  を実行して PR/MR を作成する（`none` の場合は案内を受け取る）→ その結果（PR/MR の URL、または
  `none` 時のブランチ名・`git merge --no-ff` 案内）を人に報告して止まる」という記述に変える。実行主体
  を人からエージェントへ変更する（`vault/designs/D-005.md` の決定：GitHub/GitLab では PR/MR 作成まで
  はエージェントが行い、マージは人が行うという既存の安全境界に揃える）
- 呼び出しは引数無し `bash scripts/vcs_finish.sh`
- `none` の場合、エージェントはマージを一切実行せず、スクリプトが出すブランチ名と
  `git merge --no-ff` の案内をそのまま人に伝えて止まる
- 手順1〜7（ブランチ作成・調査・質問・決定事項・フェーズ分割・書く・コミットする）は本タスクの対象
  外。触れない
