# T-02 README.md へのライセンス節追記

## 目的
`README.md` にライセンスの節を追記し、リポジトリのライセンス種別と `LICENSE` ファイルへの参照を明示する。

## 入力
- `README.md`（現状の全体構成。見出し順は変えない）
- T-01 の成果物 `LICENSE`（種別名・参照先として使う）

## 成果物
- `README.md` の更新（既存ファイルへの追記。1ファイル）

## 受け入れ基準
- `README.md` に `## ライセンス` という見出しが存在する。確認コマンド: `grep -n "^## ライセンス" README.md`
- その節の直後5行以内に `LICENSE` という文字列（ファイルへの参照）が含まれる。確認コマンド: `grep -A5 "^## ライセンス" README.md | grep -n "LICENSE"`
- その節の直後5行以内に決定済みのライセンス名（例: `MIT License`）が明記されている。確認コマンド: `grep -A5 "^## ライセンス" README.md | grep -n "MIT License"`
- 既存の他の見出し（`## 目的`・`## セットアップ`等）が削除されていない。確認コマンド: `git diff README.md | grep -E '^-## '` の出力が空
- `README.md` 以外のファイルを変更していない。確認コマンド: `git status --porcelain | grep -v ' vault/' | grep -v ' README.md$'` の出力が空（`vault/` 配下の進捗・log 更新は除く）

## 決定済み
- ライセンス名は `MIT License`（T-01 の「決定済み」と同じ表記。別の呼称を作らない）
- 追記位置は既存の見出し構成を壊さない範囲であれば自由（末尾に `## ライセンス` を追加してよい）
- 文面は簡潔でよい。例：「このリポジトリは `<ライセンス名>` の下で公開しています。詳細は [LICENSE](LICENSE) を参照してください。」
