# T-05 decisions.md に archive をスクリプト化した判断の行を足す

## 目的
`docs/decisions.md` の 2026-09-17 の行「月次 archive はスクリプト化せず runbook の手順（`git mv`）のみ」を置き換える判断（`scripts/archive_plans.sh` を足し、`--apply` は人が実行する）を、表の末尾に1行で記録する。

## 入力
- `docs/decisions.md`（表の形式。既存の「〜を置き換え」の行：2026-10-01 の行が例）
- 計画票 `vault/plans/P-20261003-archive-old-logs.md` の「分割方針」

## 成果物
- `docs/decisions.md`（表の末尾に1行追加する。1ファイル）

## 受け入れ基準
- 置き換える旧い判断を名指しした行がある：`grep -c '2026-09-17 の「月次 archive はスクリプト化せず' docs/decisions.md` の出力が `1`
- 追加した行が表の最終行で、スクリプト名を含む：`tail -1 docs/decisions.md | grep -c 'scripts/archive_plans.sh'` の出力が `1`
- 人が実行する理由を書いている：`tail -1 docs/decisions.md | grep -c '人が実行する'` の出力が `1`
- 既存の行を消していない・変えていない：`git diff main -- docs/decisions.md | grep -c '^-|'` の出力が `0`

## 決定済み
- 行の形：`| <日付> | 2026-09-17 の「月次 archive はスクリプト化せず runbook の手順（`git mv`）のみ」を置き換え、`scripts/archive_plans.sh` を足す（`--dry-run` / `--apply`、配置は `vault/archive/<年-月>/{plans,tasks,verdicts,log}/`） | <なぜ> |`
- 日付は作業日（`TZ=Asia/Tokyo date '+%Y-%m-%d'`）
- 「なぜ」列に書くこと：runbook の手動手順は計画票と log・タスク票と verdict のディレクトリが同じ場所で名前が衝突していた。安全装置（done・全行 done・main で done＝マージ済み・現在の計画でない・未コミットが無い・移動先が無い）を機械で確かめたい。`--apply` は人が実行する（creator は `vault/plans/`・`vault/log/` に書き込めず、スクリプト経由ではフックの禁止を回避することになるため）。「人が実行する」の文言をそのまま含める
- 既存の 2026-09-17 の行は消さない・書き換えない（記録は追記のみ）
- ファイル末尾は追加した行で終わる（後ろに空行や別の文を足さない）
- 確認コマンドの `git diff main -- docs/decisions.md` は、この計画で decisions.md を変えるのがこのタスクだけなので使ってよい
