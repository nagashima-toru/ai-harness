# T-02 smoke.sh に permissions.allow 不足案内のケースを足す

## 目的
T-01 で足した `permissions.allow` の不足案内（note 行）と「allow を変更しない」挙動を、smoke.sh で機械的に確かめられるようにする。

## 入力
- `scripts/merge_settings_json.py`（T-01 の成果物）と、T-01 タスク票の「決定済み」（関数の形・note 行の文言・出す位置・型不正時の扱い）
- `scripts/smoke.sh` の `== merge_settings_json.py ==` 節（(m)(n)(v)(w)(x) のケース、`$STMP` の使い方）と `== install.sh の settings.json 扱い ==` 節（`$WTMP` の使い方）

## 成果物
- `scripts/smoke.sh`（`(al-1)`〜`(al-6)` のケースを追加する。1ファイル）

## 受け入れ基準
- smoke 全体が通る：`bash scripts/smoke.sh 2>&1 | tail -1` の出力が `fail=0` で終わる
- 追加したケースに失敗が無い：`bash scripts/smoke.sh 2>&1 | grep -c '^  NG   (al-'` の出力が `0`
- 追加したケースが8件以上通る：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (al-[1-6]) '` の出力が `8` 以上
- allow だけ不足する時の skip と型不正のケースが通る：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (al-[15]) '` の出力が `2` 以上
- install.sh 経由で note 行が出るケースが通る：`bash scripts/smoke.sh 2>&1 | grep -c '^  ok   (al-6) '` の出力が `1` 以上
- 6つのケースがすべて smoke.sh に書かれている：`grep -oE 'expect_eq "\(al-[1-6]\)' scripts/smoke.sh | sort -u` の出力が `expect_eq "(al-1)` 〜 `expect_eq "(al-6)` の6行

## 決定済み
- ケース名は `(al-1)`〜`(al-6)` で始める（`expect_eq "(al-1) ..."` の形）。1ケースに `expect_eq` が複数あってよい
- (al-1)〜(al-5) は `== merge_settings_json.py ==` 節の (x) の後、`rm -rf "$STMP"` の前に置き、`$STMP` の下にファイルを作る（既存ケースと同じく `python3 -c` で `$ROOT/.claude/settings.json` を読み、一部を変えて書き出す）。(al-6) は `== install.sh の settings.json 扱い ==` 節の (p) の後、`rm -rf "$WTMP"` の前に置く。`/tmp/` の固定パスは使わない。新しく `rm -rf` を足さない
- ケースの中身（src はすべて `$ROOT/.claude/settings.json`）
  - (al-1) allow だけ不足：dst は src のコピーから allow の `Bash(jq *)` を削除し、`Bash(git *)` を `Bash(git:*)` に置き換えたもの。出力の1行目が `note ` で始まり `permissions.allow` を含み、`Bash(git *)` と `Bash(jq *)` の両方を含む（完全一致判定の確認）。出力の最終行が `skip ` で始まる。dst の allow に `Bash(git:*)` が残り `Bash(jq *)` が無い（変更されていない）。`.bak-` のバックアップが作られない
  - (al-2) allow と deny の両方が不足：note 行が merge 行より前に出る（出力の1行目が `note `、2行目が `merge `）。merge 後も dst の allow に不足していた項目が足されていない
  - (al-3) dst が無い（create）：出力に `note` で始まる行が無い
  - (al-4) 揃っている dst（src のコピー）：出力に `permissions.allow` を含む note 行が無い
  - (al-5) dst の `permissions.allow` が文字列：終了コード0、出力に `permissions.allow の型が不正` を含む note 行が1行
  - (al-6) install.sh 経由：`$WTMP/.claude/settings.json` の allow から1項目（例 `Bash(jq *)`）を削除した上で `bash "$ROOT/scripts/install.sh" --update "$WTMP"` を実行し、その標準出力に `^note .*permissions\.allow にハーネスが使う許可が` に一致する行が1行ある。実行後も allow にその項目が無い
- note 行の文言は T-01 の「決定済み」の形（`note <dst>: permissions.allow にハーネスが使う許可が <N> 件足りない: ...`）に合わせて検査する
- 既存ケース (m)(n)(v)(w)(x)(o)(p) は変えない。既存ケースの期待値が T-01 の変更で崩れた場合は、自分で直さず blocked にして question に書く
- `scripts/merge_settings_json.py` にバグが見つかった時は、自分で直さず blocked にして question に書く（成果物は smoke.sh だけ）
