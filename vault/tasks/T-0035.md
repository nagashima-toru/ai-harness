# T-0035 install.sh・.gitignore・README/runbook/decisions.md に配布・周知を反映する

## 目的
git 運用ルール（T-0030〜T-0034）を、標準ルールとして他プロジェクトへも配布し、人向けドキュメントに周知する。生成物（`merge_claude_md.py` が作るバックアップファイル）を誤ってコミットしないよう `.gitignore` を整える。

## 入力
- `scripts/install.sh`（複製対象リスト。`for f in tasks/.gitkeep ... rules/planner/planner.md; do` の行に新規2ファイルを追加する）
- `.gitignore`（現状4行。`CLAUDE.md.bak-*` のパターンが無い。`scripts/merge_claude_md.py` はこのパターンのバックアップファイルを作る）
- `README.md`（「## 拡張ポイント（ルール）」節。ここか、その直後に git 運用の要点を追記する）
- `docs/runbook.md`（「## 3. キューを回す」の後、「## 4. blocked に答えて todo に戻す」の前あたりに「PR ができたらマージする」手順を追記する）
- `docs/decisions.md`（末尾に1行追記する形式。既存行の書式に合わせる）
- `vault/rules/common/git.md`（T-0030）・`vault/rules/creator/git-workflow.md`（T-0031）

- `README.md` に「1計画=1ブランチ」「PR作成はエージェントまで」「マージは人」の3点を含む説明が追記されている。確認：`grep -c '1計画' README.md` と `grep -c 'マージは人' README.md` がそれぞれ1以上
- `docs/runbook.md` に、PR ができた後は人がマージする旨の手順が追記されている。確認：`grep -c 'マージ' docs/runbook.md` が1以上

- `bash scripts/smoke.sh | tail -1` が `fail=0` を含む（他ファイルを壊していないことの確認）

## 決定済み
- `install.sh` の追加位置：既存の `copy_if_absent` 対象リスト（`rules/planner/planner.md` の直後）に `rules/common/git.md rules/creator/git-workflow.md` を追加する（他の並び順は変えない）
- `.gitignore` の追加行は末尾に `CLAUDE.md.bak-*` を1行追加するだけでよい（他の行は変更しない）
- `README.md` の追記先は「## 拡張ポイント（ルール）」節の末尾に新しい段落（または箇条書き3行）として追加する。新しい節見出しを作る必要はない。内容の目安：「1計画=1ブランチ（`work/p-xxx-<slug>`）で作業し、作業ステップごとにコミットする。計画内の全タスクが `done` になったら作成エージェントが push して `gh pr create` するところまで行う。マージは人が行う（詳細は `vault/rules/common/git.md`）」
- `docs/runbook.md` の追記先は「## 3. キューを回す」の直後に新しい小節（例：`## 3.5 計画が終わったら PR をマージする`）を追加する形でよい。内容の目安：「計画内の全タスクが `done` になると作成エージェントが `gh pr create` して報告する。人が内容を確認して `gh pr merge` する（マージ・ブランチ削除は人の操作）」
- `docs/decisions.md` の追記行は既存の表形式（`| 日付 | 何を | なぜ |`）に合わせ、日付は `TZ=Asia/Tokyo date '+%Y-%m-%d'` で取得した当日の日付にする。「何を」の列に「git 運用ルール」という語を含める（例：「git 運用ルール（1計画1ブランチ・PR作成はエージェントまで・マージは人・main直接コミット拒否・未コミット差分検査）を導入」）
- `docs/vault-spec.md`・`docs/install.md`・`vault/rules/README.md` は変更しない（`docs/install.md` は複製対象を「標準ルール」と総称しており個別ファイル名を列挙していないため、今回の追加で更新が必要な記述は無い）
- git commit はしない（人が確認してからコミットする）
