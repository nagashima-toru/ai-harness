# T-03 vault-spec 7節の集計キーの定義を書き換える

## 目的
仕様の正本 `docs/vault-spec.md` 7節の集計キーの定義を、「最後の `creator=` 付き行（`doing→review` または `doing→blocked`）の値」に合わせる（issue #97）。

## 入力
- `docs/vault-spec.md` 7節（143行目：`- 集計キー：そのタスクの最後の `doing→review` 行の `creator=` の値。...`）
- `gh issue view 97`

## 成果物
- `docs/vault-spec.md`

## 受け入れ基準
- 新しい定義の行がある。確認：`grep -c '^- 集計キー：そのタスクの `doing→review`・`doing→blocked` 行のうち、`creator=` が付いた最後の行の値' docs/vault-spec.md` が `1`
- 古い定義の文言が無い。確認：`grep -c '最後の `doing→review` 行の `creator=` の値' docs/vault-spec.md` が `0`
- 変更は集計キーの1行だけ。確認：`git diff --numstat main -- docs/vault-spec.md` の出力が `1	1	docs/vault-spec.md`
- 7節の他の定義の行が残っている。確認：`grep -c '^- blocked 率：`→blocked` で終わった件数 ÷ 対象タスク数$' docs/vault-spec.md` が `1`、`grep -c '^- 1回目 PASS 率：' docs/vault-spec.md` が `1`

## 決定済み
- 143行目を次の1行でそのまま置き換える（文言を変えない）：
  `- 集計キー：そのタスクの `doing→review`・`doing→blocked` 行のうち、`creator=` が付いた最後の行の値。`creator=` が付いていない行は読み飛ばす。`creator=` 付きの行が1つも無いタスクは `unknown` として扱う（エラーにしない）`
- 他の行（対象タスク・1回目 PASS 率・平均 attempt・blocked 率・出力形式・`creator=`／`verifier=` の書式の説明）は変えない。新しい行も足さない
- `docs/vault-spec.md` は `vault/rules/` ではない。`agent_write_guard.py` が creator に拒否するのは `vault/plans/`・`vault/log/`・`vault/rules/` だけなので、直接書ける（提案ファイルは不要）
- `scripts/model_stats.py`・`scripts/smoke.sh`・`vault/designs/D-010.md` は触らない（T-01・T-02・T-04）
- コミットは不要（受け入れ基準に無い）
