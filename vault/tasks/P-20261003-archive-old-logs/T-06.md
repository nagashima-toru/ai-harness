# T-06 移す対象の計画 ID 一覧を確定し dry-run で検査する

## 目的
人が `--apply` で移す対象の一覧を事前に確定し、`scripts/archive_plans.sh --dry-run` がすべての対象を NG 無しで受け付けることを確かめる。実際の移動はこのタスクでは行わない（人が PR ブランチ上で行う）。

## 入力
- `vault/log/*.md`（`creator=` の有無）
- `vault/plans/*.md`（status とタスク表）
- `scripts/archive_plans.sh`（T-01 の成果物）と T-01 タスク票の「決定済み」（`--from-file` の形式）
- 計画票 `vault/plans/P-20261003-archive-old-logs.md` の「分割方針」と「人への質問」1の回答

## 成果物
- `vault/tasks/P-20261003-archive-old-logs/T-06-targets.txt`（新規。移す計画 ID の一覧。1ファイル）

## 受け入れ基準
- 一覧が43件：`grep -c '^P-' vault/tasks/P-20261003-archive-old-logs/T-06-targets.txt` の出力が `43`
- 計画 ID 以外の行（空行・コメント）が無い：`grep -vc '^P-' vault/tasks/P-20261003-archive-old-logs/T-06-targets.txt` の出力が `0`
- `creator=` が1つも無い log の計画がすべて一覧にある：`grep -L 'creator=' vault/log/*.md | grep -c -F -f vault/tasks/P-20261003-archive-old-logs/T-06-targets.txt` の出力が `43`
- ドライランで NG が出ない：`bash scripts/archive_plans.sh --dry-run --from-file vault/tasks/P-20261003-archive-old-logs/T-06-targets.txt 2>&1 | grep -c 'NG '` の出力が `0`
- ドライランの移動行が171行（計画票43・タスク票43・verdict 42・log 43）：`bash scripts/archive_plans.sh --dry-run --from-file vault/tasks/P-20261003-archive-old-logs/T-06-targets.txt | grep -c ' vault/archive/20'` の出力が `171`
- 何も移していない：`git status --porcelain -- vault/archive` の出力が空

## 決定済み
- 対象は「人への質問」1の A（古い形式の log を持つ計画だけ）。`creator=` が1つも無い `vault/log/<計画ID>.md` の計画 ID（2026-10-03 時点で43件、planner が確認済み）。人が B を選んだ場合は、承認前に planner がこのタスク票を書き直す（creator は A のまま進めてよい）
- この計画自身（`P-20261003-archive-old-logs`）は入れない（log に `creator=` が付くので上の条件で自然に外れる）
- ファイルの形式：1行1件、計画 ID だけを書く（行頭が `P-`）。`#` のコメント行と空行は書かない（受け入れ基準3の `grep -F -f` が空行を「全行に一致するパターン」として扱い、検査が素通りになるため）。計画 ID の後ろに空白や注記を付けない。並びはファイル名順。一覧の条件・作成日などの説明はこのタスク票の「進捗」に書く
- `P-20260924-worktree-isolation-guard` は verdict のディレクトリが無いので、移動行は3行になる（171行はこれを数えた値）
- 一覧に入れた計画のいずれかでドライランが NG になった場合は、一覧から外さずに blocked にし、question に NG の行を書く（対象を勝手に減らさない）
- `--apply` は実行しない。`vault/plans/`・`vault/log/`・`vault/tasks/`（このファイルと、このタスク票の「進捗」以外）・`vault/verdicts/` は変えない
- このファイルは T-06 の成果物で、提案ファイル（`-proposal.md`）ではない。人が `--apply --from-file` でそのまま使う
